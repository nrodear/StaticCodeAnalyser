## Beschreibung

Delphi-Konvention seit dem ersten Tag: ein Zeiger-Alias auf `TXxx` heißt `PXxx`. Das Präfix `P` macht die Indirektion an der Aufrufstelle sichtbar. Entspricht SonarDelphi communitydelphi:PointerName. Ein Namens-Framework wird das Präfix später konfigurierbar machen.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
type TIntPtr = ^Integer;
```

### Gut (idiomatische Korrektur)

```pascal
type PInteger = ^Integer;
```
