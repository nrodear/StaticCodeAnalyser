# SCA044 — Lange String-Verkettung - besser Format()

> Mehrteilige String-Verkettung - in einen Format()-Aufruf überführen

## Beschreibung

Ketten wie `'a' + Var + 'b' + IntToStr(N)` (drei oder mehr Verkettungen mit nicht-literalen Segmenten) sind schwerer zu überblicken und schwerer zu übersetzen als `Format('a%sb%d', [Var, N])`: jedes IntToStr / FloatToStr / FormatDateTime mitten in einem String ist eine weitere Stelle, an der ein `resourcestring` die Meldungsvorlage nicht erfassen kann. Der Detektor betrachtet Zuweisungen, deren rechte Seite mindestens drei `+`-Operatoren (vier oder mehr Terme) mit mindestens einem nicht-literalen Term hat, sodass triviale Fälle (`'<' + Name + '>'`) still bleiben; eine Verkettung, die direkt als Aufrufargument übergeben wird, wird nicht geprüft. Übersprungen werden rechte Seiten, die bereits Format aufrufen, Zuweisungen an SQL-Properties (die deckt SCA003 ab) und Zeilen unter einem aktiven `// noinspection ConcatToFormat`. Die gemeldete Form kann in performancekritischen inneren Schleifen beabsichtigt sein, in denen die Varargs von Format boxen; für diesen Fall ist der Unterdrückungs-Marker da.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
Msg := 'User ' + Name + ' has ' + IntToStr(N) + ' open tickets';
```

### Gut (idiomatische Korrektur)

```pascal
Msg := Format('User %s has %d open tickets', [Name, N]);
```
