## Beschreibung

Marco Cantu, delphi.org und Stack Overflow zählen `with` übereinstimmend zu den häufigsten Fehlerquellen in Delphi. Bezeichner aus dem äußeren Scope werden still von Membern des with-Ziels verdeckt. Stattdessen eine lokale Variable als Alias verwenden.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
with Customer do
begin
  Name := SomeName;   // Customer.Name? or local Name?
end;
```

### Gut (idiomatische Korrektur)

```pascal
C := Customer;
C.Name := SomeName;
```
