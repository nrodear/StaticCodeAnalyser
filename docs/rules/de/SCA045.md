## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

Marco Cantu, delphi.org and Stack Overflow consistently rank `with` among the top Delphi bug sources. Identifiers from the outer scope get silently shadowed by members of the with-target. Use a local variable alias instead.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
with Customer do
begin
  Name := SomeName;   // Customer.Name? or local Name?
end;
```

### Gut (idiomatische Korrektur)

```pascal
C := Customer;
C.Name := SomeName;
```
