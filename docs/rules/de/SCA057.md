## Beschreibung

Zusammenfassung mehrerer `DfmDbInUiForm`-Funde auf demselben Formular - sobald die Anzahl 3 erreicht, fügt SCA zusätzlich zu den Einzelfunden (sie bleiben bestehen) einen einzelnen Hinweis "TDataModule herausziehen" hinzu, um die architektonische Lösung sichtbar zu machen, statt auf eine Komponente nach der anderen zu zeigen. Den DB-Zugriff in ein TDataModule zu verlagern, trennt die Datenanbindung sauber von der Oberfläche: dieselbe TFDConnection und dieselben Queries können von mehreren Formularen gemeinsam genutzt werden, die DB-Schicht ist testbar, ohne ein TForm zu instanziieren, und die Einrichtung von DesignForm gegenüber RuntimeForm bleibt sauber. Die Schwelle ist 3 und derzeit fest einprogrammiert - bewusst niedrig gehalten, denn sobald 3 DB-Komponenten auf einem Formular zu sehen sind, ist das Muster bereits falsch.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
(TForm with 5+ TFDQuery/TFDConnection components)
```

### Gut (idiomatische Korrektur)

```pascal
(move all DB components to a TDataModule)
```
