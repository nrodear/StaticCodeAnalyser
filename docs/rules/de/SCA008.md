> Zugriff auf eine Variable, die an dieser Stelle nil sein kann

## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

Variable was assigned a value that could be nil (e.g. Find...-method returning nil) and is dereferenced without prior nil-check. Crashes with EAccessViolation at runtime.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
obj := FindObject(id);
obj.DoStuff;   // <-- AV if FindObject returns nil
```

### Gut (idiomatische Korrektur)

```pascal
obj := FindObject(id);
if Assigned(obj) then obj.DoStuff;
```
