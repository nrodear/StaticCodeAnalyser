## Beschreibung

Gruppierte Deklarationen (`A, B, C: Integer;` für Variablen, Felder oder Parameter) verwirren Diffs (eine neue Variable ändert eine bestehende Zeile), verhindern Kommentare je Variable und erschweren Refactorings mit Typänderung. Jede Deklaration in einer eigenen Zeile ist sauberer. Fasst SonarDelphi communitydelphi:GroupedFieldDeclaration / :GroupedVariableDeclaration / :GroupedParameterDeclaration zu einer Regel zusammen (SCA kann sie später aufteilen).

## Beispiele

### Schlecht (löst die Regel aus)

> Diese Regel meldet mit niedriger Konfidenz: mit der Vorgabe `[Rules] MinConfidence=medium` bleibt das folgende Beispiel unsichtbar. Mit `[Rules] MinConfidence=low` erscheint es.

```pascal
var A, B, C: Integer;
field FX, FY: TPoint;
```

### Gut (idiomatische Korrektur)

```pascal
var A: Integer;
    B: Integer;
    C: Integer;
```
