## Beschreibung

Inline-Assembler erzeugt eine Plattformbindung (Bytes nur für x86/x64, die einen ARM-Cross-Compile oder FreePascal-Ziele nicht überstehen), umgeht den Delphi-Optimierer (kein Inlining, keine Umordnung) und ist schwer zu debuggen. Die berechtigten Anwendungsfälle (CPUID-Erkennung, MMX/SSE-Intrinsics) sind durch RTL-Hilfsroutinen abgedeckt. Entspricht SonarDelphi communitydelphi:InlineAssembly.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
function Cpuid: Cardinal;
asm
  XOR EAX, EAX
  CPUID
end;
```

### Gut (idiomatische Korrektur)

```pascal
function Cpuid: Cardinal;
begin
  Result := GetCpuFeatures;
end;
```
