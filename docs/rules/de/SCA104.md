## Beschreibung

Delphi-Konvention: Klassentypen `TXxx`, Records `TXxx` oder `RXxx`, Interfaces `IXxx`, Zeiger `PXxx` (SCA100), Ausnahmen `EXxx`. Dieser Detektor deckt nur die Teilmenge Klassen/Records ab. Forward-Deklarationen (`TFoo = class;`), `class of`-Referenzen (`TFooClass = class of TFoo`) und generische Syntax werden berücksichtigt. Entspricht SonarDelphi communitydelphi:TypeName.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
type Counter = class
  ...
  end;
```

### Gut (idiomatische Korrektur)

```pascal
type TCounter = class
  ...
  end;
```
