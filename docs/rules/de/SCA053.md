## Beschreibung

Ein `var X: T;` in einem Methodenrumpf ist deklariert, wird aber im selben Rumpf weder gelesen noch geschrieben. Entspricht dem Delphi-Compiler-Hinweis H2164, wird aber als SCA-Fund ausgegeben, damit er sich einheitlich mit den übrigen Regeln filtern, unterdrücken, priorisieren und verfolgen lässt - nützlich, wenn H2164 projektweit stummgeschaltet ist. Der Rumpf-Scan erkennt per `with` umgebundene Bezeichner und ignoriert Variablen, deren Namen einem vorhandenen Feld/einer vorhandenen Property entsprechen (das `with` würde sie implizit umbinden). Inline-Variablen, die mit `var X: T := ...` eingeführt werden, werden genauso behandelt. Mit `// noinspection UnusedLocalVar` unterdrücken, wenn die Variable absichtlich beibehalten wird (deklarative Dokumentation oder von einer API verlangte Record-Initialisierung).

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
var
  Tmp: Integer;   // never used
begin
  DoStuff;
end;
```

### Gut (idiomatische Korrektur)

```pascal
begin
  DoStuff;
end;
```
