# SCA087 — Leerer Sichtbarkeitsabschnitt in der Klasse

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Abschnittskopf `public`/`private`/... ohne Member darunter

## Beschreibung

Eine Klasse mit einem Sichtbarkeits-Schlüsselwort, auf das unmittelbar ein weiteres Sichtbarkeits-Schlüsselwort (oder `end`) folgt, ist meist ein Refactoring-Rest - alle Member dieses Abschnitts wurden anderswohin verschoben. Den leeren Abschnittskopf löschen. Entspricht SonarDelphi communitydelphi:EmptyVisibilitySection.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
type TFoo = class
  public
  private
    FX: Integer;
  end;
```

### Gut (idiomatische Korrektur)

```pascal
type TFoo = class
  private
    FX: Integer;
  end;
```
