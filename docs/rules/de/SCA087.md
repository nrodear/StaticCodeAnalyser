## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

A class with a visibility keyword followed immediately by another visibility keyword (or `end`) is usually a refactor leftover - all members of that section moved elsewhere. Delete the empty header. Matches SonarDelphi communitydelphi:EmptyVisibilitySection.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
type TFoo = class
  public
  private
    FX: Integer;
  end;
```

### Gut (idiomatische Korrektur)

```pascal
type TFoo = class
  private
    FX: Integer;
  end;
```
