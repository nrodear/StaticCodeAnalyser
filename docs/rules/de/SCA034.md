# SCA034 — Pflichtfeld ohne UI-Bindung

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> TField mit Required=True hat kein gebundenes Eingabe-Control

## Beschreibung

Ein Pflichtfeld, das der Benutzer nicht erreichen kann, lässt jedes Insert mit 'Field X must have a value' scheitern. Entweder ein Control binden oder das Required=True entfernen.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
FieldDefs: Email Required=True   // no DBEdit / DBLookup bound to it
```

### Gut (idiomatische Korrektur)

```pascal
object edtEmail: TDBEdit
  DataSource = dsPerson
  DataField = 'Email'
end
```
