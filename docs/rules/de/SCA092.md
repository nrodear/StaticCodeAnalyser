# SCA092 — Unit ohne Deklarationen

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Unit hat weder type, const, var noch procedure/function - löschen oder füllen

## Beschreibung

Eine `.pas`-Datei mit Unit-Kopf, aber ohne Deklarationen ist toter Ballast. Entweder die Datei löschen oder den Platzhalter füllen. Entspricht SonarDelphi communitydelphi:EmptyFile.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
unit X;
interface
implementation
end.
```

### Gut (idiomatische Korrektur)

```pascal
// delete the file
```
