## Beschreibung

Erkennt N+ aufeinanderfolgende identische Zeilen, die zwei- oder mehrmals in derselben Datei vorkommen (Vorgabe-Minimum: 8 Zeilen; Kopien in verschiedenen Dateien werden nicht verglichen). Der DRY-Verstoß erzeugt Änderungskopplung: ein Bugfix an einer Kopie weicht still von den anderen ab, und Reviewer können nicht leicht erkennen, dass eine Verhaltenskorrektur nur eine von N Aufrufstellen erfasst hat. Refactoring: in eine Hilfsmethode oder eine gemeinsame Konstante herausziehen. Zeilen werden normalisiert (getrimmt, kleingeschrieben, Folgen von Leerraum zusammengefasst), damit kosmetische Unterschiede kein echtes Duplikat verdecken. Triviale Zeilen (leer, begin, end, else, try, finally, except, reine Kommentarzeilen) zählen nicht zu einem Block. Schwelle über [Detectors] DuplicateBlockMinLines.
