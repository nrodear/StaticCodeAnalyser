# SCA170 — string-Parameter ohne const

> string-Parameter ohne const deklariert - erzwingt bei jedem Aufruf eine Refcount-Erhöhung

## Beschreibung

Delphi erhöht bei jedem Aufruf den Referenzzähler des Strings, wenn der Parameter ohne `const` deklariert ist. Mit `const` übergibt der Compiler eine reine Referenz und spart sich das Hoch- und Herunterzählen des Referenzzählers. Der Compiler verbietet außerdem Zuweisungen an einen `const`-Parameter, was den Vertrag, nichts zu verändern, explizit macht. Für String-Parameter, die nicht verändert werden (die überwältigende Mehrheit), `const` bevorzugen. Der Detektor meldet Parameter vom Typ `string`/`AnsiString`/`UnicodeString`/`WideString`/`RawByteString`/`ShortString` ohne `const`/`var`/`out`.

## Beispiele
