# SCA169 — Assert-Argument enthält einen Aufruf mit Seiteneffekt

> Assert(SomeCall) - der Aufruf entfällt im Release-Build und sein Seiteneffekt geht stillschweigend verloren

## Beschreibung

Der Delphi-Compiler entfernt Assert-Aufrufe in Release-Builds vollständig (sofern DCC_Assertions nicht eingeschaltet ist). Enthält der geprüfte Ausdruck einen Funktionsaufruf mit Seiteneffekten (Allokation, Zustandsänderung, I/O, Zählerinkrement), verschwindet auch der Seiteneffekt - das Verhalten im Release weicht vom Debug ab. Der Detektor meldet Assert-Aufrufe, deren Argument ein Funktionsaufruf-Muster enthält, nach Ausschluss einer Whitelist bekannter reiner RTL-Helfer (Length, Assigned, SizeOf, IntToStr, ...). Den Aufruf aus dem Assert herausziehen und stattdessen das Ergebnis per Assert prüfen.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
Assert(InitializeSubsystem);   // Release build skips Init entirely
```

### Gut (idiomatische Korrektur)

```pascal
var Ok := InitializeSubsystem;
Assert(Ok, 'subsystem init failed');
```
