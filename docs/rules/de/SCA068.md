## Beschreibung

Trailing-Komma vor `)` in einer Argument-Liste. In einem normalen Aufruf weist Delphi es zurück: das Komma fügt ein leeres Argument hinzu (E2034 too many actual parameters). Nur ein spät gebundener Aufruf auf einem Variant oder dispinterface (OLE-Automatisierung) übersetzt es; dort ist das leere Argument ein ausgelassener optionaler Parameter. Dort hat es keinen semantischen Nutzen (anders als in Python/JS, wo es den Diff stabilisiert) und deutet auf ein vergessenes Argument hin. Entspricht SonarDelphi communitydelphi:TrailingCommaArgumentList.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
Excel.Workbooks.Open(FileName,);   // Excel: Variant
Excel.ActiveWorkbook.SaveAs(NewName, );
```

### Gut (idiomatische Korrektur)

```pascal
Excel.Workbooks.Open(FileName);   // Excel: Variant
Excel.ActiveWorkbook.SaveAs(NewName);
```
