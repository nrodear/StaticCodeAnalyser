## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

Trailing comma before `)` in Delphi has no semantic benefit (unlike Python/JS where it stabilizes the diff) and suggests a forgotten argument. Matches SonarDelphi communitydelphi:TrailingCommaArgumentList.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
WriteLn('A', 'B', );
DoStuff(Param1, Param2,);
```

### Gut (idiomatische Korrektur)

```pascal
WriteLn('A', 'B');
DoStuff(Param1, Param2);
```
