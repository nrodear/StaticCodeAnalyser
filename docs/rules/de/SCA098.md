# SCA098 — Überflüssige bedingte Zuweisung

> `if Cond then X := True else X := False` sollte `X := Cond` heißen

## Beschreibung

Zwei Zweige, die derselben Variable True/False zuweisen, lassen sich auf eine einzige direkte Zuweisung reduzieren (oder `not Cond`, wenn die Polarität umgekehrt ist). Kürzer, schneller und näher am booleschen Ausdruck. Entspricht SonarDelphi communitydelphi:RedundantConditional.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
if Active then Result := True else Result := False;
```

### Gut (idiomatische Korrektur)

```pascal
Result := Active;
```
