## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

Credentials in source code end up in version control, build artifacts, decompilers, and stack traces. Move secrets to environment variables, OS credential store, or encrypted configuration.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
Password := 'admin123';
```

### Gut (idiomatische Korrektur)

```pascal
Password := GetEnvironmentVariable('DB_PASSWORD');
```
