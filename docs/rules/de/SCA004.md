## Beschreibung

Zugangsdaten im Quelltext landen in der Versionsverwaltung, in Build-Artefakten, in Decompilern und in Stacktraces. Geheimnisse in Umgebungsvariablen, den Anmeldedatenspeicher des Betriebssystems oder eine verschlüsselte Konfiguration verlagern.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
Password := 'admin123';
```

### Gut (idiomatische Korrektur)

```pascal
Password := GetEnvironmentVariable('DB_PASSWORD');
```
