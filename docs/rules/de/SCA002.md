> Leerer except-Block schluckt jede Exception ohne Reaktion

## Beschreibung

Ein except-Block ohne Anweisungen fängt jede Ausnahme ab, auch unerwartete (EAccessViolation, EOutOfMemory). Bugs werden unsichtbar. Die Ausnahme mindestens protokollieren oder erneut auslösen.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
try DoStuff except end;
```

### Gut (idiomatische Korrektur)

```pascal
try DoStuff except on E: Exception do LogError(E.Message); end;
```
