## Beschreibung

Offene Arbeitsmarker (TODO, FIXME, HACK, XXX) bilden eine parallele Aufgabenverwaltung im Quelltext. Das Muster scheitert durch Anhäufung: Marker, die im Abstand von Jahren hinzukamen, werden nie gemeinsam gesichtet, der ursprüngliche Autor geht, und der nächste Leser kann nicht erkennen, ob das TODO noch relevant ist oder stillschweigend ausgeliefert wurde. SCA macht jeden solchen Marker sichtbar, damit CI-Gates einen Release-Branch ohne TODOs oder eine Sichtung zur PR-Zeit erzwingen können. Erkannte Formen: Kommentare `// TODO` und `{ TODO ... }`, der Marker als ganzes Wort, mit optionalem Jira-ID-Suffix (`// TODO PROJ-123: ...`). TODO, FIXME und HACK treffen unabhängig von Groß-/Kleinschreibung, XXX nur in Großbuchstaben (ein kleingeschriebenes `xxx` ist fast immer ein Platzhalter). `(* ... *)`-Kommentare werden nicht durchsucht, und die Markermenge ist fest. Ein Marker, der bleiben muss, lässt sich mit `// noinspection TodoComment` unterdrücken.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
// TODO: handle the case where input is empty
```

### Gut (idiomatische Korrektur)

```pascal
if Input = '' then
  raise EArgumentException.Create('Input must not be empty');

```
