## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

C++ FAQ 23.5 / *Effective Java* item 17 in Delphi form: virtual dispatch in a constructor runs the most-derived override before subclass fields are initialised. Defer to a non-virtual post-construction hook.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
constructor TBase.Create;
begin
  Configure;   // virtual
end;
```

### Gut (idiomatische Korrektur)

```pascal
constructor TBase.Create;
begin
  // skip virtual call
end;
procedure TBase.AfterConstruction;
begin
  Configure;
end;
```
