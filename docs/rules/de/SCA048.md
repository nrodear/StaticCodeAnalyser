> Virtuelle Methode aus dem Konstruktor gerufen - die Ableitung sieht ein halb initialisiertes Self

## Beschreibung

C++ FAQ 23.5 / *Effective Java* Item 17 in Delphi-Form: ein virtueller Aufruf in einem Konstruktor führt das am weitesten abgeleitete Override aus, bevor die Felder der Ableitung initialisiert sind. Auf einen nicht-virtuellen Hook nach der Konstruktion verschieben.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
constructor TBase.Create;
begin
  Configure;   // virtual
end;
```

### Gut (idiomatische Korrektur)

```pascal
constructor TBase.Create;
begin
  // skip virtual call
end;
procedure TBase.AfterConstruction;
begin
  Configure;
end;
```
