# SCA028 — DFM-Ereignisbehandler zeigt auf fehlende Methode

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Bug-red)

> OnClick / On... verweist auf eine Methode, die es in der Formularklasse nicht gibt

## Metadaten

## Beschreibung

Das DFM-Streaming stürzt beim Laden des Formulars mit *"class TForm has no published method X"* ab. Meist verursacht durch eine manuelle Umbenennung in der .pas, ohne die .dfm anzupassen.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
object btnSave: TButton
  OnClick = btnSaveClick   // method removed in .pas
end
```

### Gut (idiomatische Korrektur)

```pascal
object btnSave: TButton
  OnClick = btnSaveClick
end

// and in the .pas, published:
procedure btnSaveClick(Sender: TObject);
```
