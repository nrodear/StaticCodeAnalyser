## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

Pascal coding convention has been space-indentation since the 80s. Tabs render at 2/4/8 columns depending on the editor, break code-review side-by-side diffs and confuse alignment. SonarDelphi tracks the same as communitydelphi:TabulationCharacter.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
procedure Foo;
begin
<TAB>DoStuff;
end;
```

### Gut (idiomatische Korrektur)

```pascal
procedure Foo;
begin
  DoStuff;
end;
```
