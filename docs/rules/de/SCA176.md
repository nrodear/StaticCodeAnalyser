# SCA176 — Methode mit hoher kognitiver Komplexität (verschachtelter Kontrollfluss)

## Beschreibung

Die zyklomatische Komplexität (SCA022) zählt unabhängige Pfade linear - zehn flache if-Anweisungen wiegen so viel wie ein dreifach verschachteltes if. Die kognitive Komplexität, 2017 von Sonar eingeführt, vervielfacht die Kosten von Verschachtelung: Jedes Kontrollfluss-Konstrukt addiert 1 + Verschachtelungstiefe. Drei verschachtelte Schleifen ergeben damit 1+2+3=6 statt 3. Der Detektor durchläuft jede Methode mit einem expliziten Stack statt mit Rekursion (sodass tief verschachtelter Code den Aufrufstack nicht zum Überlaufen bringen kann) und verfolgt die aktuelle Tiefe und die laufende Summe. Boolesche Operatoren (and/or/xor) in if-Bedingungen addieren jeweils +1. Schwelle: 15 (Sonar-Standard), konfigurierbar über INI [Detectors] CognitiveLimit.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
procedure ProcessOrder(const AOrder: TOrder);
begin
  if AOrder.IsValid and AOrder.HasItems then        // +1 (depth 0), +1 'and'  = 2
    for var I := 0 to AOrder.Count - 1 do           // +1+1 (depth 1)          = 2
      while AOrder[I].NeedsRetry do                 // +1+2 (depth 2)          = 3
        if AOrder[I].InStock or AllowBackorder then // +1+3 (depth 3), +1 'or' = 5
          case AOrder[I].Kind of                    // +1+4 (depth 4)          = 5
            ikPhysical:
              if AOrder[I].Weight > 0 then          // +1+5 (depth 5)          = 6
                Ship(AOrder[I]);
          end;
end;
// Cognitive complexity = 2+2+3+5+5+6 = 23 (limit 15)
```

### Gut (idiomatische Korrektur)

```pascal
procedure ShipItem(const AItem: TOrderItem);
begin
  if not (AItem.InStock or AllowBackorder) then Exit;  // +1, +1 'or' = 2
  if AItem.Kind <> ikPhysical then Exit;               // +1
  if AItem.Weight <= 0 then Exit;                      // +1
  Ship(AItem);
end;

procedure ProcessOrder(const AOrder: TOrder);
begin
  if not AOrder.IsValid then Exit;                     // +1
  if not AOrder.HasItems then Exit;                    // +1
  for var I := 0 to AOrder.Count - 1 do                // +1 (depth 0)
    while AOrder[I].NeedsRetry do                      // +1+1 (depth 1)
      ShipItem(AOrder[I]);
end;
// ShipItem = 4, ProcessOrder = 5 - both well below 15
```
