## Beschreibung

Jede Klasse erbt implizit von TObject; `TFoo = class(TObject)` ist identisch mit `TFoo = class`. Ohne die explizite Basis fallen echte Änderungen der Vererbung in Diffs deutlicher auf. Entspricht SonarDelphi communitydelphi:ExplicitTObjectInheritance.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
type TFoo = class(TObject) ... end;
```

### Gut (idiomatische Korrektur)

```pascal
type TFoo = class ... end;
```
