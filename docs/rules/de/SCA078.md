# SCA078 — Catch-all auf der Wurzelklasse Exception

## Beschreibung

Das Abfangen der Wurzelklasse `Exception` fängt jeden Fehler ab, auch nicht behebbare (EAccessViolation, EOutOfMemory, EStackOverflow). Besser einen spezifischen Ausnahmetyp abfangen (EDatabaseError, EFOpenError, EConvertError, ...), damit fremde Fehler nicht verdeckt werden. Mit `// noinspection` unterdrücken, wenn das Catch-all beabsichtigt ist (z. B. an einer Logger-Grenze).

## Beispiele

### Schlecht (löst die Regel aus)

> Diese Regel meldet mit niedriger Konfidenz: mit der Vorgabe `[Rules] MinConfidence=medium` bleibt das folgende Beispiel unsichtbar. Mit `[Rules] MinConfidence=low` erscheint es.

```pascal
try Foo; except on E: Exception do Log(E.Message); end;
```

### Gut (idiomatische Korrektur)

```pascal
try Foo; except on E: EDatabaseError do Log(E.Message); end;
```
