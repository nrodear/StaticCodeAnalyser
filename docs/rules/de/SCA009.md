## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

Similar to MemoryLeak (SCA001) but checked structurally: any .Create followed by code without an enclosing try/finally is flagged regardless of whether Free is called eventually.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
obj := TFoo.Create;
obj.DoStuff;
obj.Free;
```

### Gut (idiomatische Korrektur)

```pascal
obj := TFoo.Create;
try obj.DoStuff finally obj.Free end;
```
