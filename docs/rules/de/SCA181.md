# SCA181 — DUnitX-Attribut [Category] ohne Kategorienamen

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Bug-red)

> [Category] ohne Argument ist in DUnitX ein Compile-Fehler - immer einen Kategorienamen übergeben

## Beschreibung

Das DUnitX-Attribut [Category] verlangt ein String-Argument, mit dem Tests für die selektive Ausführung gruppiert werden. Ohne das Argument meldet der Compiler einen Fehler wegen eines fehlenden Parameters. Immer einen expliziten Kategorienamen übergeben (z. B. 'Slow', 'CI-only', 'Integration').

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
[Category]
procedure Foo;
```

### Gut (idiomatische Korrektur)

```pascal
[Category('Slow')]
procedure Foo;
```
