# SCA127 — Basisklasse `Exception` statt einer eigenen Ableitung ausgelöst

## Beschreibung

Die RTL-Basisklasse `Exception` auszulösen entspricht `new Error('something')` in JavaScript: Es teilt dem Aufrufer mit, *dass* etwas schiefging, aber nicht *was*. Der aufrufende Code muss dann die breitestmögliche Klasse fangen (`on E: Exception do ...`), die auch jeden unabhängigen Laufzeitfehler fängt und dazu neigt, Fehler zu verschlucken. Eine spezifische Ableitung ist vorzuziehen (z. B. `EArgumentOutOfRangeException`, `EFileNotFoundException`, ein domänenspezifisches `EMyDomainError`). Der Detektor durchläuft jeden `nkRaise`-Knoten und meldet ihn, wenn der ausgelöste Ausdruck mit `Exception.Create` beginnt (ohne Beachtung der Groß-/Kleinschreibung) oder genau `Exception` ist (ohne Create-Aufruf). Blankes `raise;` (erneutes Auslösen) und `raise E;` (Variable) werden nicht gemeldet. Entspricht Sonar-Delphi `RaisingRawExceptionCheck`.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
if x < 0 then
  raise Exception.Create('x is negative');
```

### Gut (idiomatische Korrektur)

```pascal
if x < 0 then
  raise EArgumentOutOfRangeException.CreateFmt('x = %d', [x]);
```
