## Beschreibung

NOSONAR-Marker sind technische Schulden: jeder stellt einen Fund still, ohne das eigentliche Problem zu beheben. SCA meldet jedes NOSONAR, damit Reviewer die Unterdrückungen im Code-Review prüfen können. SCA nutzt für die native Unterdrückung einen eigenen Marker `// noinspection` - mit NOSONAR versehener Code aus SonarDelphi sollte migriert werden. Entspricht SonarDelphi communitydelphi:NoSonar.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
Dispose(P); // NOSONAR - we know about this
```

```pascal
// noinspection - covered by integration test
Dispose(P);
```
