# SCA036 — UI-Control passt nicht zum TField-Typ

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Klasse des DB-Controls passt nicht zu TField.DataType (TDBEdit für ein TBooleanField)

## Beschreibung

Der Benutzer sieht den Rohwert und kann den Typ verfälschen. Ein Control wählen, das zum Feldtyp passt (TDBCheckBox für Booleans, TDBLookupComboBox für Fremdschlüssel).

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
DBEdit1.DataField = 'IsActive'   // TBooleanField
```

### Gut (idiomatische Korrektur)

```pascal
DBCheckBox1.DataField = 'IsActive'
```
