# SCA056 — Master-Detail ohne MasterFields

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Bug-red)

> TDataSet hat MasterSource gesetzt, aber weder MasterFields noch IndexFieldNames

## Beschreibung

Die VCL bildet stillschweigend ein kartesisches Produkt statt des beabsichtigten Master-Detail-Joins - jede Elternzeile zieht zur Laufzeit jede Detailzeile. Abhilfe: MasterFields setzen (und IndexFieldNames bei IB/FB).

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
QDetail.MasterSource = dsMaster   // MasterFields = '' (empty)
```

### Gut (idiomatische Korrektur)

```pascal
QDetail.MasterSource = dsMaster   QDetail.MasterFields = 'OrderID'
```
