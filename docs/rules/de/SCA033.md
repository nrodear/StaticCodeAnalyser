## Beschreibung

Eine SQL-Property einer DB-Abfrage (TADOQuery / TFDQuery / TUniQuery / TZQuery / TKSQLQuery.SQL.Text) wird zusammengesetzt, indem die Property Text / Caption / Hint / EditText / ItemText eines UI-Eingabe-Controls (TEdit, TComboBox, TMaskEdit, ...) verkettet wird - klassische SQL-Injection über das Formular. Ein Benutzer, der `' OR ''1''=''1' --` in das Suchfeld tippt, liest beliebige Zeilen; `'; DROP TABLE Users; --` ist zerstörerisch. Refactoring: benannte Parameter binden und über ParamByName zuweisen, nie verketten. Dieser Detektor ist das DFM-/UI-Pfad-Gegenstück zu SCA003 (lexikalische SQL-Injection) und SCA058 (gefährliche SQL-Anweisung).

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
FDQuery1.SQL.Text := 'SELECT * FROM U WHERE Name=''' + EdName.Text + '''';
```

### Gut (idiomatische Korrektur)

```pascal
FDQuery1.SQL.Text := 'SELECT * FROM U WHERE Name=:n';
FDQuery1.ParamByName('n').AsString := EdName.Text;
```
