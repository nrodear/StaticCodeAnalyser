# SCA105 — Interface-Typ ohne I-Präfix

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Interface-Aliase sollten mit `I` beginnen (`IFoo = interface`)

## Beschreibung

Delphi-Konvention: Interfaces heißen `IXxx`, analog zu `TXxx` für Klassen und `PXxx` für Zeiger. Das Präfix `I` zeigt an jeder Aufrufstelle, ob ein Vertrag oder eine Implementierung vorliegt. Erfasst auch `dispinterface`. Entspricht SonarDelphi communitydelphi:InterfaceName.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
type Service = interface ['{...}'] end;
```

### Gut (idiomatische Korrektur)

```pascal
type IService = interface ['{...}'] end;
```
