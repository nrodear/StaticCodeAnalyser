## Beschreibung

Deklariert eine Unit zwei oder mehr öffentliche Klassen, ist es schwerer als nötig, sie zu finden und zwischen Units zu verschieben. SonarDelphi communitydelphi:ClassPerFile empfiehlt dasselbe. Forward-Deklarationen (`TFoo = class;`) und Klassenreferenztypen (`TFooClass = class of TFoo`) sind ausgenommen.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
type
  TFoo = class ... end;
  TBar = class ... end;
```

### Gut (idiomatische Korrektur)

```pascal
// uFoo.pas
type TFoo = class ... end;
// uBar.pas
type TBar = class ... end;
```
