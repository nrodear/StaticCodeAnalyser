# SCA143 — Unit hat keinen erklärenden Header-Kommentar

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

## Beschreibung

Ein kurzer Header-Kommentar zwischen der Deklaration `unit ...;` und dem Schlüsselwort `interface` sagt künftigen Maintainern, wozu die Unit dient - Zweck, Umfang, wichtige Invarianten, Zuständigkeit. Der Detektor liest die ersten Zeilen der Datei, findet die Marker `unit` und `interface` und prüft, dass mindestens eine Kommentarzeile (`//`, `{...}` oder `(* ... *)`) dazwischen steht. Der Schweregrad ist Hinweis, weil viele Legacy-Units den Header ohne funktionale Folgen weglassen. Entspricht Sonar-50-Regel #48.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
unit MyUnit;

interface

uses ...;
```

### Gut (idiomatische Korrektur)

```pascal
unit MyUnit;

// Database-connection pool: wraps FireDAC TFDConnection setup
// for the report subsystem. Thread-safe; single instance per app.

interface

uses ...;
```
