# SCA079 — Aufeinanderfolgende const/type/var-Sektion

## Beschreibung

`const A = 1; const B = 2;` sollte `const A = 1; B = 2;` heißen - ein Abschnitts-Schlüsselwort kann alle deklarieren. Dasselbe gilt für `type` und `var`. Fasst SonarDelphi communitydelphi:ConsecutiveConstSection / :ConsecutiveTypeSection / :ConsecutiveVarSection zu einer Regel zusammen. Die Art des Abschnitts steht in der Meldung.

## Beispiele

### Schlecht (löst die Regel aus)

> Diese Regel meldet mit niedriger Konfidenz: mit der Vorgabe `[Rules] MinConfidence=medium` bleibt das folgende Beispiel unsichtbar. Mit `[Rules] MinConfidence=low` erscheint es.

```pascal
const A = 1;
const B = 2;
```

### Gut (idiomatische Korrektur)

```pascal
const
  A = 1;
  B = 2;
```
