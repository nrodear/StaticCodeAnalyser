# SCA072 — Überflüssiger Boolean-Vergleich

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> `X = True` sollte `X` heißen (und `X <> False` entsprechend)

## Beschreibung

Einen Boolean mit True/False zu vergleichen ist umständlich und erzeugt subtile Fehler (bei WinAPI-BOOL mit Truthy != 1 ergibt `X = True` false). Der Ausdruck selbst ist bereits die Bedingung. Entspricht SonarDelphi communitydelphi:RedundantBoolean. Hinweis: Deklarationen `const X = True;` sind ausgenommen (legitime Zuweisung, kein Vergleich).

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
if Active = True then ...
if Disabled <> False then ...
```

### Gut (idiomatische Korrektur)

```pascal
if Active then ...
if Disabled then ...
```
