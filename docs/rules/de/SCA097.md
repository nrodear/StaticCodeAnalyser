# SCA097 — Destruktor ohne inherited-Aufruf

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Bug-red)

> Dem Destruktor fehlt `inherited Destroy` - das Aufräumen der Basis entfällt (Leck-Risiko)

## Beschreibung

Ein Destruktor ohne `inherited Destroy` (oder `inherited;`) hindert die Basisklasse daran, ihre eigenen Felder freizugeben, Handler abzumelden und Referenzzähler zu aktualisieren. Fast immer ein Leck. Entspricht SonarDelphi communitydelphi:DestructorWithoutInherited.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
destructor TFoo.Destroy;
begin
  FreeAndNil(FBar);
end;
```

### Gut (idiomatische Korrektur)

```pascal
destructor TFoo.Destroy;
begin
  FreeAndNil(FBar);
  inherited;
end;
```
