> TField mit Required=True ist nur an Controls mit Visible=False gebunden

## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

Control exists but the user cannot see or interact with it - inserts fail every time. Make at least one bound control visible or drop the Required=True.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
DBEdit1.DataField = 'Email'   DBEdit1.Visible = False
```

### Gut (idiomatische Korrektur)

```pascal
object DBEdit1: TDBEdit
  DataField = 'Email'
  Visible = True
end

// or drop Required = True if the field really is optional
```
