# SCA141 — Klassenimplementierung überschreitet 500 Zeilen

## Beschreibung

Wie GodClass (SCA138), aber nach Zeilenspanne statt nach Methoden-/Feldanzahl gemessen. Erfasst Klassen, die nach Member-Anzahl klein wirken, aber riesige Implementierungsrümpfe haben - typisch für Legacy-Logikklassen, die über Jahre gewachsen sind. Der Detektor durchläuft `nkClass`-Knoten; für jede Klasse bestimmt er eine Spanne über min(class-decl-line, first-method-with-prefix-line) .. max(class-decl-children-line, last-method-with-prefix-line). Schwelle 500 Zeilen. Records, Interfaces, Helper und Forward-Deklarationen werden übersprungen. Entspricht Sonar-50-Regel #35.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
// TMainForm with 800 lines of business logic mixed with UI handlers,
// database calls and report generation.
```

### Gut (idiomatische Korrektur)

```pascal
// Extract verticals into focused classes:
TReportRunner   = class ... end;     // own unit
TDataController = class ... end;     // own unit

TMainForm = class(TForm)
  FReport: TReportRunner;
  FData:   TDataController;
end;
```
