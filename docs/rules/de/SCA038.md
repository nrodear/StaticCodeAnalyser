## Beschreibung

Durchsetzung des Style-Guides für projektspezifische Klassenverbote (TQuery, TLabel, wenn ein TStyledLabel vorhanden ist, ...). Der Detektor bleibt still, solange das Projekt nicht `[Components] ForbiddenClasses=...` in analyser.ini setzt.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
object Query1: TQuery   // ForbiddenClasses=TQuery
```

### Gut (idiomatische Korrektur)

```pascal
object FDQuery1: TFDQuery
```
