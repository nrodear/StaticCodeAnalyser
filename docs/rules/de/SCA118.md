# SCA118 — Exception-Klasse ohne `E`-Präfix

> Eine `class(Exception)`-Ableitung sollte der RTL-Konvention `E<Name>` folgen

## Beschreibung

Die Delphi-RTL-Konvention ist eindeutig: Exception-Klassen beginnen mit `E` (EAbort, EConvertError, EAccessViolation). Eigene Exception-Klassen ohne das Präfix brechen die Konvention und verschleiern die Art der Klasse an der Aufrufstelle (`raise MyError.Create(...)` vs. `raise EMyError.Create(...)`). Der Detektor findet jede Klasse, deren TypeRef von einer bekannten Exception-Klasse erbt (Exception, EAbort, EAccessViolation, EExternal) und deren Name nicht mit `E<UpperCase>` beginnt.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
type
  MyError = class(Exception);
```

### Gut (idiomatische Korrektur)

```pascal
type
  EMyError = class(Exception);
```
