## Beschreibung

Der Object-Pascal-Styleguide (Embarcadero DocWiki, Marco Cantu, SonarDelphi) ist eindeutig: Schlüsselwörter werden klein geschrieben. Varianten in gemischter Schreibweise wie `Begin`/`End`/`Procedure` sind Überbleibsel aus der Turbo-Pascal/Delphi-1-Ära und erzeugen Uneinheitlichkeit in modernen Codebasen. SonarDelphi erfasst dasselbe als communitydelphi:LowercaseKeyword.

## Beispiele

### Schlecht (löst die Regel aus)

> Diese Regel meldet mit niedriger Konfidenz: mit der Vorgabe `[Rules] MinConfidence=medium` bleibt das folgende Beispiel unsichtbar. Mit `[Rules] MinConfidence=low` erscheint es.

```pascal
Procedure Foo;
Begin
  If X then DoStuff;
End;
```

### Gut (idiomatische Korrektur)

```pascal
procedure Foo;
begin
  if X then DoStuff;
end;
```
