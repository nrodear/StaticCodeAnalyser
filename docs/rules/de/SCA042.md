# SCA042 — Ereignisbehandler mit zu vielen Bindungen

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Eine einzelne Methode hängt an N oder mehr Komponenten-Ereignissen (Vorgabe N=5)

## Beschreibung

Spaghetti-Indikator: ein Ereignisbehandler, der viele unzusammenhängende Ereignisse bedient, ist schwer zu lesen, schwer zu ändern und hat fast immer Kohäsionsprobleme. Nach Verantwortlichkeit aufteilen. Gemeldet, wenn eine Methode in einer DFM an 5 oder mehr Komponenten-Ereignisse gebunden ist und die Bindungen gemischt sind - verschiedene Komponentenklassen oder verschiedene Ereignisse. Ein Ereignisbehandler, den Komponenten einer Klasse für dasselbe Ereignis teilen (zwölf Farbbuttons mit einem OnClick), ist eine parametrisierte Bündelung und wird nicht gemeldet.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
object Form1: TForm1
  object btnSave: TButton
    OnClick = HandleEverything
  end
  object btnOpen: TButton
    OnClick = HandleEverything
  end
  object btnClose: TButton
    OnClick = HandleEverything
  end
  object edtName: TEdit
    OnChange = HandleEverything
  end
  object edtCity: TEdit
    OnChange = HandleEverything
  end
end
```

### Gut (idiomatische Korrektur)

```pascal
object Form1: TForm1
  object btnSave: TButton
    OnClick = btnSaveClick
  end
  object btnOpen: TButton
    OnClick = btnOpenClick
  end
  object btnClose: TButton
    OnClick = btnCloseClick
  end
  object edtName: TEdit
    OnChange = edtNameChange
  end
  object edtCity: TEdit
    OnChange = edtCityChange
  end
end
```
