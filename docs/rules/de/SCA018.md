## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

Deep nesting hurts readability and indicates the method is doing too much. Use guard clauses (early Exit) or extract inner blocks into helper methods.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
if a then
  if b then
    if c then
      if d then DoStuff;
```

### Gut (idiomatische Korrektur)

```pascal
if not a then Exit;
if not b then Exit;
if not c then Exit;
if d then DoStuff;
```
