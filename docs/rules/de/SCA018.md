# SCA018 — Blockverschachtelung überschreitet die Grenze

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

## Beschreibung

Tiefe Verschachtelung schadet der Lesbarkeit und zeigt, dass die Methode zu viel tut. Guard-Clauses (frühes Exit) verwenden oder innere Blöcke in Hilfsmethoden herausziehen. Ein Block wird gemeldet, wenn seine Tiefe die Grenze überschreitet - bei der Vorgabe 4 wird die fünfte Verschachtelungsebene gemeldet.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
if a then
  if b then
    if c then
      if d then
        if e then DoStuff;
```

### Gut (idiomatische Korrektur)

```pascal
if not a then Exit;
if not b then Exit;
if not c then Exit;
if not d then Exit;
if e then DoStuff;
```
