# SCA099 — Unsymmetrisches begin/end in if/else

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Der then-Zweig nutzt `begin..end`, der else-Zweig ist eine einzelne Anweisung

## Beschreibung

Nutzt der then-Zweig `begin..end`, sollte der else-Zweig das ebenfalls tun (oder beide sollten darauf verzichten). Die gemischte Form (`end else DoStuff;`) lässt einen späteren Leser im Unklaren, ob weitere Anweisungen in den else-Zweig gehören, aber vergessen wurden. `else if` (else-if-Kette) und `else begin` sind ausdrücklich erlaubt. Entspricht SonarDelphi communitydelphi:IfElseBegin.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
if Active then
begin
  DoA;
  DoB;
end
else
  DoC;
```

### Gut (idiomatische Korrektur)

```pascal
if Active then
begin
  DoA;
  DoB;
end
else
begin
  DoC;
end;
```
