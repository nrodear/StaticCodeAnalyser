# SCA099 — Unsymmetrisches begin/end in if/else

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Der then-Zweig nutzt `begin..end`, der else-Zweig ist eine einzelne Anweisung

## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

When the then-branch uses `begin..end`, the else-branch should too (or both should drop it). The mixed form (`end else DoStuff;`) makes a future reader unsure whether more statements belong in the else-branch but were forgotten. `else if` (else-if chain) and `else begin` are explicitly allowed. Matches SonarDelphi communitydelphi:IfElseBegin.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
if Active then
begin
  DoA;
  DoB;
end
else
  DoC;
```

### Gut (idiomatische Korrektur)

```pascal
if Active then
begin
  DoA;
  DoB;
end
else
begin
  DoC;
end;
```
