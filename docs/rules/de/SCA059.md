# SCA059 — Format()-Gleitkommaformat ohne TFormatSettings

> %.2f / %.3f ohne explizite TFormatSettings - die Falle Komma gegen Punkt als Dezimaltrenner

## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

On a DE Windows `Format('%.2f', [3.14])` yields '3,14'; on EN-US it yields '3.14'. For machine-readable output (SQL, JSON, CSV) always pass `TFormatSettings.Invariant`.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
S := Format('%.2f', [Price]);
```

### Gut (idiomatische Korrektur)

```pascal
S := Format('%.2f', [Price], TFormatSettings.Invariant);
```
