# SCA059 — Format()-Gleitkommaformat ohne TFormatSettings

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Bug-red)

> %.2f / %.3f ohne explizite TFormatSettings - die Falle Komma gegen Punkt als Dezimaltrenner

## Beschreibung

Auf einem DE-Windows liefert `Format('%.2f', [3.14])` '3,14', auf EN-US '3.14'. Für maschinenlesbare Ausgabe (SQL, JSON, CSV) immer `TFormatSettings.Invariant` übergeben.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
S := Format('%.2f', [Price]);
```

### Gut (idiomatische Korrektur)

```pascal
S := Format('%.2f', [Price], TFormatSettings.Invariant);
```
