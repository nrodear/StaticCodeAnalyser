# SCA110 — String-Verkettung in der Schleife

## Beschreibung

Jedes `s := s + x` in einem Schleifenrumpf allokiert einen NEUEN String der Länge length(s)+length(x) und kopiert beide Teile hinein. Über N Iterationen sind das O(N^2) Byte-Kopien und Heap-Druck. Zwei idiomatische Alternativen in Delphi: (1) in einen TStringBuilder schreiben und am Ende einmal ToString aufrufen, (2) die Teile in einer TStringList sammeln und .Text einmal lesen. Heuristik des Detektors: lexikalischer Abgleich auf das Muster LHS == erster RHS-Operand (ohne Beachtung der Groß-/Kleinschreibung) in jedem for/while/repeat-Block. Fehlalarme sind möglich, wenn `s` absichtlich als Akkumulator über kurze Schleifen mit kleinen Nutzdaten wiederverwendet wird; mit `// noinspection StringConcatInLoop` unterdrücken.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
for i := 0 to High(Names) do
  s := s + Names[i] + ', ';
```

### Gut (idiomatische Korrektur)

```pascal
var SB := TStringBuilder.Create;
try
  for i := 0 to High(Names) do
    SB.Append(Names[i]).Append(', ');
  s := SB.ToString;
finally SB.Free; end;
```
