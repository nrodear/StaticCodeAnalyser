# SCA112 — FieldByName(...) in der Schleife gerufen

> `DataSet.FieldByName('x').AsXxx` in einer Schleife - lineare Suche je Datensatz

## Beschreibung

FieldByName durchläuft die TFields-Collection bei jedem Aufruf per String-Vergleich. In einer Schleife über ein DataSet wird so aus einem Lookup je Feld N Lookups je .Next, mitunter je Zeile mal N Felder = O(N*M). Die TField-Referenz einmal vor der Schleife zwischenspeichern und direkt lesen/schreiben. Derselbe Lösungsweg wie bei SCA111 (ParamByName) - nur eine andere Collection.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
while not Q.Eof do begin
  Total := Total + Q.FieldByName('Amount').AsCurrency;
  Q.Next;
end;
```

### Gut (idiomatische Korrektur)

```pascal
var Amt := Q.FieldByName('Amount');
while not Q.Eof do begin
  Total := Total + Amt.AsCurrency;
  Q.Next;
end;
```
