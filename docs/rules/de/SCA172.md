# SCA172 — Boolean-Property ohne Is-/Has-/Can-/Should-Präfix

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Der Name der Boolean-Property liest sich als Substantiv - besser ein Verb-Präfix, das sich als Frage liest

## Beschreibung

Eine Boolean-Property, die wie ein Substantiv benannt ist, liest sich an der Aufrufstelle mehrdeutig (`if X.Active then` vs. `if X.IsActive then`). Ein verbartiges Präfix (`Is`/`Has`/`Can`/`Should`/`Will`) bevorzugen, durch das sich die Aufrufstelle natürlich als Frage liest. Der Detektor meldet Boolean-Properties, deren Name nicht mit einem dieser Präfixe beginnt, mit einer eingebauten Whitelist etablierter VCL-Konventionen (Enabled, Visible, Active, Checked, Modified, ReadOnly, Selected, Focused, Loaded, Modified, Dirty, ...).

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
property Ready: Boolean;
```

### Gut (idiomatische Korrektur)

```pascal
property IsReady: Boolean;
```
