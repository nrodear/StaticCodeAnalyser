## Beschreibung

Zwei `private`-Abschnitte (oder `public`/`protected`/`published`) in derselben Klasse mit Membern dazwischen sollten zu einem zusammengefasst werden. Das hilft Reviewern, die Form der Klasse auf einen Blick zu erfassen. Entspricht SonarDelphi communitydelphi:ConsecutiveVisibilitySection. Hinweis: ein leerer Abschnittskopf, auf den ein weiterer Kopf folgt, ist die verwandte, aber eigenständige Regel `EmptyVisibilitySection` (SCA087).

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
type TFoo = class
  private FX: Integer;
  public procedure A;
  private FY: Integer;
  end;
```

### Gut (idiomatische Korrektur)

```pascal
type TFoo = class
  private
    FX, FY: Integer;
  public procedure A;
  end;
```
