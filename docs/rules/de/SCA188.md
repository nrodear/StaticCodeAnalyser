## Beschreibung

Die Datei enthält ein Unicode-Steuerzeichen für bidirektionale Überschreibung oder Isolierung (U+202A-202E, U+2066-2069, U+061C). Damit kann Quelltext einem menschlichen Reviewer anders angezeigt werden, als er kompiliert wird - der Trojan-Source-Angriff (CVE-2021-42574, CWE-1007). In Delphi-Quelltext gibt es dafür keine legitime Verwendung; das Steuerzeichen entfernen.
