# SCA071 — Unit-Section-Keyword nicht in Spalte 1

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> `unit`/`interface`/`uses`/`implementation`/`initialization`/`finalization` sollten in Spalte 1 beginnen

## Beschreibung

Nach Object-Pascal-Konvention stehen die strukturellen Abschnitts-Schlüsselwörter einer Unit bündig links in Spalte 1. Eingerückte Abschnitts-Schlüsselwörter verschleiern beim Überfliegen die Struktur der Unit und können auf falsch gezählte begin/end-Verschachtelung hindeuten. Entspricht SonarDelphi communitydelphi:UnitLevelKeywordIndentation.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
  implementation

  procedure Foo; ...
```

### Gut (idiomatische Korrektur)

```pascal
implementation

procedure Foo; ...
```
