# SCA093 — Mehrere inherited-Aufrufe in einer Methode

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> Zwei oder mehr `inherited;` in derselben Methode - die Seiteneffekte der Basis laufen doppelt

## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

Each `inherited` invocation runs the parent implementation. Two calls fire side-effects (event notifications, refcount updates, log lines) twice. Almost always a copy-paste bug. Matches SonarDelphi communitydelphi:TwiceInheritedCalls.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
procedure Foo;
begin
  inherited;
  DoStuff;
  inherited;
end;
```

### Gut (idiomatische Korrektur)

```pascal
procedure Foo;
begin
  inherited;

end;
```
