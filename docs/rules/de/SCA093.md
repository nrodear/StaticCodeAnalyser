# SCA093 — Mehrere inherited-Aufrufe in einer Methode

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> Zwei oder mehr `inherited;` in derselben Methode - die Seiteneffekte der Basis laufen doppelt

## Beschreibung

Jeder `inherited`-Aufruf führt die Implementierung der Basisklasse aus. Zwei Aufrufe lösen Seiteneffekte (Ereignisbenachrichtigungen, Aktualisierungen des Referenzzählers, Logzeilen) doppelt aus. Fast immer ein Copy-Paste-Fehler. Entspricht SonarDelphi communitydelphi:TwiceInheritedCalls.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
procedure Foo;
begin
  inherited;
  DoStuff;
  inherited;
end;
```

### Gut (idiomatische Korrektur)

```pascal
procedure Foo;
begin
  inherited;
  DoStuff;
end;
```
