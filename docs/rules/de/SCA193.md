## Beschreibung

Ein Bezeichner (Variable, Typ, Routine, ...) enthält ein Nicht-ASCII-Zeichen. Das ist der Homoglyphen- bzw. Confusable-Identifier-Vektor der Trojan-Source-Familie (CVE-2021-42694, CWE-1007): Ein Buchstabe wie das kyrillische U+043E sieht aus wie das lateinische 'o', ist aber ein anderer Bezeichner, sodass zwei Bezeichner identisch aussehen und dennoch unterschiedlich gebunden werden können. Ein legitimer Unicode-Bezeichner ist ebenfalls möglich, daher vor einer Änderung prüfen; ASCII-Bezeichner bevorzugen, wegen der Portabilität und um Verwechslungen zu vermeiden.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
var Login: string;  // one letter is a Cyrillic homoglyph (U+043E), not Latin 'o'
```
