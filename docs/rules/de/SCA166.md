# SCA166 — Uninitialisierte lokale Variable

> Lokale Variable wird vor ihrer ersten Zuweisung in Quelltext-Reihenfolge gelesen oder nie zugewiesen

## Beschreibung

Lokale Variablen nicht verwalteter Typen (Integer, Boolean, Pointer, record, Klasseninstanz) beginnen mit undefiniertem Inhalt. Sie vor einer Zuweisung zu lesen liefert Datenmüll oder eine Access Violation - ein klassischer Absturzfehler. Der Detektor durchläuft die Anweisungen jeder Methode in Quelltext-Reihenfolge und verfolgt für jede lokale Variable den ersten Schreib- und den ersten Lesezugriff: Eine Variable, die gelesen, aber nie geschrieben wird, wird mit hoher Konfidenz gemeldet, ein Lesezugriff vor dem ersten Schreibzugriff in Quelltext-Reihenfolge mit mittlerer Konfidenz. Die Prüfung ist nicht pfadsensitiv - ein Schreibzugriff in einem Zweig zählt für jede Zeile darunter, daher wird `if Cond then L := TStringList.Create; L.Add('x');` nicht gemeldet. Bekannte Schreiber aus der RTL (Read, ReadLn, FillChar, Move, ZeroMemory, Initialize, New, GetMem) werden über eine Allowlist erkannt; andere Aufrufe mit var-/out-Parametern werden pessimistisch als Lesezugriffe behandelt (übersehene Funde, aber keine Fehlalarme). Die automatisch initialisierten verwalteten Typen von Pascal (string, dynamisches Array, interface) werden übersprungen, sofern sie nicht per INI eingeschaltet sind. Methoden über konfigurierbaren Obergrenzen (standardmäßig 200 lokale Variablen / 5000 Anweisungen) werden nicht analysiert, um pathologische Worst-Case-Kosten zu vermeiden.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
function MaxOf(const A: array of Integer): Integer;
var
  I, Best: Integer;
begin
  for I := Low(A) to High(A) do
    if A[I] > Best then      // Best is read before its first assignment
      Best := A[I];
  Result := Best;
end;
```

### Gut (idiomatische Korrektur)

```pascal
function MaxOf(const A: array of Integer): Integer;
var
  I, Best: Integer;
begin
  Best := Low(Integer);
  for I := Low(A) to High(A) do
    if A[I] > Best then
      Best := A[I];
  Result := Best;
end;
```
