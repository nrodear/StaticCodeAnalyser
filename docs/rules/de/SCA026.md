# SCA026 — Hartkodierte DB-Zugangsdaten im DFM

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Vulnerability-darkred)

## Beschreibung

In einer .dfm gespeicherte Datenbank-Zugangsdaten gelangen in die Versionsverwaltung, in Build-Artefakte und in jeden Decompiler. Geheimnisse in Umgebungsvariablen, den Anmeldedatenspeicher des Betriebssystems oder eine verschlüsselte Konfiguration verlagern und zur Laufzeit zuweisen.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
object FDConnection1: TFDConnection
  Params.Strings = ('Password=admin123' 'User_Name=sa')
end
```

### Gut (idiomatische Korrektur)

```pascal
FDConnection1.Params.Values['Password'] := GetEnvironmentVariable('DB_PWD');
```
