## Beschreibung

Doppelte Klammern um einen einzelnen Bezeichner, ein Literal oder einen einfachen Ausdruck bringen nichts - ein einzelnes Paar genügt (oft gar keines). Entspricht SonarDelphi communitydelphi:RedundantParentheses. Nur der Fall des einfachen Ausdrucks wird gemeldet; ein komplexes `((A + B))` kann weiterhin von inneren Klammern für die Rangfolge profitieren und wird nicht gemeldet.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
if ((Active)) then ...
Result := ((42));
```

### Gut (idiomatische Korrektur)

```pascal
if Active then ...
Result := 42;
```
