# SCA103 — Klassenfeld ohne F-Präfix

## Beschreibung

Delphi-Konvention: Instanzfelder einer Klasse heißen `FFoo`, damit der Leser sofort erkennt, dass sie sich auf ein Member der Klasse beziehen (im Gegensatz zu einer lokalen Variable oder einem Parameter). Das Präfix `F` vermeidet Namenskollisionen mit public-Properties (Feld `FFoo` mit Property `Foo` ist das kanonische Paar). Geprüft werden nur `private`- und `protected`-Felddeklarationen - public-/published-Felder erfasst ohnehin `PublicField` (SCA089). Entspricht SonarDelphi communitydelphi:FieldName.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
type TFoo = class
  private
    Counter: Integer;
  end;
```

### Gut (idiomatische Korrektur)

```pascal
type TFoo = class
  private
    FCounter: Integer;
  end;
```
