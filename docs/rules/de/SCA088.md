# SCA088 — Alte Unit-Initialisierung begin..end.

## Beschreibung

Units vor Delphi 2 kennzeichneten ihren Init-Block mit `begin..end.`. Seit Delphi 2 ist die idiomatische Form `initialization..end.`, die sich für symmetrisches Aufräumen mit einem optionalen `finalization`-Block kombinieren lässt. Entspricht SonarDelphi communitydelphi:LegacyInitializationSection.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
// at end of unit:
begin
  RegisterClass(TFoo);
end.
```

### Gut (idiomatische Korrektur)

```pascal
initialization
  RegisterClass(TFoo);
end.
```
