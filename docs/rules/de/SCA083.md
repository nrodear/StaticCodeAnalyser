# SCA083 — Leerer finally-Block

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> `try ... finally end;` räumt nichts auf - entweder füllen oder das finally weglassen

## Beschreibung

Ein leerer `finally`-Block ist fast immer ein vergessenes Aufräumen. Gibt es wirklich nichts aufzuräumen, die `try..finally`-Klammer entfernen. Entspricht SonarDelphi communitydelphi:EmptyFinallyBlock.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
Stream := TFileStream.Create(P);
try
  ...
finally
end;
```

### Gut (idiomatische Korrektur)

```pascal
Stream := TFileStream.Create(P);
try
  ...
finally
  Stream.Free;
end;
```
