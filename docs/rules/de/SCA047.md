## Beschreibung

Gemeldet nur, wenn das Ziel nachweislich ein Speicherplatz ist: eine lokale Variable, ein Parameter, Result, eine Zuweisung an den Funktionsnamen, ein in derselben Unit deklariertes Feld - oder ein Member-Pfad (Pt.Y, R^.iType), dessen Wurzel ein solcher Speicherplatz ist und bei dem jedes Segment ein einfaches Record-Feld ist, aufgelöst über die eigenen Record-Deklarationen der Unit plus eine kuratierte RTL-Liste (TPoint-, TRect-Felder, ...). Property-Ziele bleiben in jeder Position still - das Schreiben auf eine Property führt ihren Setter aus, der den Wert begrenzen, erneut anwenden oder umformatieren kann (TopLine := TopLine begrenzt gegen das in der Größe geänderte Fenster; TRectF.Height := TRectF.Height schreibt Bottom). Indizierte Pfade (a[i]) und Namen, die sich nicht auflösen lassen, bleiben ebenfalls still. Der Kompromiss ist bewusst: unbekannte Formen werden zu falsch Negativen, nie zu Fehlalarmen. Result := Result; zum Stummschalten eines Compiler-Hints wird weiterhin gemeldet und lässt sich mit einem // noinspection-Kommentar direkt über der Zeile unterdrücken.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
FCount := FCount;
```

### Gut (idiomatische Korrektur)

```pascal
FCount := ACount;
```
