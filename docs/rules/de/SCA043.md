# SCA043 — Komponente hat Action und OnClick

> Action und OnClick sind beide gesetzt - Action gewinnt, OnClick ist toter Code

## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

When a TAction is assigned, VCL routes events through the action object and the OnClick never fires. Pick one or call the OnClick body from the action's OnExecute.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
object btnSave: TButton
  Action = actSave
  OnClick = btnSaveClick   // never fires
end
```

### Gut (idiomatische Korrektur)

```pascal
object btnSave: TButton
  Action = actSave   // the action carries the handler
end

// or drop Action and keep OnClick - but not both
```
