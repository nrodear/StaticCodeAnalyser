# SCA133 — Blankes raise außerhalb eines except/on-Handlers

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Bug-red)

> `raise;` ohne Ausnahme-Ausdruck ist nur INNERHALB eines except-Handlers gültig (erneutes Auslösen) - überall sonst lehnen Delphi (E2145) und FPC es ab

## Beschreibung

Ein blankes `raise;` löst die gerade behandelte Ausnahme erneut aus und ist daher nur innerhalb von `except` / `on E: T do` gültig. Delphi lehnt diese Form überall sonst mit dem Compilerfehler E2145 'Re-raising an exception only allowed in exception handler' ab, FPC mit `parser_e_no_reraise_possible` ('Re-raise isn't possible there'). Der Detektor durchläuft den Methoden-AST rekursiv und führt dabei ein Flag `InHandler` mit. Das Flag wird gesetzt, wenn der Durchlauf in `nkExceptBlock` oder `nkOnHandler` absteigt. Ein `nkRaise`-Knoten mit `Name = 'raise'` (blanke Form), der angetroffen wird, während das Flag False ist, erzeugt einen Fund. Blankes `raise;` in `finally`-Blöcken, die selbst außerhalb eines except-Handlers liegen, wird ebenfalls gemeldet. Entspricht Sonar-50-Regel #15 (`RaiseWithoutClass`).

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
procedure Foo(x: Integer);
begin
  if x < 0 then
    raise;             // <- not inside a handler: compiler error E2145
end;
```

### Gut (idiomatische Korrektur)

```pascal
procedure Foo(x: Integer);
begin
  if x < 0 then
    raise EArgumentException.CreateFmt('x = %d (must be >= 0)', [x]);
end;
```
