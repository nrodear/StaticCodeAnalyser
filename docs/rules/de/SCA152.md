# SCA152 — Benutzersichtbarer Text als Literal zugewiesen

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

## Beschreibung

Hartkodierter benutzersichtbarer Text macht die Anwendung ohne Quelltextänderungen unübersetzbar. Der Detektor durchsucht jede Quelltextzeile lexikalisch nach zwei engen Mustern: `<ident>.Caption|Hint|Text := '<text>'` und `ShowMessage|MessageDlg('<text>'`. Der erfasste Text wird nur gemeldet, wenn er (a) mindestens 2 Zeichen lang ist, (b) mindestens einen Buchstaben enthält (schließt einzelne Trennzeichen wie `'-'`, `'.'`, `':'` und numerische Literale aus) und (c) nicht wie ein Ressourcenschlüssel aussieht (nur Großbuchstaben + Unterstriche oder beginnt mit `$`). Zeilenkommentare (`//`) werden übersprungen. Einschränkungen: Treffer auf Nicht-UI-Klassen mit einer Property Caption/Hint/Text (z. B. interne Helfer) können Fehlalarme sein - in diesem Fall den Zeilen-Unterdrückungs-Marker `// noinspection HardcodedString` verwenden. Entspricht Sonar-50-Regel #46 (enge Form, nur UI).

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
Form1.Caption := 'Mein Programm';
Button1.Hint  := 'Klick mich';
ShowMessage('Daten gespeichert');
```

### Gut (idiomatische Korrektur)

```pascal
resourcestring
  SAppCaption = 'Mein Programm';
  SBtnHint    = 'Klick mich';
  SSavedMsg   = 'Daten gespeichert';

Form1.Caption := SAppCaption;
Button1.Hint  := SBtnHint;
ShowMessage(SSavedMsg);
```
