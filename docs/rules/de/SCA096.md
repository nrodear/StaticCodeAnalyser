> Dem Konstruktor fehlt `inherited Create` - die Basis bleibt uninitialisiert

## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

A constructor that does not call `inherited Create(...)` (or `inherited;`) skips parent-class initialization. Parent fields and registrations end up at default/nil state, which leads to follow-up crashes when methods expect the parent to be ready. Matches SonarDelphi communitydelphi:ConstructorWithoutInherited.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
constructor TFoo.Create;
begin
  FX := 0;
end;
```

### Gut (idiomatische Korrektur)

```pascal
constructor TFoo.Create;
begin
  inherited;
  FX := 0;
end;
```
