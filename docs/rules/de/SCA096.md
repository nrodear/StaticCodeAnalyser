# SCA096 — Konstruktor ohne inherited-Aufruf

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> Dem Konstruktor fehlt `inherited Create` - die Basis bleibt uninitialisiert

## Beschreibung

Ein Konstruktor, der `inherited Create(...)` (oder `inherited;`) nicht aufruft, überspringt die Initialisierung der Basisklasse. Felder und Registrierungen der Basisklasse bleiben im Default-/nil-Zustand, was zu Folgeabstürzen führt, wenn Methoden eine einsatzbereite Basisklasse erwarten. Entspricht SonarDelphi communitydelphi:ConstructorWithoutInherited.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
constructor TFoo.Create;
begin
  FX := 0;
end;
```

### Gut (idiomatische Korrektur)

```pascal
constructor TFoo.Create;
begin
  inherited;
  FX := 0;
end;
```
