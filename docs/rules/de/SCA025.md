## Beschreibung

Benutzersichtbare Strings, die in einer .dfm eingebettet sind, lassen sich nicht lokalisieren, nicht A/B-testen und nicht in einem Übersetzungskatalog führen. Beim Aufbau des Formulars aus einem resourcestring oder einer i18n-Hilfsroutine zuweisen. Nicht gemeldet: Captions aus einem einzelnen Zeichen in Symbolschriften (Webdings/Wingdings/Marlett/Symbol - Icons, kein Text), DFM-Werte, die die Formular-Unit aus einem resourcestring ersetzt (tote Platzhalter), und Formulare, deren Unit einen DFM-Übersetzer zur Laufzeit verwendet (gnugettext/dxgettext/JvGnugettext, TranslateComponent, Dev-Cpp MultiLangSupport, cnwizards CnLangMgr, uLocalization*) - dort IST der DFM-Text die msgid-Quelle der i18n-Schicht.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
object btnSave: TButton
  Caption = 'Speichern'
end
```

### Gut (idiomatische Korrektur)

```pascal
btnSave.Caption := _('btn.save');  // i18n at runtime
```
