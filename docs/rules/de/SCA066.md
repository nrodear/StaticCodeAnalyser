# SCA066 — Leere Argumentliste

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> `Foo()` sollte `Foo;` heißen - leere Klammern weglassen

## Beschreibung

Nach Delphi-Konvention werden parameterlose Aufrufe ohne `()` geschrieben. Die C-artige Form `Foo()` fügt Rauschen hinzu, ohne etwas mitzuteilen, und passt nicht zum Rest der Sprache (Prozeduren, Properties und Funktionsreferenzen lassen die Klammern alle weg, wenn es keine Argumente gibt). Entspricht SonarDelphi communitydelphi:EmptyArgumentList.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
MyProc();
Result := MyFunc();
```

### Gut (idiomatische Korrektur)

```pascal
MyProc;
Result := MyFunc;
```
