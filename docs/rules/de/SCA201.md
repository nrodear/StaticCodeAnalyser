## Beschreibung

Eine Konfigurationsdatei im Quellbaum wird wie Code versioniert und ausgeliefert: Eine IP-Adresse darin bindet jeden Checkout und jede Installation an ein Netz, und der Umzug auf einen anderen Server oder in eine andere Umgebung erfordert wieder einen Commit. Umgebungsspezifische Adressen aus der Versionsverwaltung heraushalten (eine Datei je Rechner oder je Umgebung, die Umgebung, ein Deployment-Schritt) oder einen Hostnamen verwenden. Die Regel liest die .ini-Dateien des gescannten Baums - bei Ordner-Scans über denselben Verzeichnisdurchlauf wie die Quellen, bei Projekt-Scans unterhalb der gemeinsamen Wurzel der Projekt-Units; nicht analyser.ini und nicht die Kopien in Plattform-Ausgabeordnern wie Win32 oder Win64 unterhalb der gescannten Wurzel. Zeilen, die mit ';' oder '#' beginnen, sind Kommentare, Abschnittsköpfe (auch mit nachgestelltem Kommentar) werden übersprungen, und der Wert ist alles nach dem ersten '='. Adressgrammatik, Klassen und Ausschlüsse sind die von SCA200; zusätzlich werden Schlüssel, die Fließtext tragen (description, help, hint, comment, caption, text, example, note, title, summary), und Versionsschlüssel nicht gemeldet. Eine Zeile wird mit einem ganzzeiligen Marker '; noinspection HardcodedIpInConfig' (oder '#') direkt darüber unterdrückt, die ganze Datei mit '; noinspection-file HardcodedIpInConfig'.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
[Database]
Server=10.20.30.40
```

### Gut (idiomatische Korrektur)

```pascal
[Database]
Server=db.example.internal
```

## Absichtlich nicht gemeldet

Bei den folgenden Konstrukten schweigt der Detektor absichtlich. Jedes davon ist eine False-Positive-Klasse, die am Realwelt-Korpus gemessen wurde — keine Vermutung.

### Prose and version keys

A key whose words include description, help, hint, comment, caption, text, example, note, title or summary carries text, not a setting - unless the value is a URL or has a port, or the key names a host (HelpServer); a version key (FileVersion, ProductVersion, Build) carries a version unless it names a host (BuildServer). Neither is reported. A host word in the key or the section ([DNS], NameServer) lets a short public address such as 8.8.8.8 count as an address.

```pascal
description=Returns 10.1.2.3 for the lookup  ; not reported
```

### Files that are not read

analyser.ini (the analyser's own settings), .ini files in platform output folders (Win32, Win64, Linux64, OSX64, Android, iOSDevice64 ...), files in test directories and every other format (.conf, .cfg, .json, .xml, .properties) are not part of this rule.

```pascal
Win32\Release\App.ini  ; not read
```
