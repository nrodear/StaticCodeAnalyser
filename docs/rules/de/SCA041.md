# SCA041 — Eingabe-Control direkt auf dem TForm

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Eingabe-Control sitzt auf dem Formular, statt in einem TPanel oder TGroupBox eingebettet zu sein

## Beschreibung

Ein geschichtetes Layout (Form > Panel > Group > Controls) macht Größenänderung, DPI-Skalierung und Theming deutlich einfacher. Controls in einen Layout-Container einbetten. FPC-/Lazarus-Dialekt: diese Regel wird übersprungen, wenn der Scan mit --dialect=fpc (oder einem .lpi-/.lpk-/.lpg-Projekt) läuft - das VCL-Schichtenmodell, das sie prüft, gilt nicht für LCL-Formulare.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
object frmEdit: TForm
  object EdName: TEdit  // direct child of form
```

### Gut (idiomatische Korrektur)

```pascal
object frmEdit: TForm
  object pnlBody: TPanel
    object EdName: TEdit
```
