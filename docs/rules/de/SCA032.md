## Beschreibung

Ein Zyklus im Master-Detail-Graphen verursacht während BeforeOpen oder bei jedem Refresh eine Endlosrekursion und bringt den Prozess per Stacküberlauf zum Absturz. Den Zyklus aufbrechen, indem eine der Verknüpfungen entfernt wird.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
QA.MasterSource = dsB   QB.MasterSource = dsA   // cycle
```

### Gut (idiomatische Korrektur)

```pascal
QB.MasterSource = dsA   // A is the parent, B the detail
// QA has no MasterSource
```
