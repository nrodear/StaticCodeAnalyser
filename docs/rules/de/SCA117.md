# SCA117 — Public-Member ohne Doku-Kommentar

> Public-Methode oder -Property im `interface`-Abschnitt ohne Doku-Kommentar direkt darüber

## Beschreibung

Ein Public-Member im `interface`-Abschnitt einer Unit gehört zur dokumentierten API-Oberfläche, die andere Units verwenden. Fehlende Doku-Kommentare erschweren die Nutzung der Unit, ohne die Implementierung zu lesen. Der Detektor akzeptiert jede dieser Formen direkt über der Deklaration: `///` XMLDoc, einen `{ ... }`-Block, einen `(* ... *)`-Block oder einen oder mehrere einzeilige `//`-Kommentare. Übersprungen: Konstruktoren `Create` / Destruktoren `Destroy` (per Konvention selbsterklärend), Member, die mit `_` beginnen (Private-Markierung in Public-Abschnitten), `published`-Member (DFM/RTTI-getrieben, Doku wäre Rauschen). Unterdrückung: `// noinspection PublicMemberWithoutDoc` je Deklaration.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
type
  TFoo = class
  public
    procedure Run;
  end;
```

### Gut (idiomatische Korrektur)

```pascal
type
  TFoo = class
  public
    /// <summary>Starts the worker.</summary>
    procedure Run;
  end;
```
