## Beschreibung

Ein doppeltes Semikolon (`;;`) bedeutet meist einen übersehenen Tippfehler oder einen versehentlich eingefügten Rest. Compiler behandeln das zweite `;` als leere Anweisung, daher bricht nichts, aber es erzeugt Rauschen. Entspricht SonarDelphi communitydelphi:SuperfluousSemicolon.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
DoStuff;;
```

### Gut (idiomatische Korrektur)

```pascal
DoStuff;
```
