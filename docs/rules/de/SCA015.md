# SCA015 — String-Literal an mehreren Stellen wiederholt

## Beschreibung

Wiederholte Strings sind Gefahren durch Änderungskopplung (ein Tippfehler an einer Stelle weicht still von den anderen ab). In eine const herausziehen, besonders bei Meldungen für den Benutzer. Der Detektor zählt String-Literale mit mindestens 4 Zeichen in den Zuweisungen und Aufrufen einer Datei und meldet ein Literal ab seinem dritten Vorkommen; Literale an anderen Stellen (zum Beispiel in raise-Anweisungen) werden nicht gezählt, ebenso wenig 'true', 'false' und 'null'.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
ShowMessage('File not found');
LogError('File not found');
StatusBar.SimpleText := 'File not found';
```

### Gut (idiomatische Korrektur)

```pascal
const MSG_FILE_NOT_FOUND = 'File not found';
ShowMessage(MSG_FILE_NOT_FOUND);
LogError(MSG_FILE_NOT_FOUND);
StatusBar.SimpleText := MSG_FILE_NOT_FOUND;
```
