## Beschreibung

Verschachtelte try-Blöcke machen den Kontrollfluss von Aufräumen / Fehlerbehandlung schwerer lesbar. Die meisten Fälle lassen sich auflösen, indem die Aufräumschritte umgeordnet oder der innere Block in eine eigene Methode herausgezogen wird. Entspricht SonarDelphi communitydelphi:NestedTry. Der Detektor nutzt eine Tiefen-Heuristik (zählt die Schlüsselwörter `try` gegen `end`) und kann in stark verschachteltem begin/end-Code einige Fehlalarme erzeugen.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
try
  try
    DoStuff;
  finally
    Cleanup;
  end;
except
  Log;
end;
```

### Gut (idiomatische Korrektur)

```pascal
ProtectedDoStuff;  // helper wraps the inner try
```
