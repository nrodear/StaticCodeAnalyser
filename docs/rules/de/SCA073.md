## Beschreibung

Ein Rumpf IFoo = interface end; ohne Methoden oder Properties ist entweder ein Refactoring-Rest oder ein verkapptes Marker-Interface. Marker-Interfaces werden in Delphi besser als Attributklassen modelliert. Entspricht SonarDelphi communitydelphi:EmptyInterface. Nicht gemeldet: ein Interface mit einem *benannten* Vorfahren außer IInterface/IUnknown. Es erbt den Vertrag des Vorfahren und dient als Abfrageschlüssel (Obj as IFileSystemFileSource), als Marker-Ableitung (IOTAFormWizard = interface(IOTARepositoryWizard)), als ObjC/JNI-Brückentyp oder als Automatisierungstyp aus *_TLB.pas - die vorgeschlagene Abhilfe per Attributklasse funktioniert für keinen davon, denn Attribute sind Compile-Zeit-RTTI und lassen sich nicht über QueryInterface abfragen. interface(IUnknown) wird weiterhin gemeldet: es ist semantisch identisch mit interface.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
type IServiceMarker = interface end;
```

### Gut (idiomatische Korrektur)

```pascal
type ServiceMarkerAttribute = class(TCustomAttribute) end;
```

## Absichtlich nicht gemeldet

Bei den folgenden Konstrukten schweigt der Detektor absichtlich. Jedes davon ist eine False-Positive-Klasse, die am Realwelt-Korpus gemessen wurde — keine Vermutung.

### Interface with a named ancestor other than IInterface/IUnknown

The rule's premise - 'carries no contract' - is false here: the interface inherits the ancestor's members and exists as a query key (`Obj as IFileSystemFileSource`), as an Embarcadero-style marker derivation (`IOTAFormWizard = interface(IOTARepositoryWizard)`), as an ObjC/JNI bridge type, or as a `*_TLB.pas` automation type generated from a type library. The suggested fix - model it as an attribute class - does not work for any of them, because attributes are compile-time RTTI and cannot be queried through `QueryInterface`. `IInterface`/`IUnknown` are NOT exempt: `IFoo = interface(IUnknown) end;` is semantically identical to `IFoo = interface end;`, since IInterface is the implicit default ancestor.

```pascal
// not reported - refines an existing contract
IFileSystemFileSource = interface(IFileSource)
  ['{4CBD5A32-...}']
end;

// still reported - no ancestor contract to inherit
IServiceMarker = interface(IUnknown)
end;
```
