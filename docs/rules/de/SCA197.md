## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

An interface without a GUID exists only at compile time. Both Supports(Obj, IFoo, X) and Obj.QueryInterface(IFoo, X) resolve the interface through its GUID, so neither compiles against a GUID-less interface - and the error surfaces at the call site, often in a different unit and long after the interface was written. Delphi generates a fresh GUID with Ctrl+Shift+G while the cursor sits inside the interface declaration. Detection is lexical: the declaration `IFoo = interface` (optionally with an ancestor list) is followed by the optional GUID in square brackets. Forward declarations (`IFoo = interface;`) are skipped because they may not carry a GUID at all, and dispinterface types are outside this rule.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
type
  IReportWriter = interface
    procedure Write(const AText: string);
  end;

// elsewhere - does not compile:
if Supports(Obj, IReportWriter, W) then
```

### Gut (idiomatische Korrektur)

```pascal
type
  IReportWriter = interface
    ['{4F2C1A80-91D3-4E7B-B0A6-6C3E1D9F2B54}']
    procedure Write(const AText: string);
  end;
```

## Absichtlich nicht gemeldet

Bei den folgenden Konstrukten schweigt der Detektor absichtlich. Jedes davon ist eine False-Positive-Klasse, die am Realwelt-Korpus gemessen wurde — keine Vermutung.

### Forward declaration

`IFoo = interface;` announces the name so a later declaration can reference it. The compiler REFUSES a GUID here, so demanding one would be asking for code that does not build.

```pascal
IFoo = interface;   // not reported
```

### dispinterface

An OLE automation interface is dispatched by DISPID, not by GUID lookup through QueryInterface. Different mechanism, different rules.

```pascal
IFoo = dispinterface   // not reported
```

### Square brackets that do not contain a GUID

If the bracket holds something other than the 8-4-4-4-12 form - a constant, a macro, a typo - neither 'missing' nor 'duplicate' is decidable. The rule stays silent rather than guess.

```pascal
IFoo = interface [SOME_GUID_CONST]   // not reported
```
