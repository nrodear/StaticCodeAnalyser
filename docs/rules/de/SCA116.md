# SCA116 — TLS-Prüfung abgeschaltet

## Beschreibung

Drei Delphi-Muster schalten die TLS-Prüfung stillschweigend ab: (a) `SecureProtocols := []` entfernt jedes Protokoll und erlaubt den Rückfall auf Klartext oder das schwächste verfügbare Protokoll, (b) `IgnoreCertificateErrors := True` akzeptiert jedes Zertifikat, auch abgelaufene und selbstsignierte, (c) `OnVerifyPeer := nil` schließt den Prüf-Callback kurz. Alle drei sind attraktiv für MITM-Angriffe. Ersetzen durch explizit nur moderne Protokolle (`[TLSv1_2, TLSv1_3]`), einen echten Trust Store oder einen OnVerifyPeer-Handler mit Fingerprint-Pinning. Der Detektor findet die drei Muster der Property-Zuweisung lexikalisch.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
Client.SecureProtocols := [];
Client.IgnoreCertificateErrors := True;
```

### Gut (idiomatische Korrektur)

```pascal
Client.SecureProtocols := [TLSv1_2, TLSv1_3];
Client.OnVerifyPeer := VerifyPinnedFingerprint;
```
