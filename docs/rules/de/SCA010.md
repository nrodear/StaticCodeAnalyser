> Ganzzahl-Division (div / mod) durch eine Variable, die null sein kann

## Beschreibung

Die rechte Seite eines Integer-div oder -mod ist ein Parameter oder eine lokale Variable ohne vorherige Absicherung gegen null; zur Laufzeit löst das EDivByZero aus. Erkannte Absicherungen: eine if-Bedingung wie `Count <> 0`, `Count > 0` oder `Count >= 1` vor der Division, `if Count = 0 then Exit` (oder raise), eine for-Schleifenvariable, die bei 1 oder höher beginnt, und ein Divisor, dem nur Werte ungleich null zugewiesen werden. Ein Literal `div 0` / `mod 0` wird immer gemeldet. Den Gleitkomma-Operator / prüft diese Regel nicht.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
function Average(Total, Count: Integer): Integer;
begin
  Result := Total div Count;   // EDivByZero when Count = 0
end;
```

### Gut (idiomatische Korrektur)

```pascal
function Average(Total, Count: Integer): Integer;
begin
  if Count = 0 then
    Exit(0);
  Result := Total div Count;
end;
```
