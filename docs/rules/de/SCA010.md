## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

Right-hand side of div, mod, or / is a variable without prior guard against zero. Integer division crashes with EDivByZero, float division silently produces Inf/NaN.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
result := total / count;
```

### Gut (idiomatische Korrektur)

```pascal
if count <> 0 then result := total / count;
```
