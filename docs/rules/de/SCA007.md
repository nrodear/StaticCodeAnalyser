# SCA007 — Ungenutzte Unit in der uses-Klausel

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

## Beschreibung

Heuristik: sucht nach irgendeinem Bezeichner aus der eingebundenen Unit. Fehlalarme sind möglich bei Units, die nur Klassen registrieren / über initialization-Abschnitte globalen Zustand initialisieren.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
uses ..., MyUnusedHelper, ...;
```

### Gut (idiomatische Korrektur)

```pascal
uses
  System.SysUtils, Vcl.Forms;

// Or, if it must stay (initialization side effect, class registration):
uses
  System.SysUtils, Vcl.Forms,
  MyUnusedHelper;   // registers its classes in its initialization section
```
