# SCA165 — Ungenutzter noinspection-Marker

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Ein `// noinspection X` unterdrückt an seiner Zielzeile keinen Fund - entweder ist der Detektor besser geworden oder das Ziel war falsch

## Beschreibung

Der Unterdrückungsfilter (uSuppression) erfasst jeden Kommentar `// noinspection KindName` und die nächste Codezeile, auf die er zielt. Nachdem alle Detektoren fertig sind, prüft der Filter, welche Marker tatsächlich einen Fund unterdrückt haben. Marker, die nie gegriffen haben, werden als fkUnusedSuppression an der Marker-Zeile gemeldet - der Marker ist zu entfernen (die Weiterentwicklung des Detektors hat ihn überflüssig gemacht) oder es ist zu prüfen, ob der Kind-Name des Ziels falsch war. Robust gegen übersehene Funde: Nur Marker mit einer eindeutigen Zielzeile, die kein Kommentar ist, werden berücksichtigt (Marker am Dateiende oder in reinen Doc-Kommentarblöcken werden ignoriert). Profilabhängig: Im default-Profil erscheint dieser Hinweis; Meldungen zur Unterdrückungs-Hygiene ohne Detektor-Rauschen liefert ein Lauf mit --profile selftest-quiet.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
// noinspection MemoryLeak
WriteLn('hello');   // no leak here - suppression never fires
```

### Gut (idiomatische Korrektur)

```pascal
// (Marker entfernt - das Tool flaggt diese Zeile nicht mehr.)
WriteLn('hello');
```
