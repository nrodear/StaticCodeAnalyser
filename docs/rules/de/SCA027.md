# SCA027 — Doppelte (DataSource, DataField)-Bindung

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> Zwei oder mehr Controls binden dasselbe Paar aus DataSource und DataField

## Beschreibung

Wenn der Benutzer ein gebundenes Control bearbeitet, erhält das zweite eine parallele Aktualisierung vom Dataset - race-anfällige, schwer zu debuggende Überschreibungen. Jedes (DataSource, DataField) an genau ein Control binden.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
DBEdit1.DataField = 'NAME'
DBEdit2.DataField = 'NAME'   // same DataSource
```

### Gut (idiomatische Korrektur)

```pascal
DBEdit1.DataField = 'NAME'
DBEdit2.DataField = 'FIRSTNAME'
```
