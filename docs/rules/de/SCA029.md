# SCA029 — Verwaister Ereignisbehandler

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Published-Methode in TNotifyEvent-Form hat keine DFM-Bindung

## Beschreibung

Die Methode sieht aus wie ein Ereignisbehandler (Sender: TObject), aber keine .dfm referenziert sie - Bindungen von Collection-Items (item ... OnAction = Foo, z. B. WebModule-Actions oder Plugin-Befehlslisten) zählen als Referenzen. Bekannte Grenzen: Ereignisbehandler, die nur in einer Vorfahren-DFM außerhalb des Scans gebunden oder im Code zugewiesen werden, werden weiterhin gemeldet. Vermutlich ein Überbleibsel eines gelöschten Controls - entfernen oder anbinden.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
procedure TForm1.btnOldClick(Sender: TObject);  // nothing binds this
begin
  ...
end;
```

### Gut (idiomatische Korrektur)

```pascal
object btnOld: TButton
  OnClick = btnOldClick
end

// or delete the method - an unbound handler is never called
```
