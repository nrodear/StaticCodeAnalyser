## Beschreibung

Zahlenliterale, die direkt in die Geschäftslogik eingebettet sind, tragen keine Bedeutung: `if RetryCount > 3` zwingt jeden Leser zu raten, wofür die 3 steht, und zwingt bei jeder Wartungsänderung dazu, jedes Vorkommen von Hand zu finden. Eine benannte Konstante herausziehen, damit der Wert einen dokumentierten Zweck und genau eine maßgebliche Quelle hat. Der Detektor überspringt Trivialwerte (0, 1, 2, -1, gängige Zweierpotenz-Größen, Indizierung in bekanntermaßen winzige Collections) - die aktive Liste steht in [Detectors] MagicNumberTrivials. Schleifengrenzen gegen `Length(arr)` und der Array-Index 0 werden ebenfalls ignoriert. Über die globale Konfiguration lassen sich projektspezifische Trivialwerte ergänzen (z. B. eine feste PageSize).

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
if RetryCount > 3 then ...
```

### Gut (idiomatische Korrektur)

```pascal
const MAX_RETRIES = 3;
if RetryCount > MAX_RETRIES then ...
```
