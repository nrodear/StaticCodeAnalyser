## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

Mismatched placeholders cause EConvertError at runtime. Detector handles RTL Format (%s/%d/...) and mORMot bare-% style (FormatUtf8/FormatString).

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
Format('%s is %d', [Name]);   // <-- Age missing
```

### Gut (idiomatische Korrektur)

```pascal
Format('%s is %d', [Name, Age]);
```
