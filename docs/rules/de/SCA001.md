# SCA001 — Objekt ohne ausnahmesichere Freigabe erzeugt

## Beschreibung

Meldet vier Varianten. (1) never-freed: das Objekt wird überhaupt nie freigegeben - Warnung. (2) freed-outside-finally: ein Free ist vorhanden, steht aber außerhalb des schützenden try/finally, sodass jede Ausnahme innerhalb des Blocks ein Leck erzeugt - Warnung. (3) return-value-not-freed: eine Funktion gibt ein frisch erzeugtes Objekt zurück, und der Aufrufer gibt es nie frei - Hinweis. (4) proven-leak: nie freigegeben UND die Variable verlässt die Methode nachweislich nie (kein Aufrufargument, kein Zuweisungsziel, kein Konstruktor-Argument mit Owner-Verdacht, kein Interface-Typ) - die einzige Variante, die als Fehler gemeldet wird. Zu welcher Variante ein Fund gehört, steht in properties.variant in der SARIF-Ausgabe und im Lösungshinweis, den die Oberfläche zeigt; der Meldungstext selbst trägt nur den Variablennamen.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
list := TStringList.Create;
DoStuff(list);   // <-- exception here leaks list
```

### Gut (idiomatische Korrektur)

```pascal
list := TStringList.Create;
try
  DoStuff(list);
finally
  list.Free;
end;
```
