# SCA001 — Objekt ohne try/finally erzeugt

## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

TObject.Create (or LeakyClass.Create) without a protective try/finally block leaks the instance when subsequent code raises an exception. The Free call must run regardless of how the protected block exits.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
list := TStringList.Create;
DoStuff(list);   // <-- exception here leaks list
```

### Gut (idiomatische Korrektur)

```pascal
list := TStringList.Create;
try
  DoStuff(list);
finally
  list.Free;
end;
```
