## Beschreibung

Vorgabenamen verbergen die Absicht und vereiteln Find-Usages-/Umbenennungs-Refactorings. UI-Controls so umbenennen, dass sie ihren Zweck vermitteln (btnSave, edUserName, pnlToolbar ...).

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
object Button1: TButton
  Caption = 'Save'
end
```

### Gut (idiomatische Korrektur)

```pascal
object btnSave: TButton
  Caption = 'Save'
end
```
