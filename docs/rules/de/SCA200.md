# SCA200 — IP-Adresse als String-Literal

## Beschreibung

Eine in den Quelltext geschriebene IP-Adresse bindet das Programm an ein Netz: Jeder Umzug auf einen anderen Server, in eine andere Umgebung (Entwicklung, Test, Produktion) oder zu einem anderen Kunden erfordert eine Codeänderung und einen neuen Build, und die Adresse verrät jedem, der das Binary liest, die interne Topologie. Die Adresse aus der Konfiguration, der Kommandozeile oder der Umgebung lesen oder einen Hostnamen verwenden, den DNS je Umgebung auflöst. Die Regel liest nur String-Literale - nie Kommentare - und erkennt IPv4 in strikter Dotted-Decimal-Form (vier Oktette 0-255, keine führenden Nullen) und IPv6 in jeder Form nach RFC 4291, einschließlich Zone (%eth0), eckiger Klammern mit Port ([...]:443) und eingebetteter IPv4 (::ffff:10.1.2.3). Gemeldet werden private Adressen (RFC 1918, Unique Local fc00::/7), geteilte Adressen (100.64.0.0/10) und öffentliche Adressen. Nicht gemeldet werden Loopback, unspezifizierte Adressen (0.0.0.0, ::), Broadcast, Netzmasken, Link-Local, die Dokumentationsbereiche (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24, 2001:db8::/32, 3fff::/20), IETF-Protokollblöcke, Benchmarking (198.18.0.0/15), Multicast und reservierte Bereiche. Test-Units (Benennung und Verzeichnisse test/spec) werden übersprungen. Eine Adresse in einer http://-URL wird auch von SCA115 gemeldet: Die beiden Regeln beschreiben verschiedene Probleme, Klartext-Transport und eine feste Adresse.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
Client.Host := '10.20.30.40';
```

### Gut (idiomatische Korrektur)

```pascal
Client.Host := Settings.ReadString('Server', 'Host', 'localhost');
```

## Absichtlich nicht gemeldet

Bei den folgenden Konstrukten schweigt der Detektor absichtlich. Jedes davon ist eine False-Positive-Klasse, die am Realwelt-Korpus gemessen wurde — keine Vermutung.

### Version numbers, OIDs and product versions

Four-part numbers are often not addresses. An identifier ending in a version keyword (FileVersion, ServerVersion), another version keyword in the identifiers of the line (Ver, Build, Revision, Release, Assembly) without a host word beside it (BuildServer and ConnectionString are hosts), a version keyword directly before the number in the text ('Version 2.1.0.45'), an OID arc (2.5.x.x, 1.3.6.x, 1.3.14.x, 1.3.101.x) or an OID name, a product prefix ('Chrome/', '\', '-') and a public address of version form (all octets up to 31, the first up to 20) without a host word or port in the line are not reported. An address in a URL, behind a UNC prefix ('\\10.0.0.5\share') or with a port is always a host.

```pascal
Ide.verProc := '1.0.0.0';  // not reported
```

### Range bounds and number columns

An IPv4 ending in .0 or .255 and an IPv6 prefix with a zero interface ID (fd12:3456::/48), each without a port and outside a URL, are network or broadcast bounds (ranges, CIDR blocks), not hosts. A literal holding two more decimal fractions and no URL or port is a number column (SVG paths, measurements).

```pascal
Ranges: array[0..1] of string = ('10.0.0.0', '10.255.255.255');  // not reported
```

### Known limits

Addresses assembled from parts ('10.0.' + '0.1', #46), numeric forms (TIPAddress.Create(10, 0, 0, 1), $0A000001) and the content of Delphi 12 multi-line strings (''') are not read. Form files (.dfm/.lfm/.fmx) are not part of this rule.

```pascal
Host := '10.0.' + '0.1';  // not reported
```
