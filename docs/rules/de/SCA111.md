# SCA111 — ParamByName(...) in der Schleife gerufen

> `Query.ParamByName('x').AsXxx := ...` in einer Schleife - lineare Suche je Durchlauf

## Beschreibung

ParamByName durchläuft die TParam-Collection bei jedem Aufruf per String-Vergleich (linear in der Zahl der Parameter). In einem Hot-Path / einer Schleife wird so aus einem ParamByName je Query.Execute N je Execute. Die TParam-Referenz einmal außerhalb der Schleife zwischenspeichern oder die per Integer indizierte Property Params[i] verwenden, wenn die Position des Parameters bekannt ist.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
for i := 0 to High(Ids) do begin
  Q.ParamByName('id').AsInteger := Ids[i];
  Q.ExecSQL;
end;
```

### Gut (idiomatische Korrektur)

```pascal
var P := Q.ParamByName('id');
for i := 0 to High(Ids) do begin
  P.AsInteger := Ids[i];
  Q.ExecSQL;
end;
```
