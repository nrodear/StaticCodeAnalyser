> Length oder .Count mit Subtraktion - Unterlauf des vorzeichenlosen Typs, wenn leer

## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

`Length(s) - 1` on an empty string evaluates to 0 - 1 = MaxUInt under NativeUInt arithmetic and indexes into garbage. Guard for emptiness or cast to NativeInt.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
Last := s[Length(s) - 1];
```

### Gut (idiomatische Korrektur)

```pascal
if Length(s) >= 2 then Last := s[Length(s) - 1];
```
