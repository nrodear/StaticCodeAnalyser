## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

Reaching across forms to grab a child control breaks encapsulation - any rename in Form2 silently breaks Form1. Expose a property or method on Form2 instead.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
Form2.EdName.Text := 'x';
```

### Gut (idiomatische Korrektur)

```pascal
Form2.UserName := 'x';   // property on Form2
```
