## Beschreibung

SQL per 'WHERE x=' + operand zu bauen ermöglicht SQL-Injection, wenn dieser Operand nicht vertrauenswürdig ist. Der Detektor meldet die VERKETTUNG - er verfolgt nicht, woher der Operand stammt, daher ist ein Fund ein Prüfhinweis, kein Beweis für eine Schwachstelle. Verkettungen nur aus Literalen, Integer-Formatmasken und bekannte Sanitizer sind bereits ausgenommen. Stattdessen parametrisierte Abfragen verwenden (Params.ParamByName(...).Value := ...).

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
Query.SQL.Text := 'SELECT * FROM Users WHERE Name=''' + UserName + '''';
```

### Gut (idiomatische Korrektur)

```pascal
Query.SQL.Text := 'SELECT * FROM Users WHERE Name=:n';
Query.ParamByName('n').AsString := UserName;
```
