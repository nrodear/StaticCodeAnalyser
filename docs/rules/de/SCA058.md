# SCA058 — UPDATE / DELETE / TRUNCATE ohne WHERE

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Bug-red)

> SQL-Anweisung ändert jede Zeile - die WHERE-Klausel fehlt

## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

`UPDATE Users SET Active=0` without WHERE flips every row in the table. Same for `DELETE FROM ...` and `TRUNCATE TABLE ...`. Production-disaster waiting to happen.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
Q.SQL.Text := 'UPDATE Users SET Active=0';
```

### Gut (idiomatische Korrektur)

```pascal
Q.SQL.Text := 'UPDATE Users SET Active=0 WHERE Id=:id';
```
