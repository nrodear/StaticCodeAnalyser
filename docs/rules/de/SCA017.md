## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

WriteLn / ShowMessage / OutputDebugString / OutputDebugStringA in non-test code is almost always leftover debugging: ShowMessage in particular blocks the UI thread and is unfit for any production code path. Replace with a structured logger (TLogger, mORMot TSynLog, log4d) so the call site captures severity, category, and source location, and ops can dial verbosity at runtime. NOTE: since its first release this rule has promised to skip units under test path segments (`tests`, `test`) and test/cli units (`*Console*`, `*TestProject*`) - that skip is NOT implemented; measured 2026-09-04, 861 of 2832 corpus findings lie in such units. Implementing the skip is tracked as its own package; until it lands every unit is reported. A `// noinspection DebugOutput` marker suppresses individual lines (e.g. interactive CLI banners).
