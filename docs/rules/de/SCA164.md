# SCA164 — Routine auf oberster Ebene wird nie gerufen

## Beschreibung

Schließt die Lücke zwischen SCA147 (UnusedPrivateMethod - nur private Klassenmethoden) und der Familie der Sichtbarkeitsprüfungen SCA148+ (nur public Klassen-Member). Erkennt Routinen auf oberster Ebene (keine Klassenmethoden), deren Name nirgends in derselben Unit als Aufruf vorkommt, Selbstreferenzen ausgenommen (eine rekursive Routine, die nur sich selbst aufruft, wird trotzdem gemeldet - entspricht dem Verhalten von SonarDelphi UnusedRoutineCheck). Schutz vor Fehlalarmen: Konstruktoren und Destruktoren (nicht direkt als Prozedur aufrufbar), die Direktiven `override`/`virtual; abstract`/`message`/`dynamic` (Dispatch über Klassengrenzen oder durch das System), die IDE-Bootstrap-Prozedur `Register`, das Enumerator-Trio (`MoveNext`/`GetEnumerator`/`Current` - implizit von `for-in` aufgerufen) sowie jede Routine, die im interface-Abschnitt der Unit vorwärtsdeklariert ist (möglicher Nutzer in einer anderen Unit). Der Umfang ist eine einzelne Datei - Aufrufer von Routinen des interface-Abschnitts in anderen Units werden in diesem MVP nicht verfolgt, daher werden diese bewusst übersprungen. Mit `// noinspection UnusedRoutine` unterdrücken, wenn die Routine absichtlich erhalten bleibt (Aufruf über RTTI, von Attributen genutzt, per Plugin geladen). Entspricht SonarDelphi UnusedRoutineCheck.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
implementation
procedure InternalHelper;     // never called

  WriteLn('hi');
end;
end.
```

### Gut (idiomatische Korrektur)

```pascal
implementation

// or move it to interface if it should be exported
```
