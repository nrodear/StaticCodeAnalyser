## Beschreibung

> Dieser Abschnitt liegt nur auf Englisch vor. Übersetzt sind Name und Kurzbeschreibung; die Volltexte folgen der englischen Fassung.

VCL serialisation tolerates duplicate TabOrder but tab navigation becomes order-of-declaration dependent and unpredictable for the user. Renumber so TabOrder is unique per parent.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
EdA.TabOrder = 0
EdB.TabOrder = 0   // same parent
```

### Gut (idiomatische Korrektur)

```pascal
EdA.TabOrder = 0
EdB.TabOrder = 1
```
