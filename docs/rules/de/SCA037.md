# SCA037 — Doppelte TabOrder unter Geschwistern

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Zwei Geschwister-Controls im selben Parent teilen sich denselben TabOrder-Wert

## Beschreibung

Die VCL-Serialisierung toleriert doppelte TabOrder, aber die Tab-Navigation hängt dann von der Deklarationsreihenfolge ab und wird für den Benutzer unvorhersehbar. Neu nummerieren, sodass TabOrder je Parent eindeutig ist.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
EdA.TabOrder = 0
EdB.TabOrder = 0   // same parent
```

### Gut (idiomatische Korrektur)

```pascal
EdA.TabOrder = 0
EdB.TabOrder = 1
```
