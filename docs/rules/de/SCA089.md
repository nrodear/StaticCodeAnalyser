> Ein public-Feld bricht die Kapselung - eine Property verwenden

## Beschreibung

Ein public-Feld legt den zugrunde liegenden Speicher offen; Aufrufer können ihn ändern, ohne dass die Klasse es bemerkt. Eine Property lässt der Klasse die Möglichkeit, später Validierung/Normalisierung zu ergänzen, ohne Aufrufer zu brechen. Entspricht SonarDelphi communitydelphi:PublicField.

## Beispiele

### Schlecht (löst die Regel aus)

```pascal
type TFoo = class
  public
    Count: Integer;
  end;
```

### Gut (idiomatische Korrektur)

```pascal
type TFoo = class
  private
    FCount: Integer;
  public
    property Count: Integer read FCount write FCount;
  end;
```
