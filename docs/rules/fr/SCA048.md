# SCA048 — Appel virtuel dans le constructeur

> Méthode virtuelle appelée depuis le constructeur - la classe dérivée voit un Self à moitié initialisé

## Description

C++ FAQ 23.5 / *Effective Java* item 17 sous forme Delphi : un appel virtuel dans un constructeur exécute la redéfinition la plus dérivée avant que les champs de la classe dérivée soient initialisés. Reporter le travail dans un hook non virtuel exécuté après la construction.

## Exemples

### Mauvais (déclenche la règle)

```pascal
constructor TBase.Create;
begin
  Configure;   // virtual
end;
```

### Bon (correction idiomatique)

```pascal
constructor TBase.Create;
begin
  // skip virtual call
end;
procedure TBase.AfterConstruction;
begin
  Configure;
end;
```
