# SCA024 — Composant au nom par défaut

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Le composant porte encore le nom par défaut de l'assistant (Button1, Edit3, Panel2 ...)

| **Étiquettes** | `dfm`, `naming` |

## Description

Les noms par défaut masquent l'intention et cassent la recherche des utilisations / les refactorings de renommage. Renommer les contrôles d'interface pour qu'ils expriment leur rôle (btnSave, edUserName, pnlToolbar ...).

## Exemples

### Mauvais (déclenche la règle)

```pascal
object Button1: TButton
  Caption = 'Save'
end
```

### Bon (correction idiomatique)

```pascal
object btnSave: TButton
  Caption = 'Save'
end
```
