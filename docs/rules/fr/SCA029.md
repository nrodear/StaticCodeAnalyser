## Description

La méthode ressemble à un gestionnaire d'événement (Sender: TObject) mais aucun .dfm ne la référence - les liaisons d'éléments de collection (item ... OnAction = Foo, p. ex. les actions de WebModule ou les listes de commandes de plugin) comptent comme références. Limites connues : les gestionnaires liés uniquement dans un DFM ancêtre hors de l'analyse, ou affectés dans le code, sont tout de même signalés. Probablement un reste d'un contrôle supprimé - le supprimer ou le câbler.

## Exemples

### Mauvais (déclenche la règle)

```pascal
procedure TForm1.btnOldClick(Sender: TObject);  // nothing binds this
begin
  ...
end;
```

### Bon (correction idiomatique)

```pascal
object btnOld: TButton
  OnClick = btnOldClick
end

// or delete the method - an unbound handler is never called
```
