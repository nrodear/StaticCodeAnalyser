# SCA062 — Ligne de source trop longue

> La ligne dépasse 120 caractères - couper ou extraire une sous-expression

## Description

Les lignes de plus de 120 caractères ne tiennent pas dans une revue de code côte à côte standard (2*120+marge) et débordent d'un tiers d'écran 16:9. La valeur par défaut de SonarDelphi et les guides de style Sun/Java s'accordent sur 120. La limite est configurable via [Detectors] MaxLineLength (120 par défaut).
