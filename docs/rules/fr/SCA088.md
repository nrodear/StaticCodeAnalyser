# SCA088 — Initialisation d'unit à l'ancienne begin..end.

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Utiliser `initialization..end.` plutôt que l'ancien `begin..end.`

## Description

Avant Delphi 2, les unités marquaient leur bloc d'initialisation avec `begin..end.`. Depuis Delphi 2, la forme idiomatique est `initialization..end.`, qui peut être associée à un bloc `finalization` facultatif pour un nettoyage symétrique. Correspond à SonarDelphi communitydelphi:LegacyInitializationSection.

## Exemples

### Mauvais (déclenche la règle)

```pascal
// at end of unit:
begin
  RegisterClass(TFoo);
end.
```

### Bon (correction idiomatique)

```pascal
initialization
  RegisterClass(TFoo);
end.
```
