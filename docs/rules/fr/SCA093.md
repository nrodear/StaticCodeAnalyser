# SCA093 — Plusieurs appels inherited dans une méthode

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> Deux `inherited;` ou plus dans la même méthode - les effets de bord du parent s'exécutent deux fois

## Métadonnées

## Description

Chaque invocation de `inherited` exécute l'implémentation du parent. Deux appels déclenchent les effets de bord (notifications d'événement, mises à jour du compteur de références, lignes de journal) deux fois. Presque toujours un bug de copier-coller. Correspond à SonarDelphi communitydelphi:TwiceInheritedCalls.

## Exemples

### Mauvais (déclenche la règle)

```pascal
procedure Foo;
begin
  inherited;
  DoStuff;
  inherited;
end;
```

### Bon (correction idiomatique)

```pascal
procedure Foo;
begin
  inherited;
  DoStuff;
end;
```
