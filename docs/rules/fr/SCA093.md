# SCA093 — Plusieurs appels inherited dans une méthode

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> Deux `inherited;` ou plus dans la même méthode - les effets de bord du parent s'exécutent deux fois

## Description

> Cette section n'existe qu'en anglais. Le nom et la description courte sont traduits ; les textes complets suivent la version anglaise.

Each `inherited` invocation runs the parent implementation. Two calls fire side-effects (event notifications, refcount updates, log lines) twice. Almost always a copy-paste bug. Matches SonarDelphi communitydelphi:TwiceInheritedCalls.

## Exemples

### Mauvais (déclenche la règle)

```pascal
procedure Foo;
begin
  inherited;
  DoStuff;
  inherited;
end;
```

### Bon (correction idiomatique)

```pascal
procedure Foo;
begin
  inherited;
  DoStuff;
end;
```
