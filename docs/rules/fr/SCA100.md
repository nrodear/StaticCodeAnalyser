# SCA100 — Alias de type pointeur sans préfixe P

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> `Foo = ^Bar` devrait s'écrire `PBar = ^Bar` (convention du préfixe P)

## Description

Convention Delphi depuis le premier jour : un alias de pointeur sur `TXxx` se nomme `PXxx`. Le préfixe `P` rend l'indirection visible au site d'appel. Correspond à SonarDelphi communitydelphi:PointerName. Le framework de nommage rendra plus tard le préfixe configurable.

## Exemples

### Mauvais (déclenche la règle)

```pascal
type TIntPtr = ^Integer;
```

### Bon (correction idiomatique)

```pascal
type PInteger = ^Integer;
```
