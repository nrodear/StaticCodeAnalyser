## Description

Le fichier source est en UTF-16 (LE ou BE). Il compile, mais un source UTF-16 est inhabituel et pose des difficultés aux outils texte (git diff, grep, hooks externes, revue de code). La convention est l'UTF-8 avec BOM. Sous le dialecte FPC (--dialect=fpc ou un projet Lazarus), le résultat est signalé à la place comme ERREUR avec une confiance élevée : Free Pascal rejette les sources UTF-16, le fichier ne compile pas du tout.
