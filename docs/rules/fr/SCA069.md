## Description

Delphi 10.4+ accepte `_` comme séparateur de chiffres dans les littéraux numériques. Les constantes comme les délais (1_800_000 ms = 30 min), les tailles de fichier (1_048_576 = 1 MiB), les montants en centimes et autres sont nettement plus lisibles avec un groupement explicite. Le seuil est de 5 chiffres (codé en dur ; `[Detectors] DigitGroupingThreshold` est prévu). Les littéraux hexadécimaux et flottants sont exclus (autre convention). Correspond à SonarDelphi communitydelphi:DigitGrouping.

> Cette règle signale avec une confiance faible : avec la valeur par défaut `[Rules] MinConfidence=medium`, l'exemple ci-dessous reste masqué. Avec `[Rules] MinConfidence=low`, il apparaît.

