# SCA015 — Littéral chaîne répété a plusieurs endroits

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Duplication-blueviolet)

> Le même littéral chaîne apparaît au moins 3 fois dans un fichier - extraire vers une constante

## Description

Les chaînes répétées créent un risque de couplage au changement (une faute de frappe à un endroit diverge silencieusement des autres). Les extraire dans une const, en particulier pour les messages destinés à l'utilisateur. Le détecteur compte les littéraux de chaîne d'au moins 4 caractères dans les affectations et les appels d'un fichier et signale un littéral à partir de sa troisième occurrence ; les littéraux situés ailleurs (par exemple dans les instructions raise) ne sont pas comptés, pas plus que 'true', 'false' et 'null'.

## Exemples

### Mauvais (déclenche la règle)

```pascal
ShowMessage('File not found');
LogError('File not found');
StatusBar.SimpleText := 'File not found';
```

### Bon (correction idiomatique)

```pascal
const MSG_FILE_NOT_FOUND = 'File not found';
ShowMessage(MSG_FILE_NOT_FOUND);
LogError(MSG_FILE_NOT_FOUND);
StatusBar.SimpleText := MSG_FILE_NOT_FOUND;
```
