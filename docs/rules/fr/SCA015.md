# SCA015 — Littéral chaîne répété a plusieurs endroits

## Description

> Cette section n'existe qu'en anglais. Le nom et la description courte sont traduits ; les textes complets suivent la version anglaise.

Repeated strings are change-coupling hazards (typo in one place silently diverges from the others). Extract to a const, especially for user-facing messages. The detector counts string literals of at least 4 characters in the assignments and calls of one file and reports a literal from its third occurrence on; literals elsewhere (for example in raise statements) are not counted, nor are 'true', 'false' and 'null'.

## Exemples

### Mauvais (déclenche la règle)

```pascal
ShowMessage('File not found');
LogError('File not found');
StatusBar.SimpleText := 'File not found';
```

### Bon (correction idiomatique)

```pascal
const MSG_FILE_NOT_FOUND = 'File not found';
ShowMessage(MSG_FILE_NOT_FOUND);
LogError(MSG_FILE_NOT_FOUND);
StatusBar.SimpleText := MSG_FILE_NOT_FOUND;
```
