# SCA054 — Paramètre de méthode inutilisé

## Description

Un paramètre formel est déclaré mais jamais lu dans le corps de la méthode. Le paramètre encombre le site d'appel (chaque appelant passe une valeur sans effet) et occulte les véritables dépendances de la méthode. Refactoring : supprimer le paramètre, ou faire passer le site d'appel par une autre surcharge qui ne le prend pas. Le détecteur ignore volontairement les signatures imposées de l'extérieur : `override` (la signature du parent est fixée), les corps de remplacement `; virtual; abstract`, les implémentations d'interface (signature dictée par l'interface), les gestionnaires d'événement (`Sender: TObject` et le reste du tuple d'événement) et les méthodes enregistrées comme gestionnaires d'événement DFM. Masquer par méthode avec `// noinspection UnusedParameter` pour les callbacks à forme stable (RTTI/streaming).

## Exemples

### Mauvais (déclenche la règle)

```pascal
procedure Process(const Data: TData; Mode: Integer);  // Mode never referenced
```

### Bon (correction idiomatique)

```pascal
procedure Process(const Data: TData);
```
