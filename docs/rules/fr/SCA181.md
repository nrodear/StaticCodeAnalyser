# SCA181 — Attribut DUnitX [Category] sans nom de catégorie

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Bug-red)

> [Category] sans argument est une erreur de compilation dans DUnitX - toujours passer un nom de catégorie

## Description

L'attribut [Category] de DUnitX exige un argument chaîne qui sert à regrouper les tests pour une exécution sélective. Sans cet argument, le compilateur lève une erreur de paramètre manquant. Toujours passer un nom de catégorie explicite (p. ex. 'Slow', 'CI-only', 'Integration').

## Exemples

### Mauvais (déclenche la règle)

```pascal
[Category]
procedure Foo;
```

### Bon (correction idiomatique)

```pascal
[Category('Slow')]
procedure Foo;
```
