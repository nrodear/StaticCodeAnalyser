# SCA108 — TThread.Synchronize depuis le destructeur

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> Synchronize() appelé depuis le destructeur Destroy - un thread qui se libère lui-même y reste bloqué jusqu'à ce que le thread principal exécute l'appel, et se fige s'il ne le fait pas

## Description

TThread.Synchronize() dans le corps d'un destructeur est fragile. Quand le destructeur s'exécute dans le thread principal, Synchronize appelle simplement la méthode directement. Quand il s'exécute dans le thread de travail lui-même - le cas habituel avec FreeOnTerminate := True, où le thread se libère lui-même après Execute - Synchronize bloque le thread de travail jusqu'à ce que le thread principal traite l'appel. Si le thread principal ne traite pas les demandes de synchronisation à ce moment-là (par exemple parce qu'il attend le thread avec WaitForSingleObject au lieu de TThread.WaitFor, ou parce que l'application est en cours de fermeture), les deux threads s'attendent mutuellement et le processus se fige. Pendant la fermeture, les objets que l'appel touche peuvent aussi avoir déjà disparu. Déplacer la notification dans un gestionnaire OnTerminate (il s'exécute dans le thread principal avant la libération de l'objet thread) ou à la fin de Execute. Basé sur l'AST : parcourt chaque nkMethod dont le nom se termine par '.Destroy' (ou dont le TypeRef porte le marqueur 'destructor') et signale les nkCall vers 'Synchronize' / '<obj>.Synchronize'.

## Exemples

### Mauvais (déclenche la règle)

```pascal
destructor TWorker.Destroy;
begin
  Synchronize(procedure begin Form1.Log('done') end);  // worker blocks until the main thread runs this
  inherited;
end;
```

### Bon (correction idiomatique)

```pascal
procedure TWorker.WorkerTerminated(Sender: TObject);  // in the constructor:
begin                                                 //   OnTerminate := WorkerTerminated;
  Form1.Log('done');   // OnTerminate runs in the main thread, before Destroy
end;

destructor TWorker.Destroy;
begin
  inherited;   // no Synchronize here
end;
```
