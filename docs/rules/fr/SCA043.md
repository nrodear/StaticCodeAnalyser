# SCA043 — Le composant a Action et OnClick

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> Action et OnClick sont tous deux définis - Action l'emporte, OnClick est du code mort

## Description

> Cette section n'existe qu'en anglais. Le nom et la description courte sont traduits ; les textes complets suivent la version anglaise.

When a TAction is assigned, VCL routes events through the action object and the OnClick never fires. Pick one or call the OnClick body from the action's OnExecute.

## Exemples

### Mauvais (déclenche la règle)

```pascal
object btnSave: TButton
  Action = actSave
  OnClick = btnSaveClick   // never fires
end
```

### Bon (correction idiomatique)

```pascal
object btnSave: TButton
  Action = actSave   // the action carries the handler
end

// or drop Action and keep OnClick - but not both
```
