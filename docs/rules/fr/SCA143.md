# SCA143 — L'unité n'a pas de commentaire d'en-tête descriptif

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

## Description

Un court commentaire d'en-tête entre la déclaration `unit ...;` et le mot-clé `interface` indique aux futurs mainteneurs à quoi sert l'unité - objectif, périmètre, invariants importants, appartenance. Le détecteur lit les premières lignes du fichier, trouve les marqueurs `unit` et `interface` et vérifie qu'au moins une ligne de commentaire (`//`, `{...}` ou `(* ... *)`) se trouve entre eux. La sévérité est Conseil, car de nombreuses unités héritées omettent l'en-tête sans conséquence fonctionnelle. Correspond à la règle Sonar-50 #48.

## Exemples

### Mauvais (déclenche la règle)

```pascal
unit MyUnit;

interface

uses ...;
```

### Bon (correction idiomatique)

```pascal
unit MyUnit;

// Database-connection pool: wraps FireDAC TFDConnection setup
// for the report subsystem. Thread-safe; single instance per app.

interface

uses ...;
```
