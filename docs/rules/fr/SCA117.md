# SCA117 — Membre public sans commentaire de documentation

> Méthode ou propriété publique dans la section `interface` sans commentaire de documentation juste au-dessus

## Description

Un membre public dans la section `interface` d'une unité fait partie de la surface d'API documentée que consomment les autres unités. Sans commentaires de documentation, l'unité est plus difficile à utiliser sans lire l'implémentation. Le détecteur accepte au choix : un XMLDoc `///`, un bloc `{ ... }`, un bloc `(* ... *)`, ou un ou plusieurs commentaires `//` d'une ligne directement au-dessus de la déclaration. Exclusions : constructeurs `Create` / destructeurs `Destroy` (explicites par convention), membres commençant par `_` (marqueur de privé dans les sections publiques), membres `published` (pilotés par DFM/RTTI, la doc serait du bruit). Masquage : `// noinspection PublicMemberWithoutDoc` par déclaration.

## Exemples

### Mauvais (déclenche la règle)

```pascal
type
  TFoo = class
  public
    procedure Run;
  end;
```

### Bon (correction idiomatique)

```pascal
type
  TFoo = class
  public
    /// <summary>Starts the worker.</summary>
    procedure Run;
  end;
```
