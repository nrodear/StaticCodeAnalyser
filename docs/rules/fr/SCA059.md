# SCA059 — Format flottant dans Format() sans TFormatSettings

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Bug-red)

> %.2f / %.3f sans TFormatSettings explicite - le piège du séparateur décimal virgule ou point

## Description

Sur un Windows DE, `Format('%.2f', [3.14])` donne « 3,14 » ; sous EN-US, il donne « 3.14 ». Pour une sortie lisible par machine (SQL, JSON, CSV), toujours passer `TFormatSettings.Invariant`.

## Exemples

### Mauvais (déclenche la règle)

```pascal
S := Format('%.2f', [Price]);
```

### Bon (correction idiomatique)

```pascal
S := Format('%.2f', [Price], TFormatSettings.Invariant);
```
