# SCA071 — Mot-clé de section d'unit qui n'est pas en colonne 1

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> `unit`/`interface`/`uses`/`implementation`/`initialization`/`finalization` doivent commencer en colonne 1

## Description

La convention Object Pascal veut que les mots-clés de section structurels d'une unité soient alignés à gauche en colonne 1. Des mots-clés de section indentés brouillent la structure de l'unité à la lecture rapide et peuvent indiquer une imbrication begin/end mal comptée. Correspond à SonarDelphi communitydelphi:UnitLevelKeywordIndentation.

## Exemples

### Mauvais (déclenche la règle)

```pascal
  implementation

  procedure Foo; ...
```

### Bon (correction idiomatique)

```pascal
implementation

procedure Foo; ...
```
