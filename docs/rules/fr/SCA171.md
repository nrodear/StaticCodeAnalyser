# SCA171 — Directive de compilation OFF sans ON correspondant dans le fichier

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> {$WARNINGS OFF} (ou HINTS/RANGECHECKS/...) sans ON de fermeture - déborde sur les units suivantes

## Description

Les directives d'état du compilateur Delphi comme {$WARNINGS OFF}, {$HINTS OFF}, {$RANGECHECKS OFF}, {$BOOLEVAL OFF}, {$OVERFLOWCHECKS OFF} modifient l'état du compilateur pour tout ce qui est compilé après elles. Si le OFF n'est pas suivi d'un ON de fermeture dans le même fichier, l'aiguillage déborde sur toutes les unités de compilation suivantes du même build et supprime avertissements/conseils/contrôles bien au-delà de la portée voulue. Le détecteur compte les OFF et les ON par nom de directive dans le fichier et signale toute directive dont les OFF sont plus nombreux que les ON en fin de fichier.

## Exemples

### Mauvais (déclenche la règle)

```pascal
{$WARNINGS OFF}
procedure Foo;
begin
end;
```

### Bon (correction idiomatique)

```pascal
{$WARNINGS OFF}
procedure Foo;
begin
end;
{$WARNINGS ON}
```
