# SCA113 — TThread.Resume est obsolète

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> `MyThread.Resume` - utiliser `MyThread.Start` (depuis Delphi 2010)

## Description

TThread.Resume est obsolète depuis Delphi 2010 au profit de TThread.Start (suspension à la création + reprise au démarrage sont devenues un seul appel Start explicite). Le compilateur émet un avertissement d'obsolescence, mais il passe facilement inaperçu dans les grandes bases de code. Deux corrections : (a) appeler .Start au lieu de .Resume, (b) construire avec CreateSuspended := False et omettre entièrement l'étape Resume/Start. Le détecteur signale les appels `<ident>.Resume`. Quand le type du receveur est visible dans le même fichier (`X: TFoo` ou `X := TFoo.Create`), il doit être TThread, se terminer par `Thread` ou dériver de TThread dans ce fichier - les autres types (timers, animations, TProcess) sont ignorés. Un receveur non résolu est signalé, sauf pour une chaîne pointée ou une variable inline dont le nom ou l'initialiseur ne mentionne pas 'thread'. Si un receveur signalé n'est pas un TThread, masquer ligne par ligne avec `// noinspection ThreadResumeDeprecated`.

## Exemples

### Mauvais (déclenche la règle)

```pascal
MyThread := TWorkerThread.Create(True);
MyThread.Resume;
```

### Bon (correction idiomatique)

```pascal
MyThread := TWorkerThread.Create(True);
MyThread.Start;
```
