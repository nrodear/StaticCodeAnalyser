# SCA139 — Free sans mise à nil ensuite

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> `obj.Free;` sans `obj := nil;` (ni FreeAndNil) laisse un pointeur pendant - toute utilisation ultérieure est un Use-After-Free

| **Kind** | `FreeWithoutNil` |

## Description

Après `obj.Free`, la variable pointe toujours vers la mémoire libérée. Tout déréférencement ultérieur est un Use-After-Free, au mieux une violation d'accès, au pire une corruption silencieuse. Le détecteur parcourt les nœuds `nkCall` dont le nom correspond à `<ident>.Free` ou `<ident>.Destroy`, puis parcourt vers l'avant la même méthode à la recherche d'un `<ident> := nil` ou `FreeAndNil(<ident>)` ultérieur. Si aucun des deux n'existe, l'appel est signalé - dans une méthode aussi lorsqu'il s'agit du dernier appel : un champ survit à la méthode, et un contrôle `Assigned` ultérieur ou le destructeur touche de la mémoire libérée (dans un constructeur, Delphi exécute le destructeur à chaque exception). Une routine autonome qui libère une variable globale en dernier appel (nettoyage en fin de programme ou de script) n'est pas signalée, sauf si un `raise` suit. Les variables locales, les constantes inline et les paramètres `const` sont ignorés (ils sortent de portée), de même que les destructeurs, `BeforeDestruction`, `DoFree`, `FinalizeClass`, les gestionnaires OnDestroy et les routines autonomes `Finalize*` (l'instance, la classe ou le programme se termine avec eux). `Self`/`Result`/`inherited` comme receveurs sont exclus, car ils suivent d'autres modèles de cycle de vie. Correspond à la règle Sonar-50 #25.

## Exemples

### Mauvais (déclenche la règle)

```pascal
L := TStringList.Create;
try
  L.Add('x');
finally
  L.Free;             // <- L still points at freed memory
end;
WriteLn(L.Count);     // Use-After-Free
```

### Bon (correction idiomatique)

```pascal
L := TStringList.Create;
try
  L.Add('x');
finally
  FreeAndNil(L);      // L is nil; further use raises loudly
end;
```
