# SCA051 — Le membre public pourrait être protected

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Membre public référencé uniquement depuis des classes dérivées, jamais de l'extérieur

## Description

Analyse d'un seul fichier : chaque appelant visible du membre public est lui-même une méthode d'une classe dérivée de la classe déclarante. `protected` est la visibilité minimale qui satisfait tous les points d'appel actuels et signale l'intention de conception (« ceci est un point d'extension, pas une partie de l'API destinée aux consommateurs »). Même réserve liée à l'analyse d'un seul fichier que pour CanBeUnitPrivate / CanBeStrictPrivate : les consommateurs situés dans d'autres unités sont invisibles pour le détecteur ; le compilateur vérifie le refactoring via E2361 s'il existe un appelant étranger. Exclus : membres published / exposés par RTTI, racines virtual/override qui font partie de la hiérarchie documentée. Restreindre en toute confiance au sein du projet déclarant ; pour les API de bibliothèque livrées, vérifier d'abord manuellement les appelants externes.

## Exemples

### Mauvais (déclenche la règle)

> Cette règle signale avec une confiance faible : avec la valeur par défaut `[Rules] MinConfidence=medium`, l'exemple ci-dessous reste masqué. Avec `[Rules] MinConfidence=low`, il apparaît.

```pascal
type
  TBase = class
  public
    procedure Hook;          // only called from TSub
  end;
  TSub = class(TBase)
  public
    procedure Run;
  end;

procedure TBase.Hook;
begin
end;

procedure TSub.Run;
begin
  Hook;
end;
```
