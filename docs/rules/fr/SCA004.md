# SCA004 — Identifiant / jeton d'API en dur

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Vulnerability-darkred)

## Description

Les identifiants présents dans le code source finissent dans le contrôle de version, les artefacts de build, les décompilateurs et les traces de pile. Déplacer les secrets vers des variables d'environnement, le magasin d'identifiants du système d'exploitation ou une configuration chiffrée.

## Exemples

### Mauvais (déclenche la règle)

```pascal
Password := 'admin123';
```

### Bon (correction idiomatique)

```pascal
Password := GetEnvironmentVariable('DB_PASSWORD');
```
