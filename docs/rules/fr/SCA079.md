# SCA079 — Sections const/type/var consécutives

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Deux blocs `const`, `type` ou `var` qui se suivent devraient être fusionnés

## Description

`const A = 1; const B = 2;` devrait s'écrire `const A = 1; B = 2;` - un seul mot-clé de section peut toutes les déclarer. De même pour `type` et `var`. Réunit SonarDelphi communitydelphi:ConsecutiveConstSection / :ConsecutiveTypeSection / :ConsecutiveVarSection en une seule règle. Le type de section figure dans le message.

## Exemples

### Mauvais (déclenche la règle)

> Cette règle signale avec une confiance faible : avec la valeur par défaut `[Rules] MinConfidence=medium`, l'exemple ci-dessous reste masqué. Avec `[Rules] MinConfidence=low`, il apparaît.

```pascal
const A = 1;
const B = 2;
```

### Bon (correction idiomatique)

```pascal
const
  A = 1;
  B = 2;
```
