## Description

> Cette section n'existe qu'en anglais. Le nom et la description courte sont traduits ; les textes complets suivent la version anglaise.

Trailing space/tab at end of line creates phantom diff lines whenever an editor with 'trim trailing whitespace on save' touches the file. SonarDelphi tracks the same as communitydelphi:TrailingWhitespace.

## Exemples

### Mauvais (déclenche la règle)

```pascal

```

### Bon (correction idiomatique)

```pascal

```
