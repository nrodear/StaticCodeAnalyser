## Description

Une espace ou une tabulation en fin de ligne crée des lignes de diff fantômes dès qu'un éditeur avec « trim trailing whitespace on save » touche le fichier. SonarDelphi suit la même chose sous communitydelphi:TrailingWhitespace.
