# SCA140 — La méthode a trop d'instructions Exit

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Une méthode avec plus de 6 appels à Exit a trop de chemins de sortie - difficile à lire, difficile à tester, facile d'en oublier un

## Métadonnées

| Champ | Valeur |
|---|---|
| **Identifiant de règle** | `SCA140` |
| **Kind** | `MultipleExit` |
| **Sévérité par défaut** | Warning |
| **Type** | Code Smell |
| **Unité du détecteur** | `uMultipleExit.pas` |
| **Étiquettes** | `control-flow`, `maintainability`, `sonar50` |

## Description

Plusieurs retours anticipés sont utiles pour les clauses de garde, mais au-delà d'un petit nombre ils fragmentent tant le flot de contrôle que les futurs mainteneurs manquent des conditions. Le détecteur compte les descendants `nkExit` de chaque `nkMethod` et signale une méthode qui en a plus de 6 : 6 instructions Exit restent silencieuses, 7 sont signalées. Le seuil est fixé dans le détecteur (`MAX_EXITS`). Les instructions Exit des routines imbriquées et des méthodes anonymes ne comptent pas. Options de refactorisation : regrouper les gardes en un seul `if (... or ... or ...) then Exit;`, passer des retours anticipés à une variable de retour unique, ou extraire la logique interne dans une méthode auxiliaire. Correspond à la règle Sonar-50 #34.

## Exemples

### Mauvais (déclenche la règle)

```pascal
function Find(Id: Integer): TUser;
begin
  if Id < 0 then begin Result := nil; Exit; end;
  if not Db.Connected then begin Result := nil; Exit; end;
  if Db.IsLocked(Id) then begin Result := nil; Exit; end;
  if Db.IsDeleted(Id) then begin Result := nil; Exit; end;
  if Db.IsArchived(Id) then begin Result := nil; Exit; end;
  if not Cache.Has(Id) then begin Result := DbLoad(Id); Exit; end;
  Result := Cache.Get(Id);
  Exit;                              // 7th Exit
end;
```

### Bon (correction idiomatique)

```pascal
function Find(Id: Integer): TUser;
begin
  Result := nil;
  if (Id < 0) or not Db.Connected then Exit;
  if Db.IsLocked(Id) or Db.IsDeleted(Id) or Db.IsArchived(Id) then Exit;
  if Cache.Has(Id) then
    Result := Cache.Get(Id)
  else
    Result := DbLoad(Id);
end;
```
