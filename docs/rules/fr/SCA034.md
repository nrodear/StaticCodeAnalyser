> Un TField avec Required=True n'a aucun contrôle de saisie lié

## Description

> Cette section n'existe qu'en anglais. Le nom et la description courte sont traduits ; les textes complets suivent la version anglaise.

A required field that the user cannot reach makes every insert fail with 'Field X must have a value'. Either bind a control or drop the Required=True.

## Exemples

### Mauvais (déclenche la règle)

```pascal
FieldDefs: Email Required=True   // no DBEdit / DBLookup bound to it
```

### Bon (correction idiomatique)

```pascal
(bind a DBEdit to the Email field)
```
