# SCA034 — Champ obligatoire sans liaison d'interface

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> Un TField avec Required=True n'a aucun contrôle de saisie lié

## Métadonnées

| Champ | Valeur |
|---|---|
| **Identifiant de règle** | `SCA034` |
| **Kind** | `DfmRequiredFieldUnbound` |
| **Sévérité par défaut** | Warning |
| **Type** | Bug |
| **Unité du détecteur** | `uDfmRequiredField.pas` |
| **Étiquettes** | `dfm`, `ux`, `required-field` |

## Description

Un champ obligatoire que l'utilisateur ne peut pas atteindre fait échouer chaque insertion avec 'Field X must have a value'. Lier un contrôle ou retirer le Required=True.

## Exemples

### Mauvais (déclenche la règle)

```pascal
FieldDefs: Email Required=True   // no DBEdit / DBLookup bound to it
```

### Bon (correction idiomatique)

```pascal
object edtEmail: TDBEdit
  DataSource = dsPerson
  DataField = 'Email'
end
```
