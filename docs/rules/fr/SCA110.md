# SCA110 — Concaténation de chaîne dans une boucle

> `s := s + x` dans for/while/repeat - réallocations quadratiques

## Description

Chaque `s := s + x` dans le corps d'une boucle alloue une NOUVELLE chaîne de longueur length(s)+length(x) et y copie les deux morceaux. Sur N itérations, cela fait O(N^2) copies d'octets et une pression sur le tas. Deux alternatives idiomatiques en Delphi : (1) construire dans un TStringBuilder et appeler ToString une seule fois à la fin, (2) collecter les morceaux dans une TStringList et lire .Text une seule fois. Heuristique du détecteur : correspondance lexicale sur le motif LHS == premier opérande RHS (insensible à la casse) dans tout bloc for/while/repeat. Faux positifs possibles si `s` est volontairement réutilisé comme accumulateur dans de courtes boucles à très petites charges ; masquer avec `// noinspection StringConcatInLoop`.

## Exemples

### Mauvais (déclenche la règle)

```pascal
for i := 0 to High(Names) do
  s := s + Names[i] + ', ';
```

### Bon (correction idiomatique)

```pascal
var SB := TStringBuilder.Create;
try
  for i := 0 to High(Names) do
    SB.Append(Names[i]).Append(', ');
  s := SB.ToString;
finally SB.Free; end;
```
