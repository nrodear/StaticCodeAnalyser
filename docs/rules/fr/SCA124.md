# SCA124 — Constructeur appelé sur une instance au lieu de la classe

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> `obj.Create` - appelle le constructeur comme méthode sur une instance existante, saute l'allocation et réinitialise les champs par-dessus des données vivantes

## Description

Delphi permet d'appeler un constructeur sur une instance, p. ex. `obj.Create;`, mais le résultat n'est presque jamais celui voulu. Appelé comme méthode de classe (`TFoo.Create`), le runtime alloue d'abord un nouveau bloc mémoire via `TObject.NewInstance`, initialise le pointeur de VMT, puis exécute le corps du constructeur. Appelé sur une instance existante, le chemin d'allocation est entièrement sauté - seul le corps du constructeur s'exécute, ce qui réinitialise les champs (`FList := TList.Create;` écrase le `FList` précédent sans le libérer, les références de types managés sont écrasées, les valeurs par défaut effacent ce que l'appelant avait positionné). Le résultat est au mieux un bug de logique, au pire une corruption mémoire. Heuristique du détecteur (aucun résolveur de types disponible) : compare `nkCall.Name` à `<Ident>.Create[(<args>)][;]` où `<Ident>` commence par une lettre minuscule (clairement une variable selon la convention Delphi, puisque les types utilisent le préfixe `T<Upper>` / `I<Upper>`). Ignore `Self`, `Result`, `Inherited`, les chemins à plusieurs points (`A.B.Create` - ambigu), les formes de transtypage (`T(x).Create`), les noms de classes et les receveurs qui suivent la convention de nommage des métaclasses (suffixe d'identificateur `Class`, p. ex. `itemClass: TFooClass`). Accepte un faible risque connu de faux positif pour les variables en minuscules de type `TClass` nommées autrement (rare en pratique). Rétrogradation provisoire de la sévérité Erreur -> Avertissement (2026-07-25) : un audit sur le corpus complet a mesuré 100 % de faux positifs au niveau Erreur ; reste Avertissement jusqu'à l'arrivée de gardes structurelles de résolution de types. Correspond à `InstanceInvokedConstructorCheck` de Sonar-Delphi.

## Exemples

### Mauvais (déclenche la règle)

```pascal
procedure Reset;
var list: TStringList;
begin
  list := TStringList.Create;
  ...
  list.Create;            // no allocation, re-initialises the existing object
end;
```

### Bon (correction idiomatique)

```pascal
procedure Reset;
var list: TStringList;
begin
  list := TStringList.Create;
  ...
  list.Clear;             // or FreeAndNil + new TStringList.Create
end;
```
