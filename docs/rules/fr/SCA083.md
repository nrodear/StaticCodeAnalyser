# SCA083 — Bloc finally vide

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> `try ... finally end;` ne libère rien - compléter ou supprimer le finally

## Description

Un bloc `finally` vide est presque toujours un nettoyage oublié. S'il n'y a vraiment rien à nettoyer, supprimer l'enveloppe `try..finally`. Correspond à SonarDelphi communitydelphi:EmptyFinallyBlock.

## Exemples

### Mauvais (déclenche la règle)

```pascal
Stream := TFileStream.Create(P);
try
  ...
finally
end;
```

### Bon (correction idiomatique)

```pascal
Stream := TFileStream.Create(P);
try
  ...
finally
  Stream.Free;
end;
```
