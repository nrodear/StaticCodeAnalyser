# SCA064 — Mot-clé Pascal pas en minuscules

> Les mots-clés Pascal (`begin`/`end`/`procedure`/...) doivent être en minuscules

## Description

Le guide de style Object Pascal (Embarcadero DocWiki, Marco Cantu, SonarDelphi) est sans ambiguïté : les mots-clés s'écrivent en minuscules. Les variantes à casse mixte comme `Begin`/`End`/`Procedure` sont des restes de l'époque Turbo-Pascal/Delphi-1 et créent des incohérences dans les bases de code modernes. SonarDelphi suit la même chose sous communitydelphi:LowercaseKeyword.

## Exemples

### Mauvais (déclenche la règle)

> Cette règle signale avec une confiance faible : avec la valeur par défaut `[Rules] MinConfidence=medium`, l'exemple ci-dessous reste masqué. Avec `[Rules] MinConfidence=low`, il apparaît.

```pascal
Procedure Foo;
Begin
  If X then DoStuff;
End;
```

### Bon (correction idiomatique)

```pascal
procedure Foo;
begin
  if X then DoStuff;
end;
```
