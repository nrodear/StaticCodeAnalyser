# SCA200 — Adresse IP en littéral de chaîne

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Security%20Hotspot-orange)

## Description

Une adresse IP écrite dans le source lie le programme à un réseau : chaque passage à un autre serveur, à un autre environnement (développement, test, production) ou à un autre client exige une modification du code et un nouveau build, et l'adresse révèle la topologie interne à quiconque lit le binaire. Lire l'adresse depuis la configuration, la ligne de commande ou l'environnement, ou utiliser un nom d'hôte que le DNS résout selon l'environnement. La règle ne lit que les littéraux de chaîne - jamais les commentaires - et reconnaît l'IPv4 sous forme décimale pointée stricte (quatre octets 0-255, sans zéros de tête) et l'IPv6 sous toutes les formes de la RFC 4291, y compris une zone (%eth0), des crochets avec un port ([...]:443) et une IPv4 incorporée (::ffff:10.1.2.3). Sont signalées les adresses privées (RFC 1918, unique local fc00::/7), les adresses partagées (100.64.0.0/10) et les adresses publiques. Ne sont pas signalés : loopback, adresse non spécifiée (0.0.0.0, ::), broadcast, masques de réseau, link-local, les plages de documentation (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24, 2001:db8::/32, 3fff::/20), les blocs de protocole de l'IETF, le benchmarking (198.18.0.0/15), le multicast et l'espace réservé. Les unités de test (nommage et répertoires test/spec) sont ignorées. Une adresse dans une URL http:// est aussi signalée par SCA115 : les deux règles décrivent des problèmes différents, le transport en clair et une adresse fixe.

## Exemples

### Mauvais (déclenche la règle)

```pascal
Client.Host := '10.20.30.40';
```

### Bon (correction idiomatique)

```pascal
Client.Host := Settings.ReadString('Server', 'Host', 'localhost');
```

## Volontairement non signalé

Le détecteur garde volontairement le silence sur les constructions ci-dessous. Chacune est une classe de faux positifs mesurée sur le corpus réel — ce n'est pas une supposition.

### Version numbers, OIDs and product versions

Four-part numbers are often not addresses. An identifier ending in a version keyword (FileVersion, ServerVersion), another version keyword in the identifiers of the line (Ver, Build, Revision, Release, Assembly) without a host word beside it (BuildServer and ConnectionString are hosts), a version keyword directly before the number in the text ('Version 2.1.0.45'), an OID arc (2.5.x.x, 1.3.6.x, 1.3.14.x, 1.3.101.x) or an OID name, a product prefix ('Chrome/', '\', '-') and a public address of version form (all octets up to 31, the first up to 20) without a host word or port in the line are not reported. An address in a URL, behind a UNC prefix ('\\10.0.0.5\share') or with a port is always a host.

```pascal
Ide.verProc := '1.0.0.0';  // not reported
```

### Range bounds and number columns

An IPv4 ending in .0 or .255 and an IPv6 prefix with a zero interface ID (fd12:3456::/48), each without a port and outside a URL, are network or broadcast bounds (ranges, CIDR blocks), not hosts. A literal holding two more decimal fractions and no URL or port is a number column (SVG paths, measurements).

```pascal
Ranges: array[0..1] of string = ('10.0.0.0', '10.255.255.255');  // not reported
```

### Known limits

Addresses assembled from parts ('10.0.' + '0.1', #46), numeric forms (TIPAddress.Create(10, 0, 0, 1), $0A000001) and the content of Delphi 12 multi-line strings (''') are not read. Form files (.dfm/.lfm/.fmx) are not part of this rule.

```pascal
Host := '10.0.' + '0.1';  // not reported
```
