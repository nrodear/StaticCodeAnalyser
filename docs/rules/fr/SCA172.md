# SCA172 — Propriété booléenne sans préfixe Is / Has / Can / Should

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Le nom de la propriété booléenne se lit comme un substantif - préférer un préfixe verbal qui se lit comme une question

## Description

Une propriété booléenne nommée comme un substantif se lit de façon ambiguë aux points d'appel (`if X.Active then` contre `if X.IsActive then`). Préférer un préfixe verbal (`Is`/`Has`/`Can`/`Should`/`Will`) qui fait lire naturellement le point d'appel comme une question. Le détecteur signale les propriétés booléennes dont le nom ne commence pas par l'un de ces préfixes, avec une liste blanche intégrée de conventions VCL établies (Enabled, Visible, Active, Checked, Modified, ReadOnly, Selected, Focused, Loaded, Modified, Dirty, ...).

## Exemples

### Mauvais (déclenche la règle)

```pascal
property Ready: Boolean;
```

### Bon (correction idiomatique)

```pascal
property IsReady: Boolean;
```
