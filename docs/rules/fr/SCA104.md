# SCA104 — Type classe ou record sans préfixe T

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Les alias de type classe et record doivent commencer par `T`

## Description

Convention Delphi : types classe `TXxx`, records `TXxx` ou `RXxx`, interfaces `IXxx`, pointeurs `PXxx` (SCA100), exceptions `EXxx`. Ce détecteur ne couvre que le sous-ensemble classe/record. Les déclarations anticipées (`TFoo = class;`), les références `class of` (`TFooClass = class of TFoo`) et la syntaxe générique sont prises en charge. Correspond à SonarDelphi communitydelphi:TypeName.

## Exemples

### Mauvais (déclenche la règle)

```pascal
type Counter = class
  ...
  end;
```

### Bon (correction idiomatique)

```pascal
type TCounter = class
  ...
  end;
```
