# SCA041 — Contrôle de saisie directement sur le TForm

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Le contrôle de saisie est posé sur la fiche au lieu d'être placé dans un TPanel ou un TGroupBox

## Description

Une mise en page en couches (Form > Panel > Group > Controls) facilite nettement le redimensionnement, la mise à l'échelle DPI et l'application de thèmes. Envelopper les contrôles dans un conteneur de mise en page. Dialecte FPC/Lazarus : cette règle est ignorée lorsque l'analyse s'exécute avec --dialect=fpc (ou un projet .lpi/.lpk/.lpg) - le modèle de couches VCL qu'elle vérifie ne s'applique pas aux fiches LCL.

## Exemples

### Mauvais (déclenche la règle)

```pascal
object frmEdit: TForm
  object EdName: TEdit  // direct child of form
```

### Bon (correction idiomatique)

```pascal
object frmEdit: TForm
  object pnlBody: TPanel
    object EdName: TEdit
```
