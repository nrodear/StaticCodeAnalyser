# SCA098 — Affectation conditionnelle redondante

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> `if Cond then X := True else X := False` devrait s'écrire `X := Cond`

## Description

Deux branches qui affectent True/False à la même variable peuvent se réduire à une seule affectation directe (ou `not Cond` si la polarité est inversée). Plus court, plus rapide, et plus directement fidèle à l'expression booléenne. Correspond à SonarDelphi communitydelphi:RedundantConditional.

## Exemples

### Mauvais (déclenche la règle)

```pascal
if Active then Result := True else Result := False;
```

### Bon (correction idiomatique)

```pascal
Result := Active;
```
