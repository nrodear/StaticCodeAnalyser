# SCA201 — Adresse IP dans un fichier de configuration versionné

## Description

Un fichier de configuration dans l'arborescence des sources est versionné et livré comme du code : une adresse IP qu'il contient fige chaque checkout et chaque installation sur un réseau, et passer à un autre serveur ou environnement exige de nouveau un commit. Garder les adresses propres à un environnement hors du contrôle de version (un fichier par machine ou par environnement, l'environnement, une étape de déploiement) ou utiliser un nom d'hôte. La règle lit les fichiers .ini de l'arborescence analysée - dans les analyses de dossier, avec le même parcours de répertoires que pour les sources, dans les analyses de projet, sous la racine commune des unités du projet ; ni analyser.ini ni les copies dans les dossiers de sortie de plateforme comme Win32 ou Win64 sous la racine analysée. Les lignes commençant par ';' ou '#' sont des commentaires, les en-têtes de section (même suivis d'un commentaire) sont ignorés, et la valeur est tout ce qui suit le premier '='. La grammaire des adresses, les classes et les exclusions sont celles de SCA200 ; en outre, les clés qui portent de la prose (description, help, hint, comment, caption, text, example, note, title, summary) et les clés de version ne sont pas signalées. Masquer une ligne avec un marqueur occupant toute la ligne '; noinspection HardcodedIpInConfig' (ou '#') juste au-dessus, ou tout le fichier avec '; noinspection-file HardcodedIpInConfig'.

## Exemples

### Mauvais (déclenche la règle)

```pascal
[Database]
Server=10.20.30.40
```

### Bon (correction idiomatique)

```pascal
[Database]
Server=db.example.internal
```

## Volontairement non signalé

Le détecteur garde volontairement le silence sur les constructions ci-dessous. Chacune est une classe de faux positifs mesurée sur le corpus réel — ce n'est pas une supposition.

### Prose and version keys

A key whose words include description, help, hint, comment, caption, text, example, note, title or summary carries text, not a setting - unless the value is a URL or has a port, or the key names a host (HelpServer); a version key (FileVersion, ProductVersion, Build) carries a version unless it names a host (BuildServer). Neither is reported. A host word in the key or the section ([DNS], NameServer) lets a short public address such as 8.8.8.8 count as an address.

```pascal
description=Returns 10.1.2.3 for the lookup  ; not reported
```

### Files that are not read

analyser.ini (the analyser's own settings), .ini files in platform output folders (Win32, Win64, Linux64, OSX64, Android, iOSDevice64 ...), files in test directories and every other format (.conf, .cfg, .json, .xml, .properties) are not part of this rule.

```pascal
Win32\Release\App.ini  ; not read
```
