# SCA102 — Routine imbriquée dans une méthode

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Procédure ou fonction locale imbriquée - à extraire au niveau de l'unité

## Description

Les routines imbriquées (une `procedure`/`function` déclarée dans la section de déclarations locales d'une autre routine) sont syntaxiquement autorisées mais nuisent aux tests et à la réutilisation : la routine interne ne peut être ni testée unitairement ni réutilisée ailleurs. Le Delphi moderne préfère les méthodes anonymes (lambdas) pour les rares cas où l'imbrication était réellement nécessaire. Les méthodes anonymes ne sont PAS signalées (elles n'ont pas de nom dans l'AST). Correspond à SonarDelphi communitydelphi:NestedRoutines.

## Exemples

### Mauvais (déclenche la règle)

```pascal
procedure Outer;
  procedure Inner; begin DoX; end;
begin
  Inner;
end;
```

### Bon (correction idiomatique)

```pascal
procedure Inner; begin DoX; end;
procedure Outer;
begin
  Inner;
end;
```
