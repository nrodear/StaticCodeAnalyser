## Description

Imbriquer des blocs try rend le flot de contrôle du nettoyage / de la reprise sur erreur plus difficile à lire. La plupart des cas se démêlent soit en réordonnant les nettoyages, soit en extrayant le bloc interne dans sa propre méthode. Correspond à SonarDelphi communitydelphi:NestedTry. Le détecteur utilise une heuristique de profondeur (comptage des mots-clés `try` vs `end`) et peut produire quelques faux positifs dans du code begin/end fortement imbriqué.

## Exemples

### Mauvais (déclenche la règle)

```pascal
try
  try
    DoStuff;
  finally
    Cleanup;
  end;
except
  Log;
end;
```

### Bon (correction idiomatique)

```pascal
ProtectedDoStuff;  // helper wraps the inner try
```
