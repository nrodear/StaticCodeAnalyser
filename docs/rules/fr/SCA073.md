# SCA073 — Déclaration d'interface vide

## Description

Un corps IFoo = interface end; sans aucune méthode ni propriété est soit un reste de refactoring, soit une interface marqueur déguisée. En Delphi, les interfaces marqueurs se modélisent mieux sous forme de classes d'attribut. Correspond à SonarDelphi communitydelphi:EmptyInterface. Non signalé : une interface ayant un ancêtre *nommé* autre que IInterface/IUnknown. Elle hérite du contrat de l'ancêtre et sert de clé de requête (Obj as IFileSystemFileSource), de dérivation marqueur (IOTAFormWizard = interface(IOTARepositoryWizard)), de type passerelle ObjC/JNI ou de type d'automation *_TLB.pas - la correction proposée par classe d'attribut ne fonctionne pour aucun d'eux, car les attributs sont de la RTTI de compilation et ne peuvent pas être interrogés via QueryInterface. interface(IUnknown) est toujours signalée : elle est sémantiquement identique à interface.

## Exemples

### Mauvais (déclenche la règle)

```pascal
type IServiceMarker = interface end;
```

### Bon (correction idiomatique)

```pascal
type ServiceMarkerAttribute = class(TCustomAttribute) end;
```

## Volontairement non signalé

Le détecteur garde volontairement le silence sur les constructions ci-dessous. Chacune est une classe de faux positifs mesurée sur le corpus réel — ce n'est pas une supposition.

### Interface with a named ancestor other than IInterface/IUnknown

The rule's premise - 'carries no contract' - is false here: the interface inherits the ancestor's members and exists as a query key (`Obj as IFileSystemFileSource`), as an Embarcadero-style marker derivation (`IOTAFormWizard = interface(IOTARepositoryWizard)`), as an ObjC/JNI bridge type, or as a `*_TLB.pas` automation type generated from a type library. The suggested fix - model it as an attribute class - does not work for any of them, because attributes are compile-time RTTI and cannot be queried through `QueryInterface`. `IInterface`/`IUnknown` are NOT exempt: `IFoo = interface(IUnknown) end;` is semantically identical to `IFoo = interface end;`, since IInterface is the implicit default ancestor.

```pascal
// not reported - refines an existing contract
IFileSystemFileSource = interface(IFileSource)
  ['{4CBD5A32-...}']
end;

// still reported - no ancestor contract to inherit
IServiceMarker = interface(IUnknown)
end;
```
