# SCA131 — IfThen() évalue les deux branches - pas de court-circuit

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> `Math.IfThen(cond, A(), B())` et `StrUtils.IfThen` sont des fonctions ordinaires - les deux bras s'exécutent avant l'appel

## Description

`Math.IfThen` (surcharge Integer/Double) comme `StrUtils.IfThen` (surcharge string) sont des fonctions ordinaires, pas des constructions du langage. Pascal évalue chaque argument *avant* l'appel, la fonction ne voit donc que les valeurs finales - elle ne peut pas « sauter » la branche non sélectionnée. Dès que les bras contiennent des appels de fonction ou de méthode avec des effets de bord (lecture en base, E/S fichier, modification d'état) ou d'un coût non négligeable, les deux s'exécutent inconditionnellement. Tout l'intérêt d'écrire `IfThen(cond, A, B)` au lieu de `if cond then x := A else x := B` reposait généralement sur l'hypothèse d'une sémantique de court-circuit - qui n'existe pas ici. Le détecteur parcourt les nœuds `nkCall` dont le nom correspond à `IfThen(`, `Math.IfThen(` ou `StrUtils.IfThen(` (insensible à la casse). Après extraction de la liste d'arguments externe, il retire les littéraux de chaîne (pour que `'a(b)'` ne trompe pas l'heuristique) et cherche des `(` imbriquées - tout appel imbriqué est un signal fort d'une branche à effets de bord. Les appels n'ayant que des littéraux ou de simples variables comme bras ne sont pas signalés - pas plus que les appels de fonctions sans paramètre écrits sans parenthèses (`IfThen(b, FetchA, FetchB)`), car sans parenthèses un appel ne peut pas être distingué d'une variable. Correspond à `IfThenShortCircuitCheck` de Sonar-Delphi.

## Exemples

### Mauvais (déclenche la règle)

```pascal
x := Math.IfThen(IsCacheHit, FetchFromCache(Key), FetchFromDb(Key));
//                            both calls run every time
```

### Bon (correction idiomatique)

```pascal
if IsCacheHit then
  x := FetchFromCache(Key)
else
  x := FetchFromDb(Key);
```
