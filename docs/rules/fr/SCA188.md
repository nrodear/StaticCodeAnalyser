## Description

Le fichier contient un caractère de contrôle Unicode bidirectionnel de type override ou isolate (U+202A-202E, U+2066-2069, U+061C). Ces caractères peuvent faire s'afficher le code source pour un relecteur humain autrement qu'il n'est compilé - l'attaque Trojan Source (CVE-2021-42574, CWE-1007). Ils n'ont aucun usage légitime dans du source Delphi ; supprimer le caractère de contrôle.
