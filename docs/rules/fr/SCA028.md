# SCA028 — Le gestionnaire d'événement DFM pointe vers une méthode absente

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Bug-red)

> OnClick / On... renvoie à une méthode qui n'existe pas dans la classe de la fiche

## Métadonnées

| Champ | Valeur |
|---|---|
| **Identifiant de règle** | `SCA028` |
| **Kind** | `DfmDeadEvent` |
| **Sévérité par défaut** | Error |
| **Type** | Bug |
| **Unité du détecteur** | `uDfmDeadEvent.pas` |
| **Étiquettes** | `dfm`, `streaming`, `dead-code` |

## Description

Le streaming DFM plante au chargement de la fiche avec *"class TForm has no published method X"*. Généralement causé par un renommage manuel dans le .pas sans mise à jour du .dfm.

## Exemples

### Mauvais (déclenche la règle)

```pascal
object btnSave: TButton
  OnClick = btnSaveClick   // method removed in .pas
end
```

### Bon (correction idiomatique)

```pascal
object btnSave: TButton
  OnClick = btnSaveClick
end

// and in the .pas, published:
procedure btnSaveClick(Sender: TObject);
```
