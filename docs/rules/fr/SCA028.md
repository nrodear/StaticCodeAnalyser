## Description

> Cette section n'existe qu'en anglais. Le nom et la description courte sont traduits ; les textes complets suivent la version anglaise.

DFM streaming crashes at form-load time with *"class TForm has no published method X"*. Usually caused by a manual rename in the .pas without updating the .dfm.

## Exemples

### Mauvais (déclenche la règle)

```pascal
object btnSave: TButton

end
```
