# SCA133 — raise nu hors d'un gestionnaire except/on

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Bug-red)

> `raise;` sans expression d'exception n'est valide qu'à l'intérieur d'un gestionnaire except (pour relancer l'exception) - ailleurs, Delphi (E2145) et FPC le refusent

| **Kind** | `RaiseOutsideExcept` |

## Description

Un `raise;` nu relance l'exception en cours de traitement ; il n'est donc valide qu'à l'intérieur de `except` / `on E: T do`. Delphi refuse cette forme partout ailleurs avec l'erreur de compilation E2145 'Re-raising an exception only allowed in exception handler', FPC avec `parser_e_no_reraise_possible` ('Re-raise isn't possible there'). Le détecteur parcourt récursivement l'AST de la méthode en suivant un indicateur `InHandler`. L'indicateur est positionné quand le parcours descend dans `nkExceptBlock` ou `nkOnHandler`. Un nœud `nkRaise` avec `Name = 'raise'` (forme nue) rencontré alors que l'indicateur vaut False produit un résultat. Un `raise;` nu dans un bloc `finally` lui-même situé hors d'un gestionnaire except est également signalé. Correspond à la règle Sonar-50 #15 (`RaiseWithoutClass`).

## Exemples

### Mauvais (déclenche la règle)

```pascal
procedure Foo(x: Integer);
begin
  if x < 0 then
    raise;             // <- not inside a handler: compiler error E2145
end;
```

### Bon (correction idiomatique)

```pascal
procedure Foo(x: Integer);
begin
  if x < 0 then
    raise EArgumentException.CreateFmt('x = %d (must be >= 0)', [x]);
end;
```
