# SCA053 — Variable locale inutilisée

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Variable locale déclarée mais jamais référencée dans le corps de la méthode

## Description

Un `var X: T;` dans le corps d'une méthode est déclaré mais jamais lu ni écrit dans ce même corps. Reprend le conseil H2164 du compilateur Delphi, mais émis comme résultat SCA afin de pouvoir être filtré, masqué, priorisé et suivi de la même manière que les autres règles - utile lorsque H2164 est désactivé pour tout le projet. L'analyse du corps reconnaît les identificateurs reliés par `with` et ignore les variables dont le nom correspond à un champ ou à une propriété existants (le `with` les relierait implicitement). Les variables inline introduites par `var X: T := ...` sont traitées de la même façon. Masquer avec `// noinspection UnusedLocalVar` lorsque la variable est conservée volontairement (documentation déclarative, ou initialisation de record exigée par une API).

## Exemples

### Mauvais (déclenche la règle)

```pascal
var
  Tmp: Integer;   // never used
begin
  DoStuff;
end;
```

### Bon (correction idiomatique)

```pascal
begin
  DoStuff;
end;
```
