# SCA001 — Objet créé sans libération sûre face aux exceptions

> Objet créé mais pas libéré de manière fiable (fuite mémoire possible)

## Description

Signale quatre variantes. (1) never-freed : l'objet n'est jamais libéré - avertissement. (2) freed-outside-finally : un Free existe mais se trouve hors du try/finally protecteur, si bien que toute exception à l'intérieur du bloc provoque une fuite - avertissement. (3) return-value-not-freed : une fonction renvoie un objet fraîchement créé et l'appelant ne le libère jamais - note. (4) proven-leak : jamais libéré ET il est prouvé que la variable ne sort jamais de la méthode (aucun argument d'appel, aucune cible d'affectation, aucun argument de constructeur suspecté d'être un propriétaire, aucun type interface) - la seule variante signalée comme erreur. La variante à laquelle appartient un résultat est indiquée dans properties.variant de la sortie SARIF et dans l'astuce de correction affichée par l'interface ; le texte du message lui-même ne contient que le nom de la variable.

## Exemples

### Mauvais (déclenche la règle)

```pascal
list := TStringList.Create;
DoStuff(list);   // <-- exception here leaks list
```

### Bon (correction idiomatique)

```pascal
list := TStringList.Create;
try
  DoStuff(list);
finally
  list.Free;
end;
```
