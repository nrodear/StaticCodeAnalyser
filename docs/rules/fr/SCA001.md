## Description

> Cette section n'existe qu'en anglais. Le nom et la description courte sont traduits ; les textes complets suivent la version anglaise.

TObject.Create (or LeakyClass.Create) without a protective try/finally block leaks the instance when subsequent code raises an exception. The Free call must run regardless of how the protected block exits.

## Exemples

### Mauvais (déclenche la règle)

```pascal
list := TStringList.Create;
DoStuff(list);   // <-- exception here leaks list
```

### Bon (correction idiomatique)

```pascal
list := TStringList.Create;
try
  DoStuff(list);
finally
  list.Free;
end;
```
