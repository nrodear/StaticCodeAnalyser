## Description

> Cette section n'existe qu'en anglais. Le nom et la description courte sont traduits ; les textes complets suivent la version anglaise.

Right-hand side of div, mod, or / is a variable without prior guard against zero. Integer division crashes with EDivByZero, float division silently produces Inf/NaN.

## Exemples

### Mauvais (déclenche la règle)

```pascal
result := total / count;
```

### Bon (correction idiomatique)

```pascal
if count <> 0 then result := total / count;
```
