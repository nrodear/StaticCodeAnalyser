# SCA010 — Division par zéro possible

> Division entière (div / mod) par une variable pouvant valoir zéro

## Description

Le membre droit d'un div ou mod entier est un paramètre ou une variable locale sans garde préalable contre zéro ; à l'exécution, cela lève EDivByZero. Gardes reconnues : une condition if comme `Count <> 0`, `Count > 0` ou `Count >= 1` avant la division, `if Count = 0 then Exit` (ou raise), une variable de boucle for qui commence à 1 ou plus, et un diviseur auquel ne sont jamais affectées que des valeurs non nulles. Un littéral `div 0` / `mod 0` est toujours signalé. L'opérateur flottant / n'est pas vérifié par cette règle.

## Exemples

### Mauvais (déclenche la règle)

```pascal
function Average(Total, Count: Integer): Integer;
begin
  Result := Total div Count;   // EDivByZero when Count = 0
end;
```

### Bon (correction idiomatique)

```pascal
function Average(Total, Count: Integer): Integer;
begin
  if Count = 0 then
    Exit(0);
  Result := Total div Count;
end;
```
