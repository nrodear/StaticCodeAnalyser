# SCA176 — Méthode à forte complexité cognitive (flot de contrôle imbriqué)

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> La complexité cognitive (style Sonar) dépasse 15 - les if/for/while/case imbriqués sont difficiles à suivre mentalement

## Description

La complexité cyclomatique (SCA022) compte les chemins indépendants de façon linéaire - dix instructions if à plat pèsent autant qu'un if imbriqué sur trois niveaux. La complexité cognitive, introduite par Sonar en 2017, multiplie le coût de l'imbrication : chaque construction de flux de contrôle ajoute 1 + profondeur d'imbrication. Trois boucles imbriquées valent donc 1+2+3=6 au lieu de 3. Le détecteur parcourt chaque méthode avec une pile explicite plutôt que par récursion (ainsi, un code profondément imbriqué ne peut pas faire déborder la pile d'appels), en suivant la profondeur courante et la somme cumulée. Les opérateurs booléens (and/or/xor) dans les conditions if ajoutent +1 chacun. Seuil : 15 (valeur par défaut de Sonar), configurable via l'INI [Detectors] CognitiveLimit.

## Exemples

### Mauvais (déclenche la règle)

```pascal
procedure ProcessOrder(const AOrder: TOrder);
begin
  if AOrder.IsValid and AOrder.HasItems then        // +1 (depth 0), +1 'and'  = 2
    for var I := 0 to AOrder.Count - 1 do           // +1+1 (depth 1)          = 2
      while AOrder[I].NeedsRetry do                 // +1+2 (depth 2)          = 3
        if AOrder[I].InStock or AllowBackorder then // +1+3 (depth 3), +1 'or' = 5
          case AOrder[I].Kind of                    // +1+4 (depth 4)          = 5
            ikPhysical:
              if AOrder[I].Weight > 0 then          // +1+5 (depth 5)          = 6
                Ship(AOrder[I]);
          end;
end;
// Cognitive complexity = 2+2+3+5+5+6 = 23 (limit 15)
```

### Bon (correction idiomatique)

```pascal
procedure ShipItem(const AItem: TOrderItem);
begin
  if not (AItem.InStock or AllowBackorder) then Exit;  // +1, +1 'or' = 2
  if AItem.Kind <> ikPhysical then Exit;               // +1
  if AItem.Weight <= 0 then Exit;                      // +1
  Ship(AItem);
end;

procedure ProcessOrder(const AOrder: TOrder);
begin
  if not AOrder.IsValid then Exit;                     // +1
  if not AOrder.HasItems then Exit;                    // +1
  for var I := 0 to AOrder.Count - 1 do                // +1 (depth 0)
    while AOrder[I].NeedsRetry do                      // +1+1 (depth 1)
      ShipItem(AOrder[I]);
end;
// ShipItem = 4, ProcessOrder = 5 - both well below 15
```
