# SCA089 — Champ public dans la classe

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Un champ public rompt l'encapsulation - utiliser une propriété

## Description

Un champ public expose le stockage sous-jacent ; les appelants peuvent le modifier sans que la classe s'en aperçoive. Une propriété laisse à la classe la possibilité d'ajouter plus tard une validation/normalisation sans casser les appelants. Correspond à SonarDelphi communitydelphi:PublicField.

## Exemples

### Mauvais (déclenche la règle)

```pascal
type TFoo = class
  public
    Count: Integer;
  end;
```

### Bon (correction idiomatique)

```pascal
type TFoo = class
  private
    FCount: Integer;
  public
    property Count: Integer read FCount write FCount;
  end;
```
