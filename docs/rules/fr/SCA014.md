# SCA014 — Littéral numérique sans constante nommée

> Littéral numérique dans une expression - extraire vers une constante nommée

## Description

Les littéraux numériques intégrés directement dans la logique métier ne portent aucun sens : `if RetryCount > 3` oblige chaque lecteur à deviner ce que représente 3 et chaque modification de maintenance à retrouver chaque occurrence à la main. Extraire une constante nommée pour que la valeur ait un objectif documenté et exactement une source de vérité. Le détecteur ignore les valeurs triviales (0, 1, 2, -1, tailles courantes en puissance de 2, indexation dans des collections connues pour être minuscules) - voir [Detectors] MagicNumberTrivials pour la liste active. Les bornes de boucle par rapport à `Length(arr)` et l'index de tableau 0 sont également ignorés. Utiliser la configuration globale pour ajouter des valeurs triviales propres au projet (p. ex. un PageSize fixe).

## Exemples

### Mauvais (déclenche la règle)

```pascal
if RetryCount > 3 then ...
```

### Bon (correction idiomatique)

```pascal
const MAX_RETRIES = 3;
if RetryCount > MAX_RETRIES then ...
```
