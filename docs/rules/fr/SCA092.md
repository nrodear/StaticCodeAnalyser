# SCA092 — Unité sans aucune déclaration

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> L'unité n'a ni type, ni const, ni var, ni procedure/function - supprimer ou compléter

## Description

Un fichier `.pas` avec un en-tête d'unité mais sans aucune déclaration est un poids mort. Soit supprimer le fichier, soit compléter l'emplacement réservé. Correspond à SonarDelphi communitydelphi:EmptyFile.

## Exemples

### Mauvais (déclenche la règle)

```pascal
unit X;
interface
implementation
end.
```

### Bon (correction idiomatique)

```pascal
// delete the file
```
