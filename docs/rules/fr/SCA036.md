# SCA036 — Type de contrôle incompatible avec le TField

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> La classe du contrôle de données ne correspond pas à TField.DataType (TDBEdit pour un TBooleanField)

## Métadonnées

| Champ | Valeur |
|---|---|
| **Identifiant de règle** | `SCA036` |
| **Kind** | `DfmFieldTypeMismatch` |
| **Sévérité par défaut** | Hint |

| **Unité du détecteur** | `uDfmFieldTypeMismatch.pas` |
| **Étiquettes** | `dfm`, `ux`, `db-binding` |

## Description

L'utilisateur voit la valeur brute et peut corrompre le type. Choisir un contrôle compatible avec le type du champ (TDBCheckBox pour les booléens, TDBLookupComboBox pour les clés étrangères).

## Exemples

### Mauvais (déclenche la règle)

```pascal
DBEdit1.DataField = 'IsActive'   // TBooleanField
```

### Bon (correction idiomatique)

```pascal
DBCheckBox1.DataField = 'IsActive'
```
