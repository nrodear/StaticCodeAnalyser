# SCA085 — X.Free; X := nil; devrait être FreeAndNil(X)

## Description

`FreeAndNil(X)` est l'idiome Delphi canonique : il fait les deux de manière atomique et évite un pointeur pendant si `X.Free` lève une exception (p. ex. échec du destructeur). La forme manuelle sur deux lignes produit aussi plus de bruit dans les diffs et se laisse plus facilement séparer lors de refactorings ultérieurs. Correspond à SonarDelphi communitydelphi:FreeAndNil.

## Exemples

### Mauvais (déclenche la règle)

```pascal
Obj.Free;
Obj := nil;
```

### Bon (correction idiomatique)

```pascal
FreeAndNil(Obj);
```
