# SCA084 — Test Assigned + nil redondant

> `Assigned(X) and (X <> nil)` - supprimer le test nil

## Description

Pour les pointeurs et les instances de classe, `Assigned(X)` est sémantiquement identique à `X <> nil`. Combiner les deux est redondant - le second test ne peut jamais donner un résultat différent. Correspond à SonarDelphi communitydelphi:AssignedAndAssignedNil.

## Exemples

### Mauvais (déclenche la règle)

```pascal
if Assigned(Obj) and (Obj <> nil) then ...
```

### Bon (correction idiomatique)

```pascal
if Assigned(Obj) then ...
```
