# SCA087 — Section de visibilité vide dans la classe

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> En-tête de section `public`/`private`/... sans aucun membre

## Description

Une classe dont un mot-clé de visibilité est immédiatement suivi d'un autre mot-clé de visibilité (ou de `end`) est généralement un reste de refactoring - tous les membres de cette section ont été déplacés ailleurs. Supprimer l'en-tête vide. Correspond à SonarDelphi communitydelphi:EmptyVisibilitySection.

## Exemples

### Mauvais (déclenche la règle)

```pascal
type TFoo = class
  public
  private
    FX: Integer;
  end;
```

### Bon (correction idiomatique)

```pascal
type TFoo = class
  private
    FX: Integer;
  end;
```
