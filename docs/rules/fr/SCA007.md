# SCA007 — Unit inutilisée dans la clause uses

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

## Description

Heuristique : recherche n'importe quel identificateur de l'unité utilisée. Faux positifs possibles pour les unités qui se contentent d'enregistrer des classes / d'initialiser un état global via des sections initialization.

## Exemples

### Mauvais (déclenche la règle)

```pascal
uses ..., MyUnusedHelper, ...;
```

### Bon (correction idiomatique)

```pascal
uses
  System.SysUtils, Vcl.Forms;

// Or, if it must stay (initialization side effect, class registration):
uses
  System.SysUtils, Vcl.Forms,
  MyUnusedHelper;   // registers its classes in its initialization section
```
