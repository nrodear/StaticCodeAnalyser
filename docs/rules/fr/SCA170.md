# SCA170 — Paramètre string sans const

> Paramètre string déclaré sans const - provoque une incrémentation du compteur de références à chaque appel

## Description

Delphi incrémente le compteur de références de la chaîne à chaque appel quand le paramètre est déclaré sans `const`. Avec `const`, le compilateur passe une référence pure et évite l'aller-retour du compteur de références. Le compilateur interdit aussi l'affectation à un paramètre `const`, ce qui rend explicite le contrat de non-modification. Pour les paramètres string non modifiés (l'écrasante majorité), préférer `const`. Le détecteur signale les paramètres dont le type est `string`/`AnsiString`/`UnicodeString`/`WideString`/`RawByteString`/`ShortString` sans `const`/`var`/`out`.
