## Description

Une propriété SQL de requête de base de données (TADOQuery / TFDQuery / TUniQuery / TZQuery / TKSQLQuery.SQL.Text) est assemblée en concaténant la propriété Text / Caption / Hint / EditText / ItemText d'un contrôle de saisie d'interface (TEdit, TComboBox, TMaskEdit, ...) - injection SQL classique via la fiche. Un utilisateur qui tape `' OR ''1''=''1' --` dans le champ de recherche lit n'importe quelle ligne ; `'; DROP TABLE Users; --` est destructeur. Refactoring : lier des paramètres nommés et les affecter via ParamByName, ne jamais concaténer. Ce détecteur est le pendant DFM/chemin d'interface de SCA003 (injection SQL lexicale) et de SCA058 (instruction SQL dangereuse).

## Exemples

### Mauvais (déclenche la règle)

```pascal
FDQuery1.SQL.Text := 'SELECT * FROM U WHERE Name=''' + EdName.Text + '''';
```

### Bon (correction idiomatique)

```pascal
FDQuery1.SQL.Text := 'SELECT * FROM U WHERE Name=:n';
FDQuery1.ParamByName('n').AsString := EdName.Text;
```
