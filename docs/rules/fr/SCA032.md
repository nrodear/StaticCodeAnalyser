## Description

Un cycle dans le graphe maître-détail provoque une récursion infinie pendant BeforeOpen ou tout rafraîchissement et fait déborder la pile du processus. Rompre le cycle en supprimant l'un des liens.

## Exemples

### Mauvais (déclenche la règle)

```pascal
QA.MasterSource = dsB   QB.MasterSource = dsA   // cycle
```

### Bon (correction idiomatique)

```pascal
QB.MasterSource = dsA   // A is the parent, B the detail
// QA has no MasterSource
```
