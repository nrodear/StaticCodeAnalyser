# SCA078 — Capture générale sur la classe racine Exception

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

## Description

Capturer la classe racine `Exception` capture toutes les erreurs, y compris les erreurs irrécupérables (EAccessViolation, EOutOfMemory, EStackOverflow). Préférer un type d'exception spécifique (EDatabaseError, EFOpenError, EConvertError, ...) afin que des échecs sans rapport ne soient pas occultés. Masquer avec `// noinspection` si la capture générale est voulue (p. ex. frontière de journalisation).

## Exemples

### Mauvais (déclenche la règle)

> Cette règle signale avec une confiance faible : avec la valeur par défaut `[Rules] MinConfidence=medium`, l'exemple ci-dessous reste masqué. Avec `[Rules] MinConfidence=low`, il apparaît.

```pascal
try Foo; except on E: Exception do Log(E.Message); end;
```

### Bon (correction idiomatique)

```pascal
try Foo; except on E: EDatabaseError do Log(E.Message); end;
```
