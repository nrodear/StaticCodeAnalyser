# SCA027 — Liaison (DataSource, DataField) en double

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> Deux contrôles ou plus lient le même couple DataSource / DataField

## Métadonnées

| Champ | Valeur |
|---|---|
| **Identifiant de règle** | `SCA027` |
| **Kind** | `DfmDuplicateBinding` |
| **Sévérité par défaut** | Warning |

| **Unité du détecteur** | `uDfmDuplicateBinding.pas` |
| **Étiquettes** | `dfm`, `db-binding` |

## Description

Lorsque l'utilisateur modifie un contrôle lié, le second reçoit une mise à jour parallèle depuis le dataset - écrasements concurrents, difficiles à déboguer. Lier chaque (DataSource, DataField) à exactement un contrôle.

## Exemples

### Mauvais (déclenche la règle)

```pascal
DBEdit1.DataField = 'NAME'
DBEdit2.DataField = 'NAME'   // same DataSource
```

### Bon (correction idiomatique)

```pascal
DBEdit1.DataField = 'NAME'
DBEdit2.DataField = 'FIRSTNAME'
```
