## Description

Les marqueurs NOSONAR sont de la dette technique : chacun fait taire un résultat sans corriger le problème sous-jacent. SCA signale chaque NOSONAR afin que les relecteurs puissent contrôler les masquages pendant la revue de code. SCA utilise son propre marqueur `// noinspection` pour le masquage natif - le code décoré de NOSONAR provenant de SonarDelphi devrait être migré. Correspond à SonarDelphi communitydelphi:NoSonar.

## Exemples

### Mauvais (déclenche la règle)

```pascal
Dispose(P); // NOSONAR - we know about this
```

### Bon (correction idiomatique)

```pascal
// noinspection - covered by integration test
Dispose(P);
```
