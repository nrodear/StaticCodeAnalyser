# SCA141 — L'implémentation de la classe dépasse 500 lignes

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Une classe dont la déclaration et les méthodes d'implémentation totalisent plus de 500 lignes a trop de responsabilités

## Description

Comme GodClass (SCA138), mais mesuré en étendue de lignes plutôt qu'en nombre de méthodes/champs. Repère les classes qui paraissent petites d'après le nombre de membres mais ont d'énormes corps d'implémentation - typique des classes de logique héritées qui ont grandi pendant des années. Le détecteur parcourt les nœuds `nkClass` ; pour chaque classe, il détermine une étendue via min(class-decl-line, first-method-with-prefix-line) .. max(class-decl-children-line, last-method-with-prefix-line). Seuil 500 lignes. Les records, interfaces, helpers et déclarations forward sont ignorés. Correspond à la règle Sonar-50 #35.

## Exemples

### Mauvais (déclenche la règle)

```pascal
// TMainForm with 800 lines of business logic mixed with UI handlers,
// database calls and report generation.
```

### Bon (correction idiomatique)

```pascal
// Extract verticals into focused classes:
TReportRunner   = class ... end;     // own unit
TDataController = class ... end;     // own unit

TMainForm = class(TForm)
  FReport: TReportRunner;
  FData:   TDataController;
end;
```
