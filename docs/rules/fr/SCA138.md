# SCA138 — La classe a trop de méthodes ou de champs

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Une classe de plus de 20 méthodes ou de plus de 15 champs d'instance concentre trop de responsabilités - difficile à tester, à faire évoluer et à relire

## Métadonnées

| Champ | Valeur |
|---|---|
| **Identifiant de règle** | `SCA138` |
| **Kind** | `GodClass` |
| **Sévérité par défaut** | Warning |

## Description

Les god classes sont des classes qui possèdent trop de comportement et d'état à la fois : exemples typiques, les racines composites d'interface utilisateur, les singletons gestionnaires tout-en-un ou les entités métier de première génération qui ont grandi avec l'application. Le détecteur parcourt les nœuds `nkClass`, compte les enfants directs `nkMethod` et `nkField` (y compris ceux à l'intérieur de `nkVisibilitySection`) et émet un résultat quand MethodCount > 20 OU FieldCount > 15. Les records, interfaces, class helpers, déclarations forward et classes marquées `class abstract` (contrats d'intention de conception) sont ignorés. Les propriétés ne sont pas comptées - ce sont du sucre syntaxique au-dessus de paires getter/setter. Les seuils sont codés en dur aux valeurs par défaut de Sonar ; les god classes les dépassent généralement de 3 à 5 fois, la limite n'a donc pas besoin d'être finement réglable. Correspond à la règle Sonar-50 #31.

## Exemples

### Mauvais (déclenche la règle)

```pascal
TUiController = class             // 60 methods, 80 fields
  FToolbar, FFilters, FGrid, ...: ...;
  procedure BuildToolbar;
  procedure FilterChange(...);
  procedure GridDrawCell(...);
  // 50 more methods mixing concerns
end;
```

### Bon (correction idiomatique)

```pascal
TToolbarSlots    = record ... end;
TFilterController = class ... end;
TGridRenderer    = class ... end;

TUiController = class                // ~10 methods, ~5 fields
  FToolbar: TToolbarSlots;
  FFilter:  TFilterController;
  FGrid:    TGridRenderer;
  procedure Setup;
end;
```
