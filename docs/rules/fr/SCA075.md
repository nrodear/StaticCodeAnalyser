# SCA075 — Héritage explicite de TObject

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> `class(TObject)` est redondant - supprimer les parenthèses

## Description

Toute classe hérite implicitement de TObject ; `TFoo = class(TObject)` est identique à `TFoo = class`. Supprimer la base explicite fait ressortir les vrais changements d'héritage dans les diffs. Correspond à SonarDelphi communitydelphi:ExplicitTObjectInheritance.

## Exemples

### Mauvais (déclenche la règle)

```pascal
type TFoo = class(TObject) ... end;
```

### Bon (correction idiomatique)

```pascal
type TFoo = class ... end;
```
