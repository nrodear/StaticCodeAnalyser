# SCA049 — Length(s) - N sans garde

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Bug-red)

> `Length(s) - K` ou `.Count - K` avec K >= 2 sans garde - index ou nombre négatif quand l'entrée est plus courte que K

## Description

`Length` et `.Count` renvoient un Integer signé, donc `Length(s) - 4` sur une chaîne de moins de quatre caractères est simplement un nombre négatif - et ce nombre va généralement tout droit dans un index, une position de Move ou un compteur : `s[Length(s) - 3]` lit avant le premier caractère (une erreur d'intervalle avec $R+, des données parasites ou une violation d'accès sans), `Move(s[Length(s) - 4], Buf, 4)` copie depuis l'extérieur de la chaîne. Le détecteur signale `Length(...)` et `.Count` suivis de `- K` où K est un littéral entier valant 2 ou plus. `- 1` est ignoré : `for I := 0 to Length(s) - 1` s'exécute simplement zéro fois sur une chaîne vide. Il s'agit d'une indication lexicale - une garde `if Length(s) >= K` qui précède n'est pas vue. Préférer les helpers RTL qui gèrent les entrées courtes (ExtractFileExt, RightStr, EndsText) ou protéger l'accès.

## Exemples

### Mauvais (déclenche la règle)

> Cette règle signale avec une confiance faible : avec la valeur par défaut `[Rules] MinConfidence=medium`, l'exemple ci-dessous reste masqué. Avec `[Rules] MinConfidence=low`, il apparaît.

```pascal
if s[Length(s) - 3] = '.' then   // 3-letter extension? Index below 1 when s has fewer than 4 chars

```

### Bon (correction idiomatique)

```pascal
if Length(ExtractFileExt(s)) = 4 then   // the RTL handles short strings
  DoStuff;
```
