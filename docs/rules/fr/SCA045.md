## Description

Marco Cantu, delphi.org et Stack Overflow classent systématiquement `with` parmi les principales sources de bugs en Delphi. Les identificateurs de la portée externe sont masqués silencieusement par les membres de la cible du with. Utiliser plutôt un alias sous forme de variable locale.

## Exemples

### Mauvais (déclenche la règle)

```pascal
with Customer do
begin
  Name := SomeName;   // Customer.Name? or local Name?
end;
```

### Bon (correction idiomatique)

```pascal
C := Customer;
C.Name := SomeName;
```
