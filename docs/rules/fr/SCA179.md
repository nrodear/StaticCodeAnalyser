# SCA179 — Attribut DUnitX [Ignore] sans argument de justification

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> [Ignore] sans argument chaîne ignore le test silencieusement - ajouter un message expliquant pourquoi il est désactivé

## Description

DUnitX accepte [Ignore] à la fois comme attribut marqueur et sous la forme [Ignore('reason')]. La forme marqueur ignore le test sans indiquer POURQUOI il a été désactivé - le test dérive alors sans maintenance, souvent oublié. Toujours ajouter une chaîne de justification qui renvoie à un ticket / une dépendance externe / une limitation connue, afin que la désactivation puisse être triée.

## Exemples

### Mauvais (déclenche la règle)

```pascal
[Ignore]
procedure SomeTest;
```

### Bon (correction idiomatique)

```pascal
[Ignore('TBD ticket #1234 - flaky on CI')]
procedure SomeTest;
```
