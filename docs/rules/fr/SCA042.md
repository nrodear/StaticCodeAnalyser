## Description

> Cette section n'existe qu'en anglais. Le nom et la description courte sont traduits ; les textes complets suivent la version anglaise.

Spaghetti indicator: one handler dispatching dozens of events is hard to read, hard to change, and almost always has cohesion problems. Split by responsibility.

## Exemples

### Mauvais (déclenche la règle)

```pascal
btn1.OnClick = HandleEverything
btn2.OnClick = HandleEverything
btn3.OnClick = HandleEverything
btn4.OnClick = HandleEverything
btn5.OnClick = HandleEverything
```

### Bon (correction idiomatique)

```pascal
btnNew.OnClick    = btnNewClick
btnOpen.OnClick   = btnOpenClick
btnSave.OnClick   = btnSaveClick
btnPrint.OnClick  = btnPrintClick
btnClose.OnClick  = btnCloseClick
```
