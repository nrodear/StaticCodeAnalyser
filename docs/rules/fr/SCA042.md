# SCA042 — Gestionnaire d'événement surcharge

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Une seule méthode est câblée sur N événements de composants ou plus (N=5 par défaut)

## Description

Indicateur de code spaghetti : un gestionnaire unique qui répartit de nombreux événements sans rapport entre eux est difficile à lire, difficile à modifier et a presque toujours des problèmes de cohésion. Le scinder par responsabilité. Signalé lorsqu'une méthode est liée à 5 événements de composants ou plus dans un DFM et que les liaisons sont hétérogènes - classes de composants différentes ou événements différents. Un gestionnaire partagé par des composants d'une même classe sur le même événement (douze boutons de couleur avec un seul OnClick) est un regroupement paramétré et n'est pas signalé.

## Exemples

### Mauvais (déclenche la règle)

```pascal
object Form1: TForm1
  object btnSave: TButton
    OnClick = HandleEverything
  end
  object btnOpen: TButton
    OnClick = HandleEverything
  end
  object btnClose: TButton
    OnClick = HandleEverything
  end
  object edtName: TEdit
    OnChange = HandleEverything
  end
  object edtCity: TEdit
    OnChange = HandleEverything
  end
end
```

### Bon (correction idiomatique)

```pascal
object Form1: TForm1
  object btnSave: TButton
    OnClick = btnSaveClick
  end
  object btnOpen: TButton
    OnClick = btnOpenClick
  end
  object btnClose: TButton
    OnClick = btnCloseClick
  end
  object edtName: TEdit
    OnChange = edtNameChange
  end
  object edtCity: TEdit
    OnChange = edtCityChange
  end
end
```
