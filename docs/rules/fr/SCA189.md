# SCA189 — Fichier source ANSI avec du contenu non-ASCII

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

## Description

Le fichier n'a pas de BOM, contient des octets non-ASCII et n'est pas de l'UTF-8 valide - il est donc réellement encodé sur 8 bits (ANSI). Le compilateur Delphi le lit dans la page de codes système (GetACP), ce qui rend les caractères non-ASCII dépendants de la machine/des paramètres régionaux et non portables. Enregistrer le fichier en UTF-8 avec BOM.
