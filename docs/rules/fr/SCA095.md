# SCA095 — Section de visibilité répétée

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> La même section `public`/`private`/... apparaît deux fois dans une classe

## Description

Deux sections `private` (ou `public`/`protected`/`published`) dans la même classe, avec des membres entre elles, devraient être fusionnées en une seule. Cela aide les relecteurs à saisir d'un coup d'œil la forme de la classe. Correspond à SonarDelphi communitydelphi:ConsecutiveVisibilitySection. Remarque : un en-tête vide suivi d'un autre en-tête relève de la règle voisine mais distincte `EmptyVisibilitySection` (SCA087).

## Exemples

### Mauvais (déclenche la règle)

```pascal
type TFoo = class
  private FX: Integer;
  public procedure A;
  private FY: Integer;
  end;
```

### Bon (correction idiomatique)

```pascal
type TFoo = class
  private
    FX, FY: Integer;
  public procedure A;
  end;
```
