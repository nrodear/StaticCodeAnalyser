## Description

> Cette section n'existe qu'en anglais. Le nom et la description courte sont traduits ; les textes complets suivent la version anglaise.

Variable was assigned a value that could be nil (e.g. Find...-method returning nil) and is dereferenced without prior nil-check. Crashes with EAccessViolation at runtime.

## Exemples

### Mauvais (déclenche la règle)

```pascal
obj := FindObject(id);
obj.DoStuff;   // <-- AV if FindObject returns nil
```

### Bon (correction idiomatique)

```pascal
obj := FindObject(id);
if Assigned(obj) then obj.DoStuff;
```
