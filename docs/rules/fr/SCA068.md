# SCA068 — Virgule finale dans la liste d'arguments

## Description

Virgule finale avant `)` dans une liste d'arguments. Dans un appel normal, Delphi la rejette : la virgule ajoute un argument vide (E2034 trop de paramètres réels). Seul un appel à liaison tardive sur un Variant ou une dispinterface (automation OLE) la compile ; l'argument vide y est un paramètre optionnel omis. Elle n'y apporte aucun bénéfice sémantique (contrairement à Python/JS, où elle stabilise le diff) et suggère un argument oublié. Correspond à SonarDelphi communitydelphi:TrailingCommaArgumentList.

## Exemples

### Mauvais (déclenche la règle)

```pascal
Excel.Workbooks.Open(FileName,);   // Excel: Variant
Excel.ActiveWorkbook.SaveAs(NewName, );
```

### Bon (correction idiomatique)

```pascal
Excel.Workbooks.Open(FileName);   // Excel: Variant
Excel.ActiveWorkbook.SaveAs(NewName);
```
