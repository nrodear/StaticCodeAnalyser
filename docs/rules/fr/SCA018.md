# SCA018 — L'imbrication de blocs dépasse le seuil

## Description

> Cette section n'existe qu'en anglais. Le nom et la description courte sont traduits ; les textes complets suivent la version anglaise.

Deep nesting hurts readability and indicates the method is doing too much. Use guard clauses (early Exit) or extract inner blocks into helper methods. A block is reported when its depth exceeds the limit - with the default 4, the fifth nested level is reported.

## Exemples

### Mauvais (déclenche la règle)

```pascal
if a then
  if b then
    if c then
      if d then
        if e then DoStuff;
```

### Bon (correction idiomatique)

```pascal
if not a then Exit;
if not b then Exit;
if not c then Exit;
if not d then Exit;
if e then DoStuff;
```
