# SCA018 — L'imbrication de blocs dépasse le seuil

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Profondeur d'imbrication if/for/while supérieure au maximum configuré (4 par défaut) ; une chaîne else-if compte pour UN seul niveau, comme un case

## Description

Une imbrication profonde nuit à la lisibilité et indique que la méthode en fait trop. Utiliser des clauses de garde (Exit anticipé) ou extraire les blocs internes dans des méthodes auxiliaires. Un bloc est signalé lorsque sa profondeur dépasse la limite - avec la valeur par défaut 4, le cinquième niveau d'imbrication est signalé.

## Exemples

### Mauvais (déclenche la règle)

```pascal
if a then
  if b then
    if c then
      if d then
        if e then DoStuff;
```

### Bon (correction idiomatique)

```pascal
if not a then Exit;
if not b then Exit;
if not c then Exit;
if not d then Exit;
if e then DoStuff;
```
