# SCA002 — Bloc except vide

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Un bloc except vide avale silencieusement toutes les exceptions

## Description

Un bloc except sans instruction intercepte toutes les exceptions, y compris les inattendues (EAccessViolation, EOutOfMemory). Les bugs deviennent invisibles. Au minimum, journaliser l'exception ou la relancer.

## Exemples

### Mauvais (déclenche la règle)

```pascal
try DoStuff except end;
```

### Bon (correction idiomatique)

```pascal
try DoStuff except on E: Exception do LogError(E.Message); end;
```
