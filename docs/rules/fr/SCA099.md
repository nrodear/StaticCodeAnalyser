# SCA099 — begin/end asymétrique dans if/else

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> La branche then utilise `begin..end` mais la branche else est une instruction unique

## Description

Lorsque la branche then utilise `begin..end`, la branche else devrait faire de même (ou les deux devraient s'en passer). La forme mixte (`end else DoStuff;`) laisse un futur lecteur incertain : d'autres instructions appartenaient-elles à la branche else et ont-elles été oubliées ? `else if` (chaîne else-if) et `else begin` sont explicitement autorisés. Correspond à SonarDelphi communitydelphi:IfElseBegin.

## Exemples

### Mauvais (déclenche la règle)

```pascal
if Active then
begin
  DoA;
  DoB;
end
else
  DoC;
```

### Bon (correction idiomatique)

```pascal
if Active then
begin
  DoA;
  DoB;
end
else
begin
  DoC;
end;
```
