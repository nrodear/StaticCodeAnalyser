# SCA005 — Format() : nombre de marqueurs incohérent

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Bug-red)

> Le nombre de marqueurs de Format() / FormatUtf8() ne correspond pas au nombre d'arguments

## Description

Des marqueurs incohérents provoquent une EConvertError à l'exécution. Le détecteur gère le Format de la RTL (%s/%d/...) et le style % nu de mORMot (FormatUtf8/FormatString).

## Exemples

### Mauvais (déclenche la règle)

```pascal
Format('%s is %d', [Name]);   // <-- Age missing
```

### Bon (correction idiomatique)

```pascal
Format('%s is %d', [Name, Age]);
```
