# SCA066 — Liste d'arguments vide

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> `Foo()` devrait s'écrire `Foo;` - supprimer les parenthèses vides

## Description

La convention Delphi est d'écrire les appels sans paramètre sans `()`. La forme `Foo()` de style C ajoute du bruit sans rien communiquer et est incohérente avec le reste du langage (procédures, propriétés, références de fonction omettent toutes les parenthèses en l'absence d'arguments). Correspond à SonarDelphi communitydelphi:EmptyArgumentList.

## Exemples

### Mauvais (déclenche la règle)

```pascal
MyProc();
Result := MyFunc();
```

### Bon (correction idiomatique)

```pascal
MyProc;
Result := MyFunc;
```
