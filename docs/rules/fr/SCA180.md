# SCA180 — Le même attribut appliqué deux fois au même membre

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Deux attributs [X] identiques sur le même membre - reste de copier-coller, sans effet

## Description

Le modèle d'attributs de Delphi accepte les attributs répétés (certains, comme [TestCase], sont volontairement appliqués plusieurs fois avec des arguments différents). Les doublons avec des arguments IDENTIQUES ne le sont pas — ce sont généralement des restes de copier-coller issus d'un refactoring. Le détecteur compare les paires (nom d'attribut, texte des arguments) et signale les occurrences identiques dans le même groupe d'attributs (lignes distantes de 2 au maximum). Les attributs appliqués plusieurs fois avec des arguments différents ([TestCase('A','1')] / [TestCase('B','2')] différents) ne sont, à juste titre, PAS signalés.

## Exemples

### Mauvais (déclenche la règle)

```pascal
[Test]
[Test]
procedure Foo;
```

### Bon (correction idiomatique)

```pascal
[Test]
procedure Foo;
```
