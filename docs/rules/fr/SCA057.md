## Description

Agrégat de plusieurs résultats `DfmDbInUiForm` sur la même fiche - dès que leur nombre atteint 3, SCA ajoute une unique indication « extraire un TDataModule » en plus des résultats individuels (qui restent), afin de mettre en avant la correction architecturale au lieu de pointer un composant après l'autre. Déplacer l'accès aux données dans un TDataModule sépare proprement la plomberie de données de l'interface : la même TFDConnection et les mêmes requêtes peuvent être partagées par plusieurs fiches, la couche base de données est testable sans instancier de TForm, et la configuration DesignForm vs RuntimeForm reste propre. Le seuil est de 3 et actuellement codé en dur - maintenu bas, car dès que 3 composants de base de données apparaissent sur une fiche, le schéma est déjà mauvais.

## Exemples

### Mauvais (déclenche la règle)

```pascal
(TForm with 5+ TFDQuery/TFDConnection components)
```

### Bon (correction idiomatique)

```pascal
(move all DB components to a TDataModule)
```
