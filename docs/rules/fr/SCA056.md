# SCA056 — Maître-detail sans MasterFields

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Bug-red)

> Le TDataSet a MasterSource mais ni MasterFields ni IndexFieldNames

## Métadonnées

| Champ | Valeur |

| **Étiquettes** | `dfm`, `data-access`, `performance` |

## Description

La VCL effectue silencieusement un produit cartésien au lieu de la jointure maître-détail prévue - chaque ligne parente ramène toutes les lignes de détail à l'exécution. Corriger en renseignant MasterFields (et IndexFieldNames pour IB/FB).

## Exemples

### Mauvais (déclenche la règle)

```pascal
QDetail.MasterSource = dsMaster   // MasterFields = '' (empty)
```

### Bon (correction idiomatique)

```pascal
QDetail.MasterSource = dsMaster   QDetail.MasterFields = 'OrderID'
```
