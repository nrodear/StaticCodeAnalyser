# SCA030 — Gestionnaire d'événement lié mais vide

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> L'événement est câblé dans le DFM, la méthode existe, le corps est vide

## Métadonnées

| Champ | Valeur |
|---|---|
| **Identifiant de règle** | `SCA030` |
| **Kind** | `DfmEmptyBoundEvent` |
| **Sévérité par défaut** | Hint |

| **Unité du détecteur** | `uDfmEmptyBoundEvent.pas` |
| **Étiquettes** | `dfm`, `stub` |

## Description

Un gestionnaire vide avec une liaison DFM active est presque toujours un stub oublié après son ajout par le concepteur de fiches. Supprimer la liaison ou implémenter le gestionnaire.

## Exemples

### Mauvais (déclenche la règle)

```pascal
procedure TForm1.btnSaveClick(Sender: TObject);
begin
end;
```

### Bon (correction idiomatique)

```pascal
procedure TForm1.btnSaveClick(Sender: TObject);
begin
  SaveDocument;
end;

// or clear OnClick in the designer and delete the method
```
