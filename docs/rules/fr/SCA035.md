# SCA035 — Champ obligatoire lié uniquement à des contrôles cachés

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> Un TField avec Required=True n'est lié qu'à des contrôles ayant Visible=False

## Métadonnées

| Champ | Valeur |
|---|---|
| **Identifiant de règle** | `SCA035` |
| **Kind** | `DfmRequiredFieldNotVisible` |
| **Sévérité par défaut** | Warning |
| **Type** | Bug |
| **Unité du détecteur** | `uDfmRequiredField.pas` |
| **Étiquettes** | `dfm`, `ux`, `required-field` |

## Description

Le contrôle existe mais l'utilisateur ne peut ni le voir ni interagir avec lui - les insertions échouent à chaque fois. Rendre visible au moins un contrôle lié ou retirer le Required=True.

## Exemples

### Mauvais (déclenche la règle)

```pascal
DBEdit1.DataField = 'Email'   DBEdit1.Visible = False
```

### Bon (correction idiomatique)

```pascal
object DBEdit1: TDBEdit
  DataField = 'Email'
  Visible = True
end

// or drop Required = True if the field really is optional
```
