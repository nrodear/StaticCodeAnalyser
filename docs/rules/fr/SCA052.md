# SCA052 — Membre public inutilisé (API morte)

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

## Description

Aucune utilisation interne ET aucune utilisation externe trouvée - surface d'API morte. La supprimer ou la documenter comme exportée volontairement (p. ex. pour la compatibilité binaire).
