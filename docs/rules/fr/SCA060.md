# SCA060 — Instruction goto

> `goto` affaiblit le flot de contrôle structuré

## Description

`goto` et les étiquettes rendent le flot de contrôle non structuré : les boucles, l'imbrication et try/finally deviennent difficiles à suivre. SonarDelphi suit la même chose sous communitydelphi:GotoStatement. Le code Delphi moderne justifie rarement goto - même un break sur plusieurs niveaux est plus propre sous forme de procédure extraite avec Exit.

## Exemples

### Mauvais (déclenche la règle)

```pascal
label MyExit;
begin
  if Failed then goto MyExit;
  ...
  MyExit:
end;
```

### Bon (correction idiomatique)

```pascal
if Failed then Exit;
...
```
