# SCA058 — UPDATE / DELETE / TRUNCATE sans WHERE

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Bug-red)

> L'instruction SQL modifie toutes les lignes - clause WHERE manquante

## Description

`UPDATE Users SET Active=0` sans WHERE bascule toutes les lignes de la table. De même pour `DELETE FROM ...` et `TRUNCATE TABLE ...`. Une catastrophe en production qui ne demande qu'à arriver.

## Exemples

### Mauvais (déclenche la règle)

```pascal
Q.SQL.Text := 'UPDATE Users SET Active=0';
```

### Bon (correction idiomatique)

```pascal
Q.SQL.Text := 'UPDATE Users SET Active=0 WHERE Id=:id';
```
