# SCA067 — Bloc assembleur en ligne

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Bloc `asm...end` - préférer Pascal et les intrinsèques du compilateur

## Métadonnées

| Champ | Valeur |

| **Kind** | `InlineAssembly` |

| **Unité du détecteur** | `uInlineAssembly.pas` |
| **Étiquettes** | `portability`, `maintainability` |

## Description

L'assembleur en ligne crée une dépendance à la plate-forme (octets propres à x86/x64 qui ne survivent pas à une compilation croisée ARM ni aux cibles FreePascal), contourne l'optimiseur Delphi (pas d'inlining ni de réorganisation) et est difficile à déboguer. Les cas d'usage légitimes (détection CPUID, intrinsèques MMX/SSE) sont couverts par des helpers de la RTL. Correspond à SonarDelphi communitydelphi:InlineAssembly.

## Exemples

### Mauvais (déclenche la règle)

```pascal
function Cpuid: Cardinal;
asm
  XOR EAX, EAX
  CPUID
end;
```

### Bon (correction idiomatique)

```pascal
function Cpuid: Cardinal;
begin
  Result := GetCpuFeatures;
end;
```
