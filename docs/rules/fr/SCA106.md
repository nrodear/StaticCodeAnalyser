## Description

La convention Delphi est le PascalCase (UpperCamel) pour les routines et les méthodes : `DoSomething`, pas `doSomething` ni `do_something`. Les surcharges d'opérateurs et les identificateurs commençant par `_` sont exemptés. Correspond à SonarDelphi communitydelphi:MethodName. Basé sur l'AST : vérifie `nkMethod.Name` (un nom qualifié `TFoo.bar` est coupé au point). Exemptions pour tout le fichier : imports de bibliothèques de types générés (*_TLB.pas) et unités déclarant des classes FPC en langage étranger (objcclass/objccategory/cppclass) - leurs noms de méthodes SONT les sélecteurs/symboles de l'API étrangère ; les routines `external`, les méthodes de type `cdecl` et les types de liaison FFI (ancres d'import JNI/ObjC) sont exemptés méthode par méthode.

## Exemples

### Mauvais (déclenche la règle)

```pascal
procedure doStuff;
```

### Bon (correction idiomatique)

```pascal
procedure DoStuff;
```
