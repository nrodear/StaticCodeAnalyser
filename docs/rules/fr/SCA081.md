## Description

Lorsqu'une unité déclare deux classes publiques ou plus, les retrouver et les déplacer entre unités est plus difficile que nécessaire. SonarDelphi communitydelphi:ClassPerFile suggère la même chose. Les déclarations anticipées (`TFoo = class;`) et les types référence de classe (`TFooClass = class of TFoo`) sont exclus.

## Exemples

### Mauvais (déclenche la règle)

```pascal
type
  TFoo = class ... end;
  TBar = class ... end;
```

### Bon (correction idiomatique)

```pascal
// uFoo.pas
type TFoo = class ... end;
// uBar.pas
type TBar = class ... end;
```
