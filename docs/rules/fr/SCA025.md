# SCA025 — Texte d'interface en dur dans le DFM

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Caption, Hint ou Text sous forme de littéral dans le DFM, sans passer par la couche i18n

## Métadonnées

| Champ | Valeur |
|---|---|
| **Identifiant de règle** | `SCA025` |
| **Kind** | `DfmHardcodedCaption` |
| **Sévérité par défaut** | Hint |
| **Type** | Code Smell |
| **Unité du détecteur** | `uDfmHardcodedCaption.pas` |
| **Étiquettes** | `dfm`, `i18n`, `localization` |

## Description

Les chaînes destinées à l'utilisateur intégrées dans un .dfm ne peuvent être ni localisées, ni testées en A/B, ni conservées dans un catalogue de traduction. Les affecter lors de la construction de la fiche à partir d'une resourcestring ou d'un helper i18n. Non signalés : les captions d'un seul caractère dans des polices de symboles (Webdings/Wingdings/Marlett/Symbol - des icônes, pas du texte), les valeurs DFM que l'unité de la fiche remplace à partir d'une resourcestring (espaces réservés morts), et les fiches dont l'unité utilise un traducteur DFM à l'exécution (gnugettext/dxgettext/JvGnugettext, TranslateComponent, Dev-Cpp MultiLangSupport, cnwizards CnLangMgr, uLocalization*) - là, le texte DFM EST la source des msgid de la couche i18n.

## Exemples

### Mauvais (déclenche la règle)

```pascal
object btnSave: TButton
  Caption = 'Speichern'
end
```

### Bon (correction idiomatique)

```pascal
btnSave.Caption := _('btn.save');  // i18n at runtime
```
