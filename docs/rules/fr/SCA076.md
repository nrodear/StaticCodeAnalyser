# SCA076 — Déclaration groupée de variables, champs ou paramètres

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Séparer `A, B: Type` en une déclaration par ligne

## Description

Les déclarations groupées (`A, B, C: Integer;` pour des variables, des champs ou des paramètres) brouillent les diffs (une nouvelle variable modifie une ligne existante), empêchent les commentaires par variable et compliquent les refactorings de changement de type. Une déclaration par ligne est plus propre. Réunit SonarDelphi communitydelphi:GroupedFieldDeclaration / :GroupedVariableDeclaration / :GroupedParameterDeclaration en une seule règle (SCA pourra les séparer plus tard).

## Exemples

### Mauvais (déclenche la règle)

> Cette règle signale avec une confiance faible : avec la valeur par défaut `[Rules] MinConfidence=medium`, l'exemple ci-dessous reste masqué. Avec `[Rules] MinConfidence=low`, il apparaît.

```pascal
var A, B, C: Integer;
field FX, FY: TPoint;
```

### Bon (correction idiomatique)

```pascal
var A: Integer;
    B: Integer;
    C: Integer;
```
