## Description

Signalé uniquement lorsqu'il est prouvé que la cible est un emplacement de stockage : une variable locale, un paramètre, Result, une affectation au nom de la fonction, un champ déclaré dans la même unité - ou un chemin de membre (Pt.Y, R^.iType) dont la racine est un tel emplacement et dont chaque segment est un simple champ de record, résolu via les propres déclarations de record de l'unité plus une liste RTL sélectionnée (champs de TPoint, TRect, ...). Les cibles de type propriété restent muettes dans toutes les positions - écrire dans une propriété exécute son setter, qui peut borner, réappliquer ou reformater la valeur (TopLine := TopLine borne par rapport à la fenêtre redimensionnée ; TRectF.Height := TRectF.Height écrit Bottom). Les chemins indexés (a[i]) et les noms qui ne peuvent pas être résolus restent également muets. Le compromis est délibéré : les formes inconnues deviennent des faux négatifs, jamais des faux positifs. Result := Result; pour faire taire un hint du compilateur est tout de même signalé et peut être masqué avec un commentaire // noinspection directement au-dessus de la ligne.

## Exemples

### Mauvais (déclenche la règle)

```pascal
FCount := FCount;
```

### Bon (correction idiomatique)

```pascal
FCount := ACount;
```
