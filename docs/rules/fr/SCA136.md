# SCA136 — Constructeur qui alloue des champs et lève sans try/except

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Bug-red)

## Description

> Cette section n'existe qu'en anglais. Le nom et la description courte sont traduits ; les textes complets suivent la version anglaise.

When a constructor raises, Delphi calls the destructor on the half-constructed instance automatically. Fields the constructor already allocated are released only if that destructor frees them - with no destructor, or one that does not free these fields, they leak. The detector walks `nkMethod` nodes whose `TypeRef` starts with `constructor` (skipping class constructors via the `;class` marker), then requires (a) at least one `nkAssign` whose LHS is `F<Name>` / `Self.F<Name>` and whose RHS contains a `.Create` call, (b) at least one `nkRaise` anywhere in the body, and (c) no `nkTryExcept` anywhere in the body. The detector also reads the destructors of the class in the same unit: when they free every allocated field (a `Free`, `FreeAndNil`, `Release` or `DisposeOf` call that names the field, or `F<Name> := nil` for an interface field), there is no finding - unless a destructor writes to a member of such a field without an `if` on it (it would fail on the nil field before the rest is freed), or a thread constructor raises before its named `inherited Create`. Freeing through a property, a helper method, an owner component or a destructor in another unit is not recognised; such findings are false positives. Limitations: no flow analysis (raise BEFORE any field-init still flags); a partial try/except is treated as fully protective. Maps to Sonar-50 rule #12.

## Exemples

### Mauvais (déclenche la règle)

```pascal
constructor TFoo.Create;
begin
  FList := TStringList.Create;
  FOther := TOther.Create;
  if not Valid then
    raise EInvalidOp.Create('bad');     // <- FList/FOther leak unless Destroy frees them
end;
```

### Bon (correction idiomatique)

```pascal
constructor TFoo.Create;
begin
  FList := TStringList.Create;
  try
    FOther := TOther.Create;
    if not Valid then
      raise EInvalidOp.Create('bad');
  except
    FreeAndNil(FOther);
    FreeAndNil(FList);
    raise;
  end;
end;
```
