# SCA136 — Constructeur qui alloue des champs et lève sans try/except

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Bug-red)

> Le constructeur affecte des champs par `<Classe>.Create` puis lève sans try/except - les champs fuient si le destructeur ne les libère pas

## Description

Quand un constructeur lève une exception, Delphi appelle automatiquement le destructeur sur l'instance à moitié construite. Les champs que le constructeur a déjà alloués ne sont libérés que si ce destructeur les libère - sans destructeur, ou avec un destructeur qui ne libère pas ces champs, ils fuient. Le détecteur parcourt les nœuds `nkMethod` dont le `TypeRef` commence par `constructor` (en ignorant les constructeurs de classe via le marqueur `;class`), puis exige (a) au moins un `nkAssign` dont la partie gauche est `F<Name>` / `Self.F<Name>` et dont la partie droite contient un appel `.Create`, (b) au moins un `nkRaise` quelque part dans le corps, et (c) aucun `nkTryExcept` dans le corps. Le détecteur lit aussi les destructeurs de la classe dans la même unité : quand ils libèrent chaque champ alloué (un appel `Free`, `FreeAndNil`, `Release` ou `DisposeOf` qui nomme le champ, ou `F<Name> := nil` pour un champ interface), il n'y a pas de résultat - sauf si un destructeur écrit dans un membre d'un tel champ sans `if` sur celui-ci (il échouerait sur le champ nil avant que le reste soit libéré), ou si un constructeur de thread lève avant son `inherited Create` nommé. La libération via une propriété, une méthode auxiliaire, un composant propriétaire ou un destructeur d'une autre unité n'est pas reconnue ; de tels résultats sont des faux positifs. Limites : pas d'analyse de flot (un raise AVANT toute initialisation de champ est quand même signalé) ; un try/except partiel est considéré comme entièrement protecteur. Correspond à la règle Sonar-50 #12.

## Exemples

### Mauvais (déclenche la règle)

```pascal
constructor TFoo.Create;
begin
  FList := TStringList.Create;
  FOther := TOther.Create;
  if not Valid then
    raise EInvalidOp.Create('bad');     // <- FList/FOther leak unless Destroy frees them
end;
```

### Bon (correction idiomatique)

```pascal
constructor TFoo.Create;
begin
  FList := TStringList.Create;
  try
    FOther := TOther.Create;
    if not Valid then
      raise EInvalidOp.Create('bad');
  except
    FreeAndNil(FOther);
    FreeAndNil(FList);
    raise;
  end;
end;
```
