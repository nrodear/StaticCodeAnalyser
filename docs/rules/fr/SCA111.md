# SCA111 — ParamByName(...) appelé dans une boucle

> `Query.ParamByName('x').AsXxx := ...` dans une boucle - recherche linéaire à chaque itération

## Description

ParamByName parcourt la collection TParam par comparaison de chaînes à chaque appel (linéaire en nombre de paramètres). Dans un chemin critique / une boucle, un ParamByName par Query.Execute devient N par Execute. Mettre en cache la référence TParam une fois hors de la boucle, ou utiliser la propriété indexée par entier Params[i] si la position du paramètre est connue.

## Exemples

### Mauvais (déclenche la règle)

```pascal
for i := 0 to High(Ids) do begin
  Q.ParamByName('id').AsInteger := Ids[i];
  Q.ExecSQL;
end;
```

### Bon (correction idiomatique)

```pascal
var P := Q.ParamByName('id');
for i := 0 to High(Ids) do begin
  P.AsInteger := Ids[i];
  Q.ExecSQL;
end;
```
