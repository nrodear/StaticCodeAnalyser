# SCA186 — Séquence UTF-8 invalide dans le fichier source

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-File%20Error-grey)

> UTF-8 mal forme (surlong, substitut ou hors plage) sous un BOM UTF-8

## Description

Le fichier porte un BOM UTF-8 mais contient des séquences d'octets qui ne sont pas de l'UTF-8 valide au sens de la RFC 3629 (encodages surlongs, substituts isolés ou points de code au-delà de U+10FFFF). Le compilateur Delphi les remplace silencieusement par U+FFFD, ce qui corrompt les caractères concernés. Réencoder le fichier en UTF-8 propre.
