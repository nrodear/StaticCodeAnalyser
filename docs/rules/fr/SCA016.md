# SCA016 — Chemin de fichier en littéral chaîne

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Security%20Hotspot-orange)

> Chemin C:\, UNC ou Linux écrit en dur dans le source

| Champ | Valeur |

| **Étiquettes** | `portability`, `configuration` |

## Description

Les chemins écrits en dur nuisent à la portabilité et au déploiement CI. Utiliser des fichiers de configuration, des variables d'environnement ou des helpers de chemin adaptés à la plateforme (TPath.Combine, etc.).

## Exemples

### Mauvais (déclenche la règle)

```pascal
LogFile := 'C:\Logs\app.log';
```

### Bon (correction idiomatique)

```pascal
LogFile := TPath.Combine(GetEnvironmentVariable('LOGDIR'), 'app.log');
```
