# SCA173 — Variant dans une méthode sensible aux performances (avec boucle)

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Variable Variant dans une méthode contenant une boucle - chaque opération Variant paie un surcoût de dispatch COM de 10 à 100 fois

## Description

Les opérations sur Variant passent par le répartiteur COM VarType (VarAdd, VarCmp, VarCast, ...), ce qui ajoute un aller-retour par le système de types à chaque lecture, écriture, comparaison et conversion. Dans une boucle critique, ce coût est multiplié par le nombre d'itérations et peut dominer le temps d'exécution de la méthode. Le détecteur signale chaque variable locale et chaque paramètre Variant / OleVariant dans les méthodes qui contiennent au moins une boucle for/while/repeat. Les cas d'usage acceptés (ponts COM/OLE, adaptateurs JSON-Variant, automatisation Excel) se traitent via le marqueur de suppression `// noinspection VariantTypeMisuse`.

## Exemples

### Mauvais (déclenche la règle)

```pascal
procedure SumRows;
var v: Variant; i: Integer;
begin
  for i := 0 to N do v := v + Rows[i];
end;
```

### Bon (correction idiomatique)

```pascal
procedure SumRows;
var s: Double; i: Integer;
begin
  s := 0;
  for i := 0 to N do s := s + Rows[i];
end;
```
