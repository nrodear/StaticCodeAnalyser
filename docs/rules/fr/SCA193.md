## Description

Un identificateur (variable, type, routine, ...) contient un caractère non-ASCII. C'est le vecteur des homoglyphes / identificateurs confondables de la famille Trojan Source (CVE-2021-42694, CWE-1007) : une lettre comme le cyrillique U+043E ressemble au 'o' latin mais forme un identificateur différent, si bien que deux identificateurs peuvent sembler identiques et pourtant désigner des choses différentes. Un identificateur Unicode légitime est aussi possible, donc examiner avant de modifier ; préférer des identificateurs ASCII pour la portabilité et pour éviter la confusion.

## Exemples

### Mauvais (déclenche la règle)

```pascal
var Login: string;  // one letter is a Cyrillic homoglyph (U+043E), not Latin 'o'
```

### Bon (correction idiomatique)

```pascal
var Login: string;  // all-ASCII identifier
```
