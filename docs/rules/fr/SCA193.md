# SCA193 — Lettre sosie (homoglyphe) dans un identificateur

## Description

Un identificateur (variable, type, routine, ...) contient une lettre cyrillique ou grecque qui ressemble exactement à une lettre latine - par exemple le U+043E cyrillique au lieu du 'o' latin, ou le Mu majuscule grec U+039C au lieu de 'M'. C'est le vecteur des homoglyphes / identificateurs confondables de la famille Trojan Source (CVE-2021-42694, CWE-1007) : deux identificateurs peuvent sembler identiques et pourtant se lier différemment. Seule compte une table fixe de sosies connus : les majuscules cyrilliques et grecques d'aspect latin, les minuscules cyrilliques a, e, o, p, c, y, x, s, i, j, h, l, d, q, w et l'omicron minuscule grec. Les umlauts, les lettres accentuées et les lettres sans jumelle latine ne sont pas signalés - ils ne trompent personne ; là où des outils cassent un tel nom (UTF-8 sans BOM, Free Pascal), SCA207 le signale. Un nom écrit entièrement dans une autre écriture peut tout de même contenir des lettres de la table et il est signalé ; vérifier avant de modifier. Un résultat par fichier, à la ligne de la première lettre sosie dans le code ; uniquement les fichiers dont l'encodage est certain (BOM ou UTF-8 valide). Préférer des identificateurs ASCII.

## Exemples

### Mauvais (déclenche la règle)

```pascal
var Login: string;  // one letter is a Cyrillic homoglyph (U+043E), not Latin 'o'
```

### Bon (correction idiomatique)

```pascal
var Login: string;  // all-ASCII identifier
```
