# SCA097 — Destructeur sans appel a inherited

![Severity](https://img.shields.io/badge/severity-Error-red) ![Type](https://img.shields.io/badge/type-Bug-red)

> Il manque `inherited Destroy` au destructeur - le nettoyage du parent est sauté (risque de fuite)

## Description

Un destructeur sans `inherited Destroy` (ni `inherited;`) empêche la classe parente de libérer ses propres champs, de désinscrire des gestionnaires et de mettre à jour les compteurs de références. Presque toujours une fuite. Correspond à SonarDelphi communitydelphi:DestructorWithoutInherited.

## Exemples

### Mauvais (déclenche la règle)

```pascal
destructor TFoo.Destroy;
begin
  FreeAndNil(FBar);
end;
```

### Bon (correction idiomatique)

```pascal
destructor TFoo.Destroy;
begin
  FreeAndNil(FBar);
  inherited;
end;
```
