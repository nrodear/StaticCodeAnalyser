# SCA096 — Constructeur sans appel à inherited

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

> Il manque `inherited Create` au constructeur - le parent reste non initialisé

## Description

Un constructeur qui n'appelle pas `inherited Create(...)` (ni `inherited;`) saute l'initialisation de la classe parente. Les champs et enregistrements du parent restent à l'état par défaut/nil, ce qui entraîne des plantages en aval lorsque des méthodes s'attendent à ce que le parent soit prêt. Correspond à SonarDelphi communitydelphi:ConstructorWithoutInherited.

## Exemples

### Mauvais (déclenche la règle)

```pascal
constructor TFoo.Create;
begin
  FX := 0;
end;
```

### Bon (correction idiomatique)

```pascal
constructor TFoo.Create;
begin
  inherited;
  FX := 0;
end;
```
