# SCA152 — Texte visible par l'utilisateur affecté en littéral

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Les affectations a Caption/Hint/Text et les appels a ShowMessage/MessageDlg avec du texte littéral contournent resourcestring et i18n - la chaîne n'est pas traduisible

## Description

Un texte visible par l'utilisateur codé en dur rend l'application intraduisible sans modifier le code source. Le détecteur analyse lexicalement chaque ligne source à la recherche de deux motifs étroits : `<ident>.Caption|Hint|Text := '<text>'` et `ShowMessage|MessageDlg('<text>'`. Le texte capturé n'est signalé que s'il (a) fait au moins 2 caractères, (b) contient au moins une lettre (ce qui écarte les séparateurs d'un caractère comme `'-'`, `'.'`, `':'` et les littéraux numériques), et (c) ne ressemble pas à une clé de ressource (uniquement majuscules + soulignés, ou commence par `$`). Les commentaires de ligne (`//`) sont ignorés. Limites : les correspondances sur des classes non graphiques ayant une propriété Caption/Hint/Text (p. ex. des auxiliaires internes) peuvent produire des faux positifs - dans ce cas, utiliser le marqueur de suppression de ligne `// noinspection HardcodedString`. Correspond à la règle Sonar-50 #46 (forme étroite, UI uniquement).

## Exemples

### Mauvais (déclenche la règle)

```pascal
Form1.Caption := 'Mein Programm';
Button1.Hint  := 'Klick mich';
ShowMessage('Daten gespeichert');
```

### Bon (correction idiomatique)

```pascal
resourcestring
  SAppCaption = 'Mein Programm';
  SBtnHint    = 'Klick mich';
  SSavedMsg   = 'Daten gespeichert';

Form1.Caption := SAppCaption;
Button1.Hint  := SBtnHint;
ShowMessage(SSavedMsg);
```
