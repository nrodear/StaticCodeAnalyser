# SCA009 — Objet créé sans try/finally protecteur

## Description

> Cette section n'existe qu'en anglais. Le nom et la description courte sont traduits ; les textes complets suivent la version anglaise.

Similar to MemoryLeak (SCA001) but checked structurally: any .Create followed by code without an enclosing try/finally is flagged regardless of whether Free is called eventually.

## Exemples

### Mauvais (déclenche la règle)

```pascal
obj := TFoo.Create;
obj.DoStuff;
obj.Free;
```

### Bon (correction idiomatique)

```pascal
obj := TFoo.Create;
try obj.DoStuff finally obj.Free end;
```
