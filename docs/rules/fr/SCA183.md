# SCA183 — Attribut suivi d'une ligne vide avant le membre cible

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Ligne d'attribut suivie d'une ligne vide - visuellement détachée, souvent un reste de refactoring

## Description

Le compilateur Delphi rattache un attribut au membre syntaxiquement suivant, quelles que soient les lignes vides intercalées. Visuellement en revanche, un attribut séparé de son membre par une ligne vide passe facilement inaperçu - le lecteur peut ne pas se rendre compte que l'attribut s'applique au membre en dessous. C'est aussi un symptôme fréquent d'un refactoring où un membre a été déplacé/supprimé mais l'attribut est resté. Le détecteur signale les lignes d'attribut dont la ligne non vide suivante se trouve à plus d'une ligne de distance.
