## Description

La convention de codage Pascal est l'indentation par espaces depuis les années 80. Les tabulations s'affichent sur 2/4/8 colonnes selon l'éditeur, cassent les diffs côte à côte des revues de code et perturbent l'alignement. SonarDelphi suit la même chose sous communitydelphi:TabulationCharacter.

## Exemples

### Mauvais (déclenche la règle)

> Cette règle signale avec une confiance faible : avec la valeur par défaut `[Rules] MinConfidence=medium`, l'exemple ci-dessous reste masqué. Avec `[Rules] MinConfidence=low`, il apparaît.

```pascal
procedure Foo;
begin
<TAB>DoStuff;
end;
```

### Bon (correction idiomatique)

```pascal
procedure Foo;

  DoStuff;

```
