# SCA103 — Champ de classe sans préfixe F

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Les champs de classe doivent suivre la convention `F<Nom>`

## Description

Convention Delphi : les champs d'instance de classe se nomment `FFoo`, afin que le lecteur sache immédiatement qu'il s'agit d'un membre de la classe (et non d'une variable locale ou d'un paramètre). Le préfixe `F` évite les conflits de noms avec les propriétés publiques (le champ `FFoo` avec la propriété `Foo` forme la paire canonique). Seules les déclarations de champs `private` et `protected` sont vérifiées - les champs public/published sont de toute façon couverts par `PublicField` (SCA089). Correspond à SonarDelphi communitydelphi:FieldName.

## Exemples

### Mauvais (déclenche la règle)

```pascal
type TFoo = class
  private
    Counter: Integer;
  end;
```

### Bon (correction idiomatique)

```pascal
type TFoo = class
  private
    FCounter: Integer;
  end;
```
