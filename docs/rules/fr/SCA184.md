# SCA184 — Composant DFM inutilisé

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Le composant DFM n'est référencé ni dans le code, ni dans d'autres unités, ni dans le DFM lui-même - probablement un reste de refactoring

## Description

Un composant déclaré dans le .dfm n'a aucune liaison d'événement, n'est référencé par les propriétés d'aucun autre composant (DataSource, Action, ActiveControl, ...), n'est jamais utilisé dans le code Pascal de la fiche elle-même et n'est accédé depuis aucune autre unité via la variable globale de la fiche. Il s'agit très probablement d'un reste de refactoring qui est toujours alloué à l'exécution. Comme la preuve d'utilisation repose sur les noms (pas de liaison exacte), cette règle est émise avec une confiance faible et reste hors du profil de confiance par défaut jusqu'à sa validation sur du code réel. Les composants de champ persistants (T*Field) ainsi que les frames incorporées / composants hérités sont ignorés par prudence ; le détecteur reste muet sans index inter-unités à l'échelle du dépôt.
