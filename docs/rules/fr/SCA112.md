# SCA112 — FieldByName(...) appelé dans une boucle

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> `DataSet.FieldByName('x').AsXxx` dans une boucle - recherche linéaire à chaque enregistrement

## Description

FieldByName parcourt la collection TFields par comparaison de chaînes à chaque appel. Dans une boucle d'itération sur un DataSet, une recherche par champ devient N recherches par .Next, parfois par enregistrement fois N champs = O(N*M). Mettre en cache la référence TField une fois avant la boucle et la lire/écrire directement. Même correction que SCA111 (ParamByName) - seule la collection diffère.

## Exemples

### Mauvais (déclenche la règle)

```pascal
while not Q.Eof do begin
  Total := Total + Q.FieldByName('Amount').AsCurrency;
  Q.Next;
end;
```

### Bon (correction idiomatique)

```pascal
var Amt := Q.FieldByName('Amount');
while not Q.Eof do begin
  Total := Total + Amt.AsCurrency;
  Q.Next;
end;
```
