# SCA118 — Classe d'exception sans préfixe `E`

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Un descendant de `class(Exception)` doit suivre la convention `E<Nom>` de la RTL Delphi

## Description

La convention de la RTL Delphi est sans ambiguïté : les classes d'exception commencent par `E` (EAbort, EConvertError, EAccessViolation). Les classes d'exception définies par l'utilisateur qui omettent le préfixe rompent la convention et obscurcissent la nature de la classe au site d'appel (`raise MyError.Create(...)` vs `raise EMyError.Create(...)`). Le détecteur reconnaît toute classe dont le TypeRef hérite d'une classe Exception connue (Exception, EAbort, EAccessViolation, EExternal) et dont le nom ne commence pas par `E<UpperCase>`.

## Exemples

### Mauvais (déclenche la règle)

```pascal
type
  MyError = class(Exception);
```

### Bon (correction idiomatique)

```pascal
type
  EMyError = class(Exception);
```
