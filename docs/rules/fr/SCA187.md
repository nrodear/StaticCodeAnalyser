## Description

Le fichier source contient un octet NUL ou un caractère de contrôle interdit (en dessous de U+0020, hors tabulation / saut de ligne / retour chariot / saut de page). Cela signifie généralement que le fichier est binaire ou que son encodage a été mal détecté (par exemple de l'UTF-16 sans BOM, où un octet sur deux vaut 0x00). Examiner le fichier et le réencoder.
