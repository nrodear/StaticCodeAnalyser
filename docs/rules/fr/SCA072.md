# SCA072 — Comparaison booléenne redondante

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> `X = True` devrait s'écrire `X` (et `X <> False` de même)

## Description

Comparer un Boolean à True/False est verbeux et crée des bugs subtils (BOOL de la WinAPI : avec une valeur vraie != 1, `X = True` s'évalue à false). L'expression elle-même est déjà la condition. Correspond à SonarDelphi communitydelphi:RedundantBoolean. Remarque : les déclarations `const X = True;` sont exclues (affectation légitime, pas une comparaison).

## Exemples

### Mauvais (déclenche la règle)

```pascal
if Active = True then ...
if Disabled <> False then ...
```

### Bon (correction idiomatique)

```pascal
if Active then ...
if Disabled then ...
```
