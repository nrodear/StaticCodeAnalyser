## Description

Un double point-virgule (`;;`) signale généralement une faute de frappe oubliée ou un reste de copier-coller égaré. Les compilateurs traitent le second `;` comme une instruction vide ; cela ne casse donc rien, mais ajoute du bruit. Correspond à SonarDelphi communitydelphi:SuperfluousSemicolon.

## Exemples

### Mauvais (déclenche la règle)

```pascal
DoStuff;;
```

### Bon (correction idiomatique)

```pascal
DoStuff;
```
