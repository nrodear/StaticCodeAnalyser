## Description

Des doubles parenthèses autour d'un identificateur, d'un littéral ou d'une expression simple n'apportent rien - une seule paire suffit (souvent aucune). Correspond à SonarDelphi communitydelphi:RedundantParentheses. Seul le cas de l'expression simple est signalé ; un `((A + B))` complexe peut encore tirer profit des parenthèses internes pour la priorité et n'est pas signalé.

## Exemples

### Mauvais (déclenche la règle)

```pascal
if ((Active)) then ...
Result := ((42));
```

### Bon (correction idiomatique)

```pascal
if Active then ...
Result := 42;
```
