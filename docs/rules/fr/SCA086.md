# SCA086 — Éviter le modificateur out

> Préférer `var` a `out` (out a une sémantique surprenante)

## Description

Les paramètres `out` vident les types managés (string/Interface/tableaux dynamiques) à l'entrée de la méthode - la valeur de l'appelant est abandonnée avant l'exécution de la méthode. Les types record/simples restent non initialisés, si bien que lire la valeur entrante est un comportement indéfini. Ces deux effets sont rarement voulus. `var` est le choix par défaut le plus sûr, sauf si la sémantique d'interopérabilité COM est nécessaire. Correspond à SonarDelphi communitydelphi:AvoidOut.
