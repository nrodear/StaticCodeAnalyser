# SCA164 — Routine de premier niveau jamais appelée

![Severity](https://img.shields.io/badge/severity-Hint-blue) ![Type](https://img.shields.io/badge/type-Code%20Smell-yellow)

> Une procédure ou fonction autonome de la section implementation n'est appelée nulle part dans l'unité et n'est pas exportée par la section interface - code mort

## Description

Comble le vide entre SCA147 (UnusedPrivateMethod - seulement les méthodes privées de classe) et la famille de contrôles de visibilité SCA148+ (seulement les membres publics de classe). Détecte les routines de premier niveau (hors classe) dont le nom n'apparaît nulle part comme appel dans la même unité, auto-références exclues (une routine récursive qui ne fait que s'appeler elle-même est tout de même signalée - comme le UnusedRoutineCheck de SonarDelphi). Gardes anti-faux positifs : constructeurs et destructeurs (non appelables directement comme procédure), les directives `override`/`virtual; abstract`/`message`/`dynamic` (dispatch inter-classes ou système), la procédure d'amorçage IDE `Register`, le trio de l'énumérateur (`MoveNext`/`GetEnumerator`/`Current` - invoqués implicitement par `for-in`) et toute routine déclarée par anticipation dans la section interface de l'unité (consommateur potentiel dans une autre unité). La portée est un seul fichier - les appelants d'autres unités des routines de la section interface ne sont pas suivis dans ce MVP, ces routines sont donc volontairement ignorées. Masquer avec `// noinspection UnusedRoutine` quand la routine est conservée volontairement (invocation via RTTI, consommée par un attribut, chargée par un plugin). Correspond au UnusedRoutineCheck de SonarDelphi.

## Exemples

### Mauvais (déclenche la règle)

```pascal
implementation
procedure InternalHelper;     // never called
begin
  WriteLn('hi');
end;
end.
```

### Bon (correction idiomatique)

```pascal
implementation
// remove InternalHelper, or call it from somewhere,
// or move it to interface if it should be exported
```
