# SCA040 — Accès à un champ d'une autre fiche

![Severity](https://img.shields.io/badge/severity-Warning-orange) ![Type](https://img.shields.io/badge/type-Bug-red)

## Description

Aller chercher un contrôle enfant dans une autre fiche casse l'encapsulation - tout renommage dans Form2 casse silencieusement Form1. Exposer plutôt une propriété ou une méthode sur Form2.

## Exemples

### Mauvais (déclenche la règle)

> Cette règle signale avec une confiance faible : avec la valeur par défaut `[Rules] MinConfidence=medium`, l'exemple ci-dessous reste masqué. Avec `[Rules] MinConfidence=low`, il apparaît.

```pascal
Form2.EdName.Text := 'x';
```

### Bon (correction idiomatique)

```pascal

```
